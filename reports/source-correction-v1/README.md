# Source-trained bounded correction pilot

Completed. See the [Chinese result analysis](REPORT_ZH.md), [results](RESULTS.json), and [execution audit](EXECUTION_AUDIT.json). R improves over D by 0.223584 Dice pp on the reused development panel, but image/support increments remain inconclusive, the RMS-matched control loses to D, and shuffled image evidence has a higher mean. The predeclared advancement gate failed.

See the [frozen Chinese protocol and route assessment](PROTOCOL_ZH.md). This is an ECSC-inspired mechanism experiment, not a reproduction of the complete S3-Adapt system. It switches from learned adaptation losses to source-supervised direct signed logit correction on the unchanged reference backbone. No RDC, ENGRAM, foundation-model downloads, text, population-area constraints, or continual state are introduced.

`src/dpa_ctta/source_correction/` reuses the existing R78 model/data interfaces and selected prior heads. Four independently optimized 3,649-parameter heads receive identical source supervision, initialization, augmentation schedule and validation selection: original D retraining, full-grid bounded correction R, band-limited R, and geometry-only R. The primary comparison is R minus D_RETRAIN. A downscaled R readout tests the actual functional RMS budget explanation, with explicit unmatched coverage when scaling upward would violate the fixed bound.

The fixed matrix contains 672 outputs and 448 regenerated baseline parity checks against the preceding amplitude-matched run. All original 40 content groups and the same train/validation/support/query roles are retained. The GPU worker can read only authorized source train/validation labels; final query labels and previous outcome scores are blocked. An independent CPU-only scorer runs after successful worker retirement. Source-trained output correction is feed-forward; it is not itself TTA or CTTA.

For reproduction, prepare a new approved run directory with `code`, `private`, `scorer`, `public`, `predictions`, `processes`, `attempts`, and `logs`. Bind the config with `output_root`, R78 `prior_root`, preceding `amplitude_root`, `source_root`, `checkpoint_path`, and a checked GPU identity. Reuse the existing exact private R78 content panel and isolated scorer panel. Preserve the pinned reference and GraTa environment variables, run the four CPU tests, and use the existing neutral interpreter/entry arrangement. `DIAG_MODE=controller` runs one capped worker then one capped scorer; there is no automatic retry or expansion. The neutral entry loads private paths from an environment file and invokes `dpa_ctta.source_correction.run`.

The contents were already exposed in earlier development experiments; patient linkage and backbone pretraining membership are unknown. Neither independent-patient generalization nor TMI-level novelty can be inferred from this pilot alone. Public artifacts exclude raw data, masks, weights, per-case predictions/scores, identifiers and private paths.

The initial worker completed all training but failed a C_FULL baseline parity check before final scoring. The retained source-trained heads were loaded in one isolated completion process; no training or checkpoint selection was replayed. `reuse_selected_heads_only=true` with `DIAG_MODE=completion_controller` requires the preserved first failed ledger, charges both attempts, and requires the unchanged full parity matrix before scoring. This engineering completion and its limits are documented in the protocol amendment and report.
