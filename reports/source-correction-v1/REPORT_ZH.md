# 源监督有界修正：路线分析与小规模对照结果

2026-10-19。**实验完成；R 相对 D 有开发集增益，但图像条件机制及 TMI 路线推进门槛未成立。** 不叠加 RDC、ENGRAM，没有追加训练、幅度扫描、种子或 CTTA 长流。

## 为什么换这条路线，能否做成 TMI

从此前已全文核查的 12 篇 ICLR 2027 投稿中，选择 **S3-Adapt 的 Evidence-Conditioned Selective Correction（ECSC）思想**，将主线从“学习在线损失”转到“源监督学习有界直接纠错”。[原文入口](https://openreview.net/forum?id=WykGoKnySH)，方法依据为已下载全文第6页式(6)/(8)和第14–15页训练状态；本轮网页工具访问未成功，使用前轮 OpenReview API 下载并精读的版本，不声称验证了最新在线修订或录用状态。

选择理由来自本项目负结果：等幅 X 与纯几何 P 几乎一致，且仍低于直接修正 D。直接源监督可以学习正负纠错，不依赖熵/教师置信来推断错误，也不要求任务塑性必须经过512维BN梯度通路。旧 D 又被窄边界 support 和距离尺度 h 限制，本轮 R 允许全图1-logit残差，直接检验该表达限制是否压制了效用。

**复用的是训练后固定参考＋signed tanh logit correction，而非整篇系统。** 未下载/引入 BiomedCLIP、MedSAM2、接地概率、文本或跨模型语义桥；保留本项目 ResUNet、9通道图像/几何接口和 BCE+普通 soft Dice。原文 class-balanced BCE+squared Dice 也未同时搬入。因此这是 ECSC 启发的最小机制迁移，既非作者实现复现，也不能用本轮结果否定原论文完整系统。

12篇重新比较见[冻结方案](PROTOCOL_ZH.md)：CAREM的二分类适用性、Calibration的源损失资格、ONH的人口病理先验、TopoSculpt的结构/计算条件都不匹配；SRDF路线已有直接负结果；其余同源置信损失或大基础模型系统没有比当前D更扎实的本地线索。本轮只选一条路线，没有把频率、拓扑和置信模块叠起来。

TMI 角度必须分清“比前轮更值得测”与“贡献已经足够”：**一个有监督 tanh 修正头本身不新，单独达不到 TMI 方法体量。** 原计划只有在源纠错、图像信息和修正范围三个机制均得到强控制支持后，才值得另行研究真实域外病理差异保护及连续流中的纠错/保留。当前试验不建立持续状态、独立患者泛化或跨医院效果；结果也未通过预定机制门槛，因此没有把它升级为 TMI 主方法。

## 公平训练与冻结矩阵

四个3,649参数头完全独立优化，初始化、源标签预算、增强、Adam(.001)和验证选择相同：D_RETRAIN复现原D，R为全图1-logit修正，R_BAND只保留原预测边界support，R_GEOM去掉RGB/边缘四通道。每头200 episode/400次源标签访问；共800 episode、1,600次标签访问；各自每50 episode验证，选出的episode依次为150/100/150/100。验证沿用原8内容组中的4个query，4条件×4检查点=每头64读出；另外4个validation support不参与这些直接头的评分。骨干始终冻结。

沿用16训练/8验证/8 support/8 query内容组。9个DIRECT分支各32读出，F/等幅X/等幅P/完整CW_LSO各保留SELF、匹配跨图和错配跨图共96读出，总计672。原图、gamma、RGB、blur四条件、全部方法和主比较 **R−D_RETRAIN** 都在读取最终标签前冻结。

R_NEG反转R；R_SHUFFLE只平移图像/边缘输入，几何输入不动。R_BUDGET逐query将R的全图logit RMS缩小至D_RETRAIN，半径只用无标签预测确定，本轮32/32均匹配。它们是诊断控制，不用于最终标签选方法。

## 为什么还不能建立图像条件纠错机制

首先，R比R_GEOM仅+0.063369pp，区间[−0.044964,+0.191806]，34/64单元落后；R比R_BAND虽平均+0.317899pp，区间[−0.044533,+0.669251]也跨0。现有小样本不足以确定图像信息和扩大修正范围各自的增量。

其次，**图像/边缘平移后的R_SHUFFLE反而有更高均值**：R−SHUFFLE为−0.545785pp，区间[−1.232505,+0.164231]，46/64单元落后。平移会造成训练/部署输入错配，不能据此证明“所有图像信息有害”；但它明确没有支持“正确空间对齐的局部图像证据导致收益”。也不能将这个预先固定的破坏性诊断事后选成新主方法。

函数变化差异同样很大：

|方法|平均logit RMS|平均绝对概率变化|每query变化像素（双通道）|
|---|---:|---:|---:|
|D_RETRAIN|0.021320|0.00024697|174.3438|
|R|0.939154|0.00102738|324.5938|
|R_BAND|0.017219|0.00026246|214.4375|
|R_GEOM|0.771071|0.00096946|341.0625|

|R_SHUFFLE|0.933797|0.00205238|941.8125|

R的全图logit RMS约为D的 **44.05倍**，许多改动可发生在非常确信的背景，硬变化数只有约1.86倍。因此“1-logit上界较小”不等于总函数改动预算较小。缩小因子平均0.022698；R_BUDGET在32/32确实匹配D的RMS后，**比D低0.172506pp，区间[−0.312549,−0.034270]，51/64单元下降**。现有结果无法排除更大/更广函数变化是收益的重要来源。

但全图标量RMS并不匹配边界内预算、空间支持或概率灵敏度；D的改动集中在边界，R则分散于全图。因此这不是证明“只有幅度有效”，也不证明任意任务相关预算下R必然差于D。当前缺少独立固定logit偏置/阈值校准强控制；几何对照接近且平移诊断均值更高，使该反解释尤其需要重视。按协议不在本轮结果出来后追加这个对照或调κ。

反向R比正常R差1.123543pp，区间下界>0，说明当前符号具有局部任务效用；它仍不能补足图像条件信息、空间范围和等预算的机制证据。

**结论与停止：** 此路线给出了比旧直接修正更好的开发配置，但主增益未到+.5pp，图像/支持范围增量区间均跨0，等函数幅度对照落后，故预定推进门槛未通过。当前应保留R为后续研究的直接修正基线，不宣称图像条件新机制或TMI方法已经成立，也不自动继续实验。
