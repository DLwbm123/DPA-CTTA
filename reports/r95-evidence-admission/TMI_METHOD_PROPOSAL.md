# 面向 TMI 的候选方案：历史编辑支持度驱动的只读输出选择

日期：2026-10-21。类型：方法设计与可证伪研究计划；**PROPOSAL_ONLY / NOT_ADMITTED**。供 Pro 审查。本文不是新实验结果、预注册完成或GPU启动授权。不重算R90–R94，不修改旧门槛，不恢复已关闭路线。

## 1. 决策摘要

建议只保留一个候选：沿用VV的全部持续更新，通过初态与当前入站状态的配对弱视图预测，测量历史新增前景的跨视图支持，检验它能否辨识“当前内容改用强静态Q0是否更好”。第一版只进行整图双头同步输出选择，不训练selector，不改损失、学习率、Adam、写入频率或历史状态。

面向TMI的潜在贡献是**历史状态配对、编辑区域定位及其对具体动作收益的增量信息**，不是增加模块数量。“动作价值合同”和严谨评估是必要证据，不能单独算算法创新。若信号不能超过简单熵、视图方差、编辑面积及匹配随机动作，本方案不具备预期的方法贡献，应关闭本定义。

当前仍缺必要逐视图概率资产、具体测量准入、数据/身份/许可与独立评价材料、门槛依据及新运行资源。R96–R98维持NOT_ADMITTED。本文只将用户已讨论的方案写清，未自动冻结阈值或扩大数据访问。

## 3. 待证伪假设

**H：历史新增前景中，弱视图对该新增方向支持不足的程度，包含关于Q0相对VV原图K输出收益的增量信息；它能够超过当前预测不确定性、编辑面积和非信息性动作选择，并保留有益适应。**

这是假设，不是从R92/R94已经得到的结论。主要反证包括：错误编辑也可跨视图一致；正确编辑也可因增强而不一致；信号可能只代理域、对象大小、编辑面积或流位置；Q0也可能错误；当前一步可能已修正入站状态的问题。

## 4. 最小方法定义

### 4.1 状态与端点

- θ0：原模型初态。静态探测使用初态affine及当前输入统计，不是stored-source-stat推理；不是新训练模型或EMA教师。
- θt：图像t到达时的VV学习状态。
- P0、P：分别在θ0和θt下的原图二值输出，沿既有阈值与预处理，不新增阈值搜索。
- K：原VV对该内容完成一次更新后的原图输出。
- Q0：θ0下原固定六弱视图读出。

NATIVE仍是连续更新的动态基线；不纳入静态候选。所有模型权重/非BN参数、q/W、增强、损失与Adam沿VV原定义。静态探测仅作只读访问。

### 4.2 同输入、同视图的状态配对

对当前图像的每个弱视图v、头h和有效对齐像素u，测量

    d[t,v,h,u] = p(θt,h,v,u) − p(θ0,h,v,u).

两状态的视图参数、预处理、反变换、有效区域完全相同。使用原六弱视图，不为信号另挑增强。几何插值与无效边缘需固定，不能将填充值当不支持；此定义要求共同有效像素。六视图相关，不能当六个独立样本。

这是两个状态的配对差异，不是已识别的独立因果效应，也不是对预测正确性的概率估计。

### 4.3 一个主信号：历史新增前景的不支持比例

原图历史新增前景区域：

    E+[t,h] = {u : P[t,h,u]=1 且 P0[t,h,u]=0}.

在共同有效区域中计算

    c[t,h,u] = mean_v 1{d[t,v,h,u] > ε_num}
    U[t,h] = mean_(u in E+[t,h]) (1 − c[t,h,u])
    U[t] = (U[t,OD] + U[t,OC]) / 2.

空E+约定U[t,h]=0；若视图对齐/有效性不合格则资格失败，不能默默当0。ε_num只能来自事前数值资格与精度约定，不能用任务得分选择。固定二值阈值两侧的编辑不等于变化幅度，因此轻微跨阈值编辑也是本候选的已知弱点，不能失败后临时加入幅度过滤。

负向删除E−单列描述，不并入主信号、不增加第二阈值。双头等权是一项待审设计选择，可能稀释OC风险；若据评分改为OC专用或max聚合，必须记为另一个开发版本，原候选不能追改成通过。

### 4.4 一个动作：整图双头选择

    z[t] = 1{U[t] > τ}
    输出 = Q0[t] if z[t]=1 else K[t].

整图OD/OC同步选择，不拼接像素、不单独选头、不额外融合。raw先评价；post仅沿既有固定后处理，并保留独立结构指标。整图选择不能保证嵌套或结构安全。

τ尚TBD。0.5仅是“平均多数视图未支持”的可审查设计起点，不是已验证最优值或已冻结运行门。未来测量前必须选择一个阈值及依据，不能保留多个阈值评分后择优。若需要标签训练/标定阈值，须明确独立开发材料与协议；不能将其称为完全无标签方法选择，更不能占用确认集。

无论z取何值，VV的原更新均执行且状态向后传递。选择只改变最终输出，不回流q/W、梯度、Adam或下一张图像。需资格证明静态/只读支路保持学习状态、缓存和RNG；否则固定轨迹收益公式不成立。

## 5. 创新边界与最接近方法

|方法/路线|已有主要机制|本候选拟检验的差别|
|---|---|---|
|CoTTA|权重与增强平均、随机恢复|不改写入或做EMA；测量初态/入站配对编辑对动作的价值|

## 6. 最小关键对照

先做独立准入的有限机制测量，再决定是否值得完整方法确认。不一次展开大矩阵。

|对照|检验的问题|
|---|---|
|原VV与固定Q0|收益是否只是默认使用另一个输出|
|匹配动作数与流位置的随机控制|是否存在超出动作频率/时段的信息增量|
|当前熵、当前视图方差简单选择|是否只是一般不确定性重命名|
|历史新增编辑面积选择|是否仅代理编辑规模|
|去掉初态配对，仅当前状态支持|状态差异是否必要|
|去掉编辑定位，使用全图配对支持|编辑定位是否必要|

简单对照的公式、方向、阈值来源、覆盖率匹配机制、随机键与次数须事前明确；不能故意给对照更差的调参权限，也不能看结果后挑最弱对照。使用全流规则动作数构造离线随机控制只作评价工具，不包装成可部署在线算法；离线域分层亦不授权在线域路由。跨域、对象大小、编辑规模、流位置的解释检查须预定，不能事后挖最有利子组。

若形成方法M，独立评价至少有VV、Q0、NATIVE、M及自身episodic版本E-M。E-M采用相同决策/读出规则、完整清除跨内容学习状态；只比较E-VV会混入读出差异。当前信号在初态入站下E+可为空，使E-M可能退化为E-VV；这应由资格及定义如实确认，不能为制造差异临时改成更新后信号。即便M优于E-M，也不能单凭此证明选择器创新，仍须M−VV及信息对照。

论文外部基线按数据访问、源统计可用性、模型训练要求、缓存与算力分层公平比较；不能为了执行不兼容方法悄悄增加source数据/额外模型权限。

## 7. 动作价值、统计目标与医疗结构保护

在VV学习轨迹确实不变时，离线定义

    g[t] = Dice(Q0[t], y[t]) − Dice(K[t], y[t])
    G_rule = Σ_t w[t] z[t] g[t],  w[t]≥0, Σ_t w[t]=1.

未选内容贡献0。权重按预定域/头/患者/轨迹目标锁定。各头及结构另报；标签仅离线评价，不进入规则或阈值。评价必须同时包括全体净收益、相对匹配控制增量、D1误切换、所有预定域头、ASSD/HD95/vCDR、空头/NA、覆盖率、极端损失和收益集中程度。AUROC/相关性仅辅助，不替代动作净收益。

主要效应幅度、保护容忍界、覆盖率下限/集中度规则仍TBD，依据任务与功效而定；不能照搬旧+.3/−.5或以负点值直接定损害。遵循[统计声明与终态合同](GATE_SPECIFICATION.md)：预先选择点值幅度＋正收益或区间超过幅度，联合IUT与单项声明族分别处理；有效分检验和明确estimand是前提。非劣不足、损害有证据、不可评价分别记录。

旧开发内容可在另行获准的有限机制测量中使用，但不成为独立确认。患者cluster也不自动覆盖持续状态的跨患者依赖；同内容seed/order不当独立队列。若只有一份新合格cohort，优先冻结VV确认，不同时开发本选择器并在该批内容独立测试。

## 10. TMI主张与分阶段推进

期望形成的论文主线是：医学持续适应的收益/风险异质性 → 历史配对编辑信号 → 有信息的动作收益 → 独立验证与结构保护。不是“已有审计很多，所以算法贡献足够”。

1. 先审查本假设的必要测量、重复性和最小预算；材料不足保持未准入，不再扩写成可运行状态。
2. 获准后只检验单一定义的信息增量与保护；失败关闭，不训练selector挽救。
3. 通过后冻结完整M及E-M，取得与声明匹配的独立评价材料，确认收益、成本及失败范围。
4. 另一适当医学分割任务用于检验机制是否超越眼底特定域特征；不是机械凑数据集。临床结构指标按任务定义，不搬用OD/OC专用指标。

最强可争取主张是“配对历史编辑信息改善持续适应输出的使用”；不能提前声称修复错误写入、临床安全、普遍有效或TMI录用有保障。

## 11. 请Pro重点审查

- U是否提供超出当前方差/编辑面积的可辨识信息，还是一种弱置信度启发式？
- 原图二值编辑区域与入站状态是否适合预测更新后K的动作价值？若不适合，应否直接否决本定义？
- 双头等权、整图动作与D1保护是否构成难以满足的约束，而不是靠增加模块解决？
