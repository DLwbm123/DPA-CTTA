## 1. 决策摘要与版本边界

## 2. 研究范围与任务接口

目标覆盖二分类、多标签／嵌套区域分割、互斥多类别语义分割；2D图像与3D体数据共享数学接口，但3D工程与有效性未验证。暂不声称覆盖实例分割、开放词汇、交互分割或缺乏合法空间对齐的场景。

令一个决策单位为输入x，其空间位置集合为Ω，预先指定的任务前景类别集合为C。二分类只有一个前景类别；独立／嵌套标签使用各自sigmoid成员；互斥多类用softmax及既定argmax生成one-hot成员，背景是解码类别但不作为单独的信号聚合类别。类别清单不能依据真值是否出现或当前得分改变。置信度阈值、平局规则、预处理、后处理均沿任务既定定义。

**一个动作覆盖完整决策单位的全部类别。** 2D默认整图；3D目标是整volume。patch只作计算分块，不能独立路由；切片级持续更新若是基线原语义，不能伪装成同一个volume级方法。无法保持基线更新时序与整volume动作时，应限制适用范围，另行设计，而非悄悄改变协议。重复拍摄、双眼、切片、patch与患者身份分开审计。

方法允许任务适配配置，但不允许事后任务特供规则。合法增强及反变换、类别解码、静态读出、决策单位、指标必须事前选定；不把眼底六弱增强、BN-affine适应或vCDR直接搬到其他模态。

## 3. 原适应器、状态与执行时序

设B是已确定的持续适应算法，S0是其初始完整学习状态，St是当前输入到达前状态。状态包括参数、统计、优化器及影响学习的缓存，不能只把它等同于BN参数。

- P0：初态下原输入的二值／类别成员输出。
- P：入站状态下原输入的成员输出。
- K：B按原规则完成当前输入适应后的输出，所有更新与后继状态原样保留。
- Q：固定初态参考读出，在预先指定的合法视图上对齐、聚合概率并按任务规则解码。眼底实例对应既有Q0；Q不是stored-source-stat模型的同义词。

执行顺序：构造输入键控的合法视图 → 初态／入站只读配对探测 → 执行B原更新得到K与下一状态 → 构造Q及实际候选分歧 → 计算一个信号与一次选择 → 输出。独立探测随机数流不得推进B的增强RNG。探测不得改变参数、running statistics、优化器、学习缓存或未来K；含train-mode统计的模型也必须满足这一点。无法隔离则资格失败。

保留B全部更新并不免费：额外前向、状态恢复、内存和时延均计费。若B自身包含TTA读出，K按其原定义；不能为“统一接口”替换基线的预测语义。

## 4. v2.1唯一候选公式

### 4.1 类别成员的双向历史编辑

对类别c、位置u，定义原输入解码成员b0,c(u)、bt,c(u)与候选成员bK,c(u)、bQ,c(u)。

    e_c(u) = bt,c(u) − b0,c(u) ∈ {−1,0,+1}
    E_c = {u : e_c(u) ≠ 0}
    D_c = {u : bK,c(u) ≠ bQ,c(u)}
    R_c = E_c ∩ D_c ∩ Ω_valid

e=+1表示新增成员，e=−1表示删除成员。二者使用同一公式，不分别设阈值。互斥多类中A→B会同时产生A删除、B新增；这是按类别宏平均的设计，不是独立像素证据。背景→前景和前景→背景仍由前景成员变化覆盖。

Ω_valid是所有指定视图反变换后的共同有效区域。不能将填充值视为反证；必须事前设定几何资格和可接受覆盖范围，空共同支持不当作正常无编辑。R之外的编辑／分歧面积单独报告，防止裁掉边缘后虚称覆盖全部风险。

加入D仅为使观察区域与实际动作相关，并不意味着这一交集一定最优。它也可能筛掉有价值信息，必须用“去除动作交集”的一个预定消融检验；不能评分后在E、D、交集、并集中选最好区域。

### 4.2 编辑方向的跨视图未复现度

以相同视图参数、预处理与空间对齐，得到初态及入站概率p0,c^(v)(u)、pt,c^(v)(u)。定义

    m_c(p) = p_c − θ_c                         独立sigmoid
    m_c(p) = p_c − max_(k≠c) p_k               互斥softmax，竞争者含背景
    d_v,c(u) = m_c(pt^(v)(u)) − m_c(p0^(v)(u))
    q_c(u) = mean_v 1{e_c(u) · d_v,c(u) > ε_num}
    U_c = mean_(u∈R_c) [1 − q_c(u)]                 若R_c非空
    A = {c : |R_c|>0}
    U = mean_(c∈A) U_c                            若A非空
    U = 0                                        若A为空且探测有效

类别内按位置等权，非空类别间等权；不以目标大小或临床权重改信号，不增加面积过滤、置信度或幅度权重。新增／删除分别描述，但不形成第二选择器。ε_num只来自数值精度资格，不由任务收益选择。接近解码阈值的微小编辑仍然可能影响信号，是明确局限。

此U只衡量编辑方向未复现程度，不是错误概率、分割质量或Q相对K收益的估计。视图相互相关，不作独立伯努利样本推断。对未经非局部后处理、无平局的成员解码，identity精确对应原输入且裕量变化超过ε_num时才必然支持方向；单位置U上限为(V−1)/V。v2直接使用softmax单类概率差的断言已撤回：背景/A/B从(.45,.40,.15)变为(.33,.36,.31)，A成为argmax但自身概率下降。v2.1使用A裕量−.05→+.03，与成员变化一致。sigmoid固定阈值时裕量差等于原概率差。

先将各视图概率按固定空间反变换对齐，再计算竞争裕量；不能先算裕量再插值。E来自原输入raw解码，D来自候选raw解码，信号不使用填洞、连通域等post成员。softmax完全平局采用固定最小类别索引，但涉及原输入平局的编辑位置不进入R；无合格位置则不触发并单列排除覆盖。数值近零由ε_num作不支持处理，不用性能调容差。眼底六弱是原确定性旋转／翻转，不新建随机弱视图，不改变既有Q0；只有原strong风格采样保留既定输入键控。

### 4.3 单一动作与阈值语义

    z = 1{A非空 且 U > 1/2}
    输出 = Q if z=1 else K

**v2.1开发仅检验这一个阈值版本**：1/2表示活跃类别平均后，编辑方向在指定视图中未复现的比例超过一半，不表示Q胜出的概率超过一半。它不是经数据选择的最优阈值；R97开发数值资格、描述性推进门与运行协议现已单独冻结，独立确认统计门仍未定。若代数行为审查要求改变定义，先记录新版本，不能运行多个版本后择优。

不作逐类、逐像素拼接或融合。没有历史编辑时默认K；K与Q完全相同也默认K。虽然此时输出选择无收益，B仍正常更新。参考分支只参与输出，绝不回流优化、pseudo-label、缓存或未来状态。

## 6. 动作方向、价值、上界与决定是否值得采集

在R内诊断a_c=e_c(bK,c−bQ,c)。a=+1表示Q撤销该历史方向，a=−1表示Q反而携带该方向；不据此新增门控。必须报告反向比例、R/D覆盖、每次动作各类收益向量；在线保存无标签统计，收益向量在信号封存后由旧合法评分离线连接。局部TP/FP/FN可作解释但本轮不新增真值读取；Dice不拆成R内外可加贡献。

对固定轨迹、固定评分函数S及既定输入权重w，标签只在离线使用：

    g_i = S(Q_i,y_i) − S(K_i,y_i)
    G_rule = Σ_i w_i z_i g_i,       w_i≥0, Σ_i w_i=1
    G_oracle,input = Σ_i w_i max(0,g_i)
    G_oracle,input − G_rule = Σ_i w_i |g_i| 1{z_i ≠ 1[g_i>0]}

报告误切换损失与遗漏收益，不能只用AUROC、选择准确率或正收益数量。该式依赖轨迹严格不变、评分可按输入加权；pooled Dice等非可加目标不能直接套用，必须换成其自身正确的评价形式。空类别、NA、后处理和权重政策必须事前固定。

对可按类别分解的S_i=Σ_c β_c S_ic，可计算诊断放宽上界Σ_i w_i Σ_c β_c max(0,g_ic)，它不小于整输入上界。独立逐类拼接可能违反互斥或嵌套约束，因此仅是数学放宽，绝非可部署方法或合法结构收益。

另可计算受候选可触发集合A_i非空限制的上界Σ_i w_i 1{A_i非空} max(0,g_i)，区分动作本身与编辑资格限制。计算它需要合法编辑资产，不能假装仅凭K/Q汇总表已具备。整输入上界若已有逐内容配对得分则不需新概率；本次运行结果在R97报告独立记录；本文公式不冒充计算结果。

上界小到无法满足事前效应要求时关闭该动作；上界大只支持继续研究，不保证无标签可识别或局部／结构保护。上界是暴露开发材料的诊断，不加确认性显著结论；不与R90写入撤销窗口oracle混用。若每个seed/order分别允许oracle动作，明确这是更宽松的轨迹条件上界，不冒充统一输入规则可达收益。

## 7. 关键对照与创新可证伪性

所有对照共享候选K/Q、合法资产、评分范围及相当的选择权限；公式、方向、阈值来源、匹配方式在评分前锁定。只检验一个主候选，不并行搜索聚合、区域、增强、阈值及覆盖率。

|对照|必须回答的问题|
|---|---|
|B原输出K、固定Q、任务原动态基线|收益是否只是偏向某个固定端点|
|匹配动作数与流位置的随机动作|是否超出频率／时段效应|
|候选分歧D区域相对熵 H(K)−H(Q)|跨状态信息是否超出两个候选的直接不确定性比较|
|实际候选分歧面积|是否只代理“两个输出差得多”|
|当前单状态视图不一致、历史编辑面积|是否只是通用不确定性或编辑规模|
|去初态配对：同R上当前状态视图成员与P不一致率|配对方向是否比单状态证据有增量|
|去历史定位：D上配对差的方向不一致度（下式）|历史编辑定位是否必要|
|去动作交集：E上同一方向公式|D交集是否有价值，还是压掉有用信号|

去初态配对对照保留R，因R依赖历史mask，它只消融逐视图概率配对，不能称为完全无历史方法。另以候选相对熵和分歧面积提供完全不依赖历史探测的对照。去历史定位对照定义s_v,c=sign_ε(d_v,c)，其中大于ε为+1、小于−ε为−1、其余为0；在D_c∩Ω_valid上计算1−|mean_v s_v,c|，再对非空类别等权平均，空集合记0。它同时移除了原图编辑定位与原图方向参照，因此只是复合消融，不能单独因果归因于定位；这一解释限制必须保留。当前对照的阈值来源、匹配与数值资格仍待预评分冻结，不能称全部运行合同齐备。

熵定义按任务概率结构：独立标签用逐类Bernoulli熵，互斥类别用包含背景的categorical熵；主要强对照区域为D_c∩Ω_valid，对非空类别等权；全图版本仅辅助，不能评分后选择更弱者。尺度归一化及类权事前固定。实际分歧面积按至少一个类别解码不同的位置占比计算。不得在线使用域真值；域、大小、编辑规模、流位置仅作预定离线混杂解释。全流动作数匹配随机是离线评价工具，不冒充在线策略。

如果M最终优于episodic版本，仍需M−B及上述强对照说明信号贡献。episodic E-M每输入完整恢复S0，并执行相同探测／决策定义；精确配对时P=P0→E为空→z=0，因此**E-M确定退化为E-B**。经资格确认可复用等价轨迹，但探测和资格成本单列，不为制造差异修改定义。

## 10. 分阶段准入、停止条件与成本

**用户现已授权R97有限开发；执行范围和冻结门见独立[R97协议](../r97-paired-readout-v21/PROTOCOL.md)。以下是阶段顺序，不是全部已通过。**

1. 定义资格：人工构造概率与成员检查、合法视图与完整只读状态资格；先解决控制定义、空类/NA和有效区域规则。不调用真实模型就能审的部分先审，实际结果另记。
2. 动作空间诊断：若现有配对评分获准复用，仅计算预定整输入／逐类放宽上界及误切换代价描述。上界不足停止，不新增概率采集。
3. 有限机制测量：在独立预算、资产／许可与冻结对照具备后，采一次必要配对信息，只评一个版本。旧开发内容可用但结论限开发；不要求先有概率证据才能申请采集，也不无限采集。
4. 完整独立确认：前述通过后冻结M、B、Q、动态基线及E-M等对照，使用合格新材料；适应历史收益和输出选择收益分别评价。
5. 跨任务检验：在新任务与适应器上验证可迁移范围，保留失败，不自动修补成另一方法。

停止项：配对或只读资格失败；动作上界不足；不超过预定强对照；只代理域/面积/流位置；收益由少量极端输入支撑而不满足预定规则；局部／结构保护未建立；独立复现失败。停止依据、效应界、覆盖/集中度门、非劣界、功效与统计estimand仍需事前论证，不能套用旧+.3/−.5或评分后选门。失败不自动改成融合、像素路由、写入门控、阈值扫描或新teacher。

统计沿[声明与终态合同](GATE_SPECIFICATION.md)、[动作价值合同](ACTION_VALUE_CONTRACT.md)：联合IUT与单项多重性分开；点值超过幅度且区间排除零，不等于下界超过幅度。患者聚类不自动解决跨患者持续状态依赖，须明确固定流条件评价或独立流算法评价。R96既有确认协议不因本设计自动改变。
