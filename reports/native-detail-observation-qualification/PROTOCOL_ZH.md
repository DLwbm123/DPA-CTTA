# 原文件细节观测的 CPU 资格协议（运行前冻结）

独立于已关闭 E8 与决策审计。只用既有8份登记RGB文件及其identity SOURCE OD位图定位；不读GT、效用、E8分数、模型权重，不调用模型。identity唯一条件，无参数或窗口搜索。

每幅OD非空bbox中心在512格定位256窗：floor((min+max+1)/2)−128，clip[0,256]，最近16格对齐（正中向上）。对应800原文件400窗，左上坐标乘25/16，严格同物理视野。源OD只用于定位，不是真值。

N：原800 RGB裁400→bilinear512。R：原文件经既有PIL BICUBIC缩512，再bilinear还原800，裁同400→bilinear512。L：既有512裁256→bilinear512。全部torch bilinear align_corners=False。三路共同使用既有512全图identity输入的lo/span，绝不分别归一化或暗中clamp；越界比例必须报告。

先合成验证常数、双坐标仿射平面、边缘clamp、0/16/128/240/256窗及half-pixel物理中心。float64坐标误差容差1e-9像素，常数1e-12；比较坐标平面时固定剔除输出四周2像素，边缘差单列。真实像素float32；同内存数组第二次构造三路必须exact相同。RGB大小/mode不符、OD空、几何门失败或访问越界硬停，不因像素差大小调门。

公开仅8图聚合的N−R、N−L、R−L绝对差均值、RMS、最大绝对差（归一化单位；全域与固定内域分列），及共享归一化越界统计。不得公开图像、坐标、位图、逐内容值、私有路径。非零像素差不是传感器分辨率、真实细节有效性、语义信息或分割收益证明。

CPU两阶段（合成check、真实qualification）；首阶段开始时冻结原始UTC/boottime，全部修复共用180秒，不安装依赖。独立guard在170秒或新增16MiB处停止本轮身份；controller各阶段等待受剩余时限约束。预留32MiB，预计峰值<16MiB；不保存像素数组。CUDA不可见且未初始化。每轮至多这一个独立实验，不同唤醒才可能运行后续GPU轮。
