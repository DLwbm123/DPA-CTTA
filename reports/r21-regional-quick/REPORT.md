# R21：延迟原型区域纠偏短测

**本轮结论：不支持扩大这一版区域纠偏。** C+W+R 相比 C+W 为 -0.0277 pp，两个顺序分别 +0.0879 / -0.1432 pp，单图耗时增加约 23.1%。伪标签修正 299,874 个像素、损坏 302,932 个像素，净值 -3,058；低方差子集没有发生硬标签修正或损坏，因此本轮也未展示纠正稳定错误的机制证据。C+W 是本轮宏平均最高，但比 C 仅高 0.0408 pp，不能据此声称稳定优势。

该负结果限于这一固定实现及短流：不能证明所有原型纠偏路线无效，也不支持把未测的贝叶斯版本表述为有效。未自动调参、重试或扩大实验。

## 判断与边界

预先规定的值得继续条件：CWR-CW 至少 +0.2 pp、两个顺序均为正、最差域/通道/顺序不低于 -2 pp、伪标签修正多于损坏且 CWR 超过 C。未满足时仅能说有效性未建立，不调参重跑。

R 的阈值、混合系数与历史置信度均为固定工程选择，并未经标签校准；历史伪标签和冻结特征可能存在系统性偏差。本轮没有比较点原型和贝叶斯原型，也不能将 R 内部各步骤的贡献拆开归因。
