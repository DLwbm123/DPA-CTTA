# Domain-state causal A02：冻结诊断协议

## 主线决策与边界

Sparse-state A01 的 DOMAIN_ONLY 已严重退化。本轮服务于 DSR 主线：识别固定域更新的参数与 BN 写入通道，为一个最小修复提供依据；不是优化对比方法或选最高分臂。A01 固定配置保持关闭，本轮只作因果干预诊断，不声称性能晋级。不扫阈值、学习率、层、队列，不复活旧 BN-scale 方案。启发来自用户提供的 [分析](https://chatgpt.com/share/6ad9e7fe-df44-83e8-94d1-d02fcda4bf52)，实际执行依既有主线自主授权和固定资产范围。

仅原 8 内容、原 checkpoint、原 GPU。所有内容为反复使用的开发内容。两顺序各 8 内容×4 外观，每顺序重新初始化。保留 A01 原伪标签、单侧不确定图、FFT 风格记忆、两颜色通道结构遮挡、域损失、稀疏支持、AdamW、随机键及源 teacher。完全去除细化。

## 四臂

| 臂 | 稀疏参数更新 | 保留训练前向 BN buffers |
|---|---|---|
| N00 | 否，跳过 backward/step | 否，恢复 |
| N10 | 是 | 否，恢复 |
| N01 | 否，跳过 backward/step | 是 |
| N11 | 是 | 是 |

所有臂仍用训练模式执行同一域前向；不能用 eval 求梯度替代 N10。恢复全部 named_buffers，包括 num_batches_tracked。关闭参数更新者优化器状态必须为空、参数逐步不变；打开者在每次 step 后确认支持外参数不变。FFT 记忆所有臂独立同规则保留，不因关闭参数而清空。

N00 每输入 POST 逐位等于 SOURCE，且完整模型状态不变。N11 每输入 POST 逐位等于 A01 DOMAIN_ONLY 浮点输出；SOURCE 也匹配旧封存浮点输出及原 SOURCE mask。任一不符为工程失败，停止科学解释。生成端只额外准入 A01 的64个私有 measurement npz（无标签）；不准入旧评分、其他数据/模型/网络。

## PRE、POST 与封存

三非静态臂在当前输入任何更新前 eval 计算 PRE，域更新后 eval 计算 POST；两读出均不写 buffers。N00 PRE 等于共享 SOURCE，不重复调用。六份动态 logits/mask、四臂域损失、源 teacher 伪标签保存；SOURCE/N00 不重复保存全浮点。第二 worker 完整重放逐位比较六 logits、mask、损失、伪标签；不以哈希替代。完整浮点预计低于 1GiB，输出硬守卫仍限制 1GiB。

## 诊断输出和预定决策

按原内容绑定与外观权重[2,1,1,1]，分别 PRE/POST 报告 OD/OC、ASSD/HD95、vCDR绝对与有符号误差、预测/GT面积比、FP/FN占全图比例，以及相对 SOURCE/B 的结果。每个内容首次到达的 PRE（外观0）单列16到达，仍按8内容绑定，不冒充16独立患者。

固定效应：参数=N10−N00，BN=N01−N00，交互=N11−N10−N01+N00，参数存在时 BN=N11−N10。均为该流式干预轨迹下的效应，不是任意轨迹的损害分解定理。若只有BN通道明显损害，下一仅定位增强写入统计；若只有参数路径损害，下一定位伪标签/特征目标；两者损害则分别处理；主要为交互则考虑同前状态局部分叉。区间跨零不被当成等效，不能以差值较小就称安全。

旧缓存损害画像在独立 scorer 生成：SOURCE/OWNED_STATE/DOMAIN_ONLY 逐内容、顺序、到达位置，面积/FP/FN及 vCDR；源伪标签新增像素及正确率由已封存伪标签与 GT 比较。私有逐输入结果不公开，公开聚合。旧缓存分析无额外模型调用；不会按逐图结果定制策略。先前聚合总损失不能拆出 BCE/Dice/FFT 梯度，本轮也不宣称完成分项归因。必要的成分干预另行冻结，不自动启动多项全修复。

本轮不是方法竞争，不要求诊断臂都胜 B，也不宣布任何臂成为方法。未来最小修复仍需原所有 OC主门、SOURCE/B/机制强控、OD/损害/表面/vCDR、双顺序，以及持续/重置控制；不以诊断目的降低正式门。
