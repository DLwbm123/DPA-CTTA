# ISNT缘宽先验：不能作为当前逐例分割硬约束

本轮有限核查神经网膜缘宽排序I≥S≥N≥T，是否为新的可部署纠错信号。不读取当前8图、GT、模型或临床状态，不计算规则符合率、合成夹具或收益。

## 原始研究证据与层级

[2017原论文摘要](https://pubmed.ncbi.nlm.nih.gov/28947074/)可读：110名正常受试者，眼底照片缘宽评估中37.0%符合完整ISNT，OCT RNFL测量为43.8%；两种测量不能混成一种指标。其IST/IS变体照片符合率70.9%/76.4%，也不是全部正常眼的强制条件。仅核原摘要与图注文字，未读全篇正文，不据此讨论具体患者。

[2006原论文索引摘要](https://pubmed.ncbi.nlm.nih.gov/17102005/)研究规则违反与正常/青光眼区分；本次正文端点未返回可读文章，只有检索摘要，不称全文核实。[2020人群研究索引摘要](https://pubmed.ncbi.nlm.nih.gov/31959590/)同样只在索引层可见诊断敏感性/特异性，正文响应不足，未读全文、不重复取回。诊断关联不是分割校正效果，不能把这些研究当本项目的训练/校准/验证。

## 为什么当前不准入

以下为迁移判断：

1. 人群倾向不确定单眼真实缘宽。强迫杯盘mask符合正常排序，可能把真实局灶缺损或病变形态“正常化”；规则符合也不证明杯缘位置正确。本轮没有验证该伤害在8图发生，不能虚报实验损害。
2. 从disc/cup预测测出的缘宽仍来自同一预测；先验并未提供新的实测深度或标注，也不能把当前模型违反排序直接当错误标签。它不是统计分歧或P2拓扑，但独立解剖先验不等于个体正确性证书。
3. 解剖I/S/N/T要求有明确的眼侧、显示方向及坐标契约；本轮未核当前8图这些元信息，不说数据库永远不存在。不能从源mask推眼侧后称独立真值，不能新增查图/标注来填权限或从GT择方位。
4. 径向宽度、扇区面积与OCT RNFL不是同一个量；方位采样/中心/盘倾斜/异常几何需固定。没有事前完整且适用的软先验设计，不任意选罚系数或把IS/IST后选为更容易过门的替代。

当前不注册普适排序投影、规则损失或选择器，不用诊断标签/GT筛“适用样本”，不把病理约束当恢复正常形态的理由，不扫描扇区/中心/强度。已核研究足以反对“所有目标必须满足”这一运行前提，未否定全部统计先验或诊断价值。

## 旧覆盖与后继

当前src/docs/reports有限具名ISNT/缘宽/眼侧搜索未找到ISNT专用实现；不证明全部历史无等价。P2-P5已含拓扑/完整性，CS-STD讨论凸形/有序头，旧血管方法已有眼侧依赖；本规则不是这些算子严格同一实现，但也不能仅以名称不同就准入。所有旧失败保持，不复活尺寸/BN/ROI/血管/相位/ColorSharp或监督OCT。

下一继续有限机制依据审阅，优先区分观测、统计先验和诊断信号；需要个体适用性但当前无法无标签识别的规则，不作为强制纠错目标。有完整且独立任务依据才另冻协议。当前无新source/root/派发，唯一ctta30分钟和持续自主授权保持。
