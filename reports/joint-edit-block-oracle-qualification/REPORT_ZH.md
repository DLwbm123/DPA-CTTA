# 联合双头编辑块 oracle：数学资格，不是新性能结果

E4只说明现有完整候选的逐图选择空间约0.103pp，不能否定局部编辑空间。本次不读真实图像、标签、权重、位图或评分，不使用GPU；只定义下一种诊断的合法动作和精确Dice优化，避免把块内像素净纠错错当Dice收益。

## 动作必须联合两头

若以后检查SOURCE→固定TOPO_SMOOTH的编辑空间，可先对两头XOR的并集建立8连接分量；每块整体接受候选的完整OD/OC向量或整体保留源。两头不能分别oracle选标签，块不能拆成逐像素自由动作；组件只依赖两个既定预测，不看GT。这里是待冻结的具体诊断定义，不是已运行真实数据的新协议。

每个像素的输出向量始终来自源或候选。若两个端点都满足OC⊆OD，则联合安装也逐像素保包含；独立两头选择没有这个保证。该性质不保证连通性、孔、ASSD、HD95、vCDR或Dice安全，也不创造无标签正确性信号。OD-only块对OC目标精确并列时拒绝，OD和结构仍须单独报告。

## 精确最大化OC Dice，而非块内多数票

设源OC面积A、GT面积G、源TP为T，每个不相交块接纳后面积变化a_j、TP变化t_j。对二元动作s_j，目标为

`D(s)=2(T+Σs_j t_j)/(A+G+Σs_j a_j)`。

当G>0时，所有合法动作分母严格正。给定当前精确比值N/D，分式规划子问题可逐块选择`2 t_j D − N a_j > 0`，精确并列拒绝。若新总分子/分母满足`N_new D − N D_new = 0`，当前比值就是全局最大：所有动作的`N(s)−qD(s)`最大值为0。否则比值严格上升；合法动作有限，所以有限终止。不需要浮点epsilon、阈值搜索、独立像素假设或贪心多数票。不宣称任意块数都有固定/多项式步数保证。

G=0单列：若最小可达面积`A+Σmin(a_j,0)=0`，选择负面积变化块使预测为空，按既定两空Dice=1；否则所有可达输出Dice=0，拒绝全部。这里依赖块不相交、动作真可实现，不能把任意非法(a,t)列表送入而宣称mask上界。

例如A=10、G=10、T=1时，某块删除1个TP和2个FP，像素C−H=+1，却把Dice从0.1降到0；最优动作是拒绝。因此按块C−H正负筛选不是精确Dice oracle。

## 合成资格与研究边界

固定5像素域、三个互不相交块，穷举全部源/候选/GT及全部块子集，用Fraction精确比对返回值和所选mask；覆盖空GT/空源/零变化/并列/增删混合。另核联合两头安装的点值包含性质和净像素纠正反例。完整数字见FORMULA_CHECK.json；body时间只计脚本主体，不冒充完整实验进程或回填历史ledger。

这是可用于以后诊断的数学工具，不是新方法/新语义证据/性能收益或原创分式规划。**尚未测真实联合块空间，也没有证明冻结特征比logits更能判断编辑。** 不因公式通过就启动特征筛选、网络更新或记忆。若后续做块级审计，仍须独立冻结候选/联合块定义、标签可见oracle、GT访问边界、原结果parity、OD与结构覆盖，并以源及最强固定静态方案为参照；公开只能聚合，不能上传块坐标或逐内容评分。
