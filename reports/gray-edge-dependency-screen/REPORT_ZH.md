# Gray-Edge光照机制：依赖、旧覆盖与准入审阅

本轮只有有限原文和当前仓库文本审阅；没有真实RGB/GT/logits/模型读取、SSH、科学stage或GPU。结论：原始低层估计器无需训练，但当前固定模型的输入颜色校正尚无完整迁移依据，**不准入合成或真实性能执行**。不等于色恒常方法无用，也不等于任何事前参数选择都不合法。

## 来源和监督

核[作者版TIP2007全文](https://staff.science.uva.nl/th.gevers/pub/GeversTIP07.pdf)第II–V节。Gray-Edge依赖图像导数统计的无彩假设，估计单一光源颜色；低层算法不要求学习权重或运行时人工标注。论文评估使用已知光源来测角误差，不能说运行时需要该真值，也不能将光照角误差改善转写成OC分割收益。原文比较导数阶数、Minkowski阶和局部平滑，并讨论数据集相关设置。

[领域源码页](https://www.colorconstancy.org/source-code/index.html)列出作者Matlab链接；单次访问该压缩包502，未下载/重试/执行，不声称已核源码默认或Matlab parity。

## 当前迁移的独立判断

| 问题 | 已知与限制 |
|---|---|
| 信息来源 | 仍是当前RGB的确定统计读出；光照颜色假设不是新增测量，也不是解剖监督 |
| 输入物理模型 | 当前8文件的传感器线性化、响应曲线及真实照明未知；不能从PNG尺寸或显示RGB推断已满足辐射假设 |
| 标准光源 | 将估计值映射到等能白是可预设的原创操作，但未证明它接近当前模型训练时的颜色契约；没有授权新增源图像访问或校准数据 |
| 参数来源 | 文献给候选及敏感性，当前未给出无需看8图结果的唯一迁移选择。不能按GT扫描阶数/平滑/裁剪/增益 |
| 语义限制 | 杯的苍白、血管、背景和光照都可能影响统计。色偏消失不等于杯边界更准；模型置信更高也不构成真值 |
| 任务变化 | 整图颜色校正是输入干预，不是旧B→S块空间内的选择；旧空间上界不能直接当其上界或准入证据 |

不要求拿到真实光照标签才能提出任何新假设，但必须另有任务依据和完整事前设计。仅以“算法无标签、代码能运行”不能补齐当前收益假设；本次没有构造该原创设计。

## 旧覆盖与停止

当前src/docs/reports按retinex、color-constancy、gray/grey-world、chromatic、illumination等词检查，未找到具名Gray-Edge算子。这是当前checkout的有限文本查重，不证明历史等价实现不存在。旧[R61更新视图协议](../../docs/protocols/R61_UPDATE_VIEW_DIAGNOSTIC.md)已涉及强亮度/对比度/gamma/noise/blur与原输入的干预；其命题不是光源估计，故不能称严格重复，也不能换名复活旧实验。旧[R61图像依据](../../docs/R61_IMAGE_EVIDENCE.md)已经保留颜色与解剖杯缘歧义。

本候选的直接颜色校正路径暂不准入；无新具体依据不反复请求源码包或扫描光度参数。没有真实图反馈、协议、source/root或派发。持续研究转向其他有独立任务依据的有限机制审阅；所有CS-STD/phase/vessel/E8/crop800关闭配置保持，唯一ctta继续。
