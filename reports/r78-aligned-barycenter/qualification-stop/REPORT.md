# 对齐视图重心 3×2：资格通过，资源准入未通过

本次已实现三种训练目标与两种只读输出，并完成 GPU 资格检查。**正式 192 图对照没有启动：冻结的资源准入公式未通过。没有 OC、OD、域伤害或方法贡献的性能结果。** 此状态不是算法性能失败，也不是最小对照完成。

## 实现与资格结果

三组均保留原 BN-only 19136 参数、六弱视图软伪目标、W、0.1×orientation LSO、Adam 和连续状态；原头及非 BN 参数冻结。NATIVE 使用原单强视图损失；VERTEX 平均两个对齐视图的完整原损失；BARY 在对齐 logits 均值处计算完整原损失。第二视图为同一强增强张量的确定性水平翻转，不另采样增强，两分支分开以 batch size 1 前向。

O 为更新后原图概率，A 为原图及对齐翻转原图的等权概率平均。A 不反馈学习。三组分别保持一条连续学习状态，双读出不被计为两条独立轨迹。

资格来源为科学源提交 `6b0e4e9`，三组均 PASS：

- 完整学习状态重放与输出精确一致；每组可训练参数均为原 BN affine 19136。
- NATIVE 与原 CW_LSO host 的输出和完整状态精确一致；加入观察后，下一次到达仍与原 host 精确一致。
- 双读出前后完整状态、诊断不变；O 与原 sigmoid 输出一致。
- VERTEX/BARY 两个分支均有非零梯度；一次联合 backward、一次 Adam，冻结范围检查通过。
- CPU 代数、翻转 round-trip、线性头重心等价、完整依赖导入和合成 scorer/停止条件检查通过。
- 两次 CPU 准备检查均 PASS；第二次对应启动前最后代码（增加显式 head 结构、10 GiB 空闲准入与计时预留检查）。没有资格失败后重跑。

资格共 11 次更新，只访问两张既定开发图的无标签像素；在线标签与源图像读取均为零，两项访问拒绝探针生效。资格结果中的 `branches_connected=false` 对 NATIVE 表示没有第二分支；`original_baseline_exact=false` 对两个新目标表示该原基线专属对照不适用，不代表资格失败。

## 冻结预算与未准入原因

启动前冻结：聚合 GPU 进程时间 7200 秒（含资格及失败成本）、3 小时墙钟、1 GiB 输出、每 worker 8 GiB PyTorch allocator、至少 10 GiB 可用显存、资格进程上限 300 秒、CPU scorer 上限 600 秒。只允许既定两张设备，不自动扩大预算、重试或扩展科学范围。

正式准入公式为：

`最大资格步骤实测耗时 × 3456 × 1.3 + 120 GPU 进程秒`

| 项目 | 数值 |
|---|---:|
| 最大资格步骤实测耗时 | 3.306885 秒 |
| 保守正式计算投影 | 14977.174017 GPU 进程秒 |
| 资格后剩余 GPU 预算 | 7169.737532 秒 |
| 投影是否小于剩余预算 | 否 |
| 正式轨迹／更新／预测 | 0／0／0 |

因此控制器在正式 worker 启动前退出，状态为 `NOT_EVALUABLE`，具体原因为资源准入不通过。资格 worker exit 0、GPU_COMPLETE；控制器和资格 PID 均已消失，GPU 上也没有本次注册 PID。控制器退出码没有由独立父进程记录，因此不将其声明为已独立核验的 exit 1。

**14977 秒是保守预测，不是已花费成本，也不是证明完整对照实际必然需要这么久。** 公式取资格阶段最大值，其中首步包含首次执行及观察/状态处理开销；本次没有另开稳定吞吐测试、修改投影公式、增加预算或重新启动来绕过冻结门槛。资格峰值 allocated 1248.028 MiB、reserved 1356 MiB；本次没有证据表明触发显存不足。
