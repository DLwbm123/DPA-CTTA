# 读出可见性与角分区：合成代数资格（运行前冻结）

目的：检查两个潜在机制障碍，而非挽救E8或报告分割性能。E8主门、失败及迁移限制保持。

1. 固定双独立线性读出W=[[1,0,0],[0,1,0]]，八个合成三维特征，B前四像素为前景，S只将第四像素撤为背景；两候选前景/背景均至少三个像素。Q沿E8定义：各像素先单位化，再比较前景与背景向量和的余弦。拒任何零范数或零分区和，不加epsilon。
2. 只缩放第三个特征坐标1→8，W不变，所以两头logits逐像素严格相等。固定seed20261020、最多2000组整数[-3,3]合成特征，寻找两种尺度的Q(S)-Q(B)异号且各绝对值>0.001的见证。按冻结顺序取第一个；未找到也如实输出，不换seed、扩大搜索或补真实样本。
3. 核读出投影P=diag(1,1,0)下Q与原二维logits的Q一致；核补集对称性。固定见证只是存在性证书，不能估计当前源模型中问题的频率或证明其导致E8失败。
4. 数学分析一般满行秩W：P=W^T(WW^T)^(-1)W，Pf由z-b唯一恢复；任何只用Pf、W及候选mask的分数均可由同一logits与W重构，不能称新增观测。W秩退化时用伪逆同理。独立sigmoid两头不作softmax类别中心化。
