# 源相对 Dice 损害上界：无数据数学资格，尚非性能实验

## 本次结论

“按源输出似然选择拓扑修复”并不自动带来任务安全；简单有限候选版本也不是完整拓扑最优投影。但在二值输出层面，可以**不读取任何标签，精确计算候选相对源掩码的最坏 Dice 下降上界**。本次给出推导并通过标准库有理数穷举核查。

这是内部机制资格，不声称数学原创、ICLR原文结论或临床安全认证；没有读取RGB/标签/权重/真实预测，没有模型前后向/GPU/科学评分或新在线协议。

## 1. 源似然投影与旧LCC并不相同，但仍可能错

源Bernoulli logit为z，任意二值候选y的负对数似然为

`CE(y,p_source) = constant − Σ_i y_i z_i`。

所以在有限形状集合内，最小源似然损失等于最大化候选内部logit总和。若候选为“每个源前景组件分别填孔”，按logit总和选择可以区别于按面积选LCC：10个logit=.1的像素只得1分，2个logit=3的像素得6分，会选择更小但更自信的组件。前者是真主体、后者是假阳性时反而更坏；源置信度不是正确性真值。

有限组件候选也不等于完整拓扑约束下的全局最优。两个正logit=1的源岛之间有一个logit=−.1的连接像素，分别保留每岛得1分，连接两岛得1.9分。完整最优可以新建桥；受限候选不包含它。新桥可能正确也可能连接无关区域，不得把受限枚举称全局精确拓扑投影或语义安全。

因此不能只换“源似然最优”的名字重跑旧组件/填孔家族。此处提出的是可检验选择机制，不是已获准入或已部署算法。

## 2. 精确源相对 Dice 损害上界

令源掩码为S，候选为P，真值Y完全未知。定义整数：

- `A=|S|`：源前景面积；
- `d=|S\P|`：被删掉的源前景像素；
- `a=|P\S|`：候选新加前景像素；
- `c=A−d`：两者共有前景。

Dice采用空预测与空真值同时出现时为1的约定。对于`A>0`：

`B(A,d,a) = max_{t ∈ {0,…,c}} [2(d+t)/(A+d+t) − 2t/(A+a+t)]`。

那么对任意二值真值Y均有

`Dice(P,Y) ≥ Dice(S,Y) − B(A,d,a)`。

这不是把源当真值。它约束候选相对同一未知真值的Dice变化；源可以有任意错误，保证仍成立。B是紧的最坏上界，而非经验相关分数。

### 为什么只需枚举一个整数t

把像素划分为共有前景、仅源前景、仅候选前景、二者均背景四组。为了最大化`Dice(S,Y)−Dice(P,Y)`：

1. 把所有仅源前景d个像素加入Y，增加源的真阳性、降低候选相对得分，因此不减小差值。
2. 从Y排除所有仅候选前景a个像素，不减小差值。
3. 共有前景中选t个真值像素。
4. 二者均背景若加入Y只改变两者分母。在以上配置下，差值对这部分数量的导数非正：`x/(A+o+x)^2`在`x≤A`范围单调增加，而候选分母还包含非负a。因此最大值在二者均背景的真值数为0处取得。

由此得到公式。最坏真值可以构造成“全部被删除像素 + t个共有像素”，故不是只有上界而不可达。

当A=0，若a=0则两掩码相同、B=0；若a>0，空真值使源Dice1/候选0，B=1。空候选也被公式覆盖。实际使用必须核对评分器空集约定，不可默换定义。

### 无浮点舍入的快速解

令`f(t)`为方括号内表达式、`B0=A+a`。相邻差值的符号等于

`N(t)=A(B0+t)(B0+t+1)−B0(A+d+t)(A+d+t+1)`。

`N(t+1)−N(t)=−2[(B0−A)(t+1)+B0*d]≤0`，因此f为离散单峰，可用整数二分找峰。代码全部用整数符号与Fraction有理数求值，无epsilon/floor或概率标定，不靠浮点阈值四舍五入。

两个特例：仅删除时`B=2d/(A+d)`；仅添加时`B=a/(2A+a)`。同数量添加/删除的潜在损害不对称，不能仅用总编辑量代替紧界。

|A|删除d|新增a|最坏下降 pp|
|---:|---:|---:|---:|
|100|1|0|1.980198|
|100|0|1|0.497512|
|100|1|1|1.980198|
|6000|10|10|0.332779|

此界对每个独立sigmoid头可分别计算；若两头各自下降不超过同一阈值，则等权双头平均也不超过该阈值。重复图/患者独立性不是此逐掩码代数成立的条件，但实际效益的统计推断仍受重复开发限制。

## 4. 不能从这个界得到什么

- **不是增益保证。** 它可以限制损害，但也可能拒绝有益编辑、保留源错误；不能由B小推断候选更好。
- **不控制结构距离。** 一个位于远处的新增像素也可能满足小Dice下降界，却改变垂直包围盒/vCDR或表面距离；两头分别安全也不保证包含。
- **最坏真值可能很保守。** 仅删除的最坏真值可只包含被删除的小区域，实际任务未必如此；不能偷偷引入真值面积下界削弱证书。
- **不是独立信息。** A/d/a完全来自源与候选，无法说明候选纠错位置正确。先验拓扑和高置信源仍可能共同错误。
- **不认证连续概率/训练梯度/状态传播。** 这是最终二值输出相对冻结源的界；跨图参数、Adam或memory接受一个更新后的未来影响未被覆盖。
- **现有最好静态基线已经通过最差Dice损害门。** P5最差约−.07067pp，明显好于−1pp的已有门。因此不能只对已知严重失败的P4做拒绝，然后宣布此界解决了尚未解决的ASSD/边界收益问题。
