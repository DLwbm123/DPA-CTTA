# X/F 实际更新幅度匹配：完成报告

本轮支持“原步幅过小压制了 X 的局部效用”，但仍未建立 X 相对强基线的独立优势。等幅 X 相对原步长 X 提升 **0.056810 Dice 百分点（pp）**，描述性 95% 区间 [0.004830, 0.108761]；相对 F 仅提升 **0.013317 pp**，区间 [−0.001694, 0.028938] 跨 0。X 与等幅纯几何 P 几乎一致，且低于直接修正 D。本轮既定路线投资门槛未通过，完成后停止，没有追加幅度扫描、训练或种子。

## 实验与实际步幅

执行前冻结的[协议](PROTOCOL_ZH.md)固定了 12 方法、8 个不重叠图像内容对、4 条件及 3 种读出。复用上一轮已选定的 X/P/F episode 100、S/D episode 150，骨干及数据不变，无新训练或额外监督。仅更新 up3 BN 的 512 维仿射状态；每动作从源状态初始化，query 只读，无跨步骤统计累积。RDC 和 ENGRAM 均关闭。

对每个更新输入 s，先得到 F 的实际更新 a_F，再令 a_MATCH=a_raw×||a_F||₂/||a_raw||₂。该标量仅来自更新输入，不读取 query 标签或评分；FP64 计算缩放后落为实际 FP32 状态。零半径和退化方向按冻结规则处理。本轮 672 个匹配状态全部通过，最大绝对范数误差 **4.674×10⁻¹⁰**，最小方向余弦 **0.9999999999999992**，没有跳过非零方向。

下表为主读出 CROSS_MATCH 的均值，像素数是 OD/OC 两通道合计、每 query 的硬预测变化数。

X 的逐输入倍率平均 **194.54**，范围 170.88–232.95；对应原 .01 步长的有效步长平均约 1.9454。这是逐次归一化，不能概括为一个固定最优学习率。32 个 query/条件读出总变化像素由 12 增至 2,030。任务指标也有改善，因此不只是“动得更多”。但等参数范数并不等于等函数变化：X_MATCH 的 logit RMS 约比 F 大 16.6%，函数空间混杂仍存在。匹配分支还需要 F 提供半径，属于冻结头诊断，不能当作无额外成本的独立部署方法。

但收益尚不能归因于图像条件模块：X−P 仅 +0.000044 pp，HD95 和 vCDR 的聚合结果相同；X−S、X−C_A 的区间也跨 0。优于反向和本次固定随机方向，支持当前方向具有局部效用，不能推出优于所有随机方向。D 仍高出 X 0.131767 pp，53/64 单元落后于 D，区间完全位于 0 下方。原主比较没有更换，不能因某个较弱控制落后而宣布成功。

SELF、CROSS_MATCH、CROSS_MISMATCH 的 X Dice 分别为 85.409200、85.406555、85.406121；同图略高，匹配与错配仅差约 0.000434 pp。三个读出对 F 的区间均跨 0；对 P 的均值差为 +0.000094、+0.000044、−0.000126 pp。这些结果没有建立有意义的条件匹配或跨图迁移增益。

## 收益与损伤同时存在

相对 B0，X_MATCH 平均 +0.056862 pp，原图条件 +0.055891 pp；13/64 单元下降，最差 −0.194018 pp。相对 F 则 20/64 单元下降，最差 −0.060121 pp。所有方法无空预测；每个方法/读出表面指标覆盖 64/64，vCDR 覆盖 32/32。X 的 ASSD、HD95、vCDR 平均优于 B0/F，预定原图、尾部、空预测和结构安全检查通过。

## 执行证据与结论边界

源代码冻结提交为 `ada9cbb9def0b63e6281ac54efecf4b42b042500`。1,024/1,024 读出完成；352/352 个不变基线重新生成并与前轮预测完全一致；672/672 个幅度匹配通过。4 项 CPU 测试通过。GPU worker 拒绝源标签、评估标签及前轮最终评分，评估仅在其成功退出后由独立 CPU scorer 读取。两个 worker 退出码均 0，均已退役，无失败尝试、重试或新增训练。

GPU worker 进程用时 84.038 秒，CPU scorer 进程用时 107.260 秒；另有远程 CPU 资格检查 1.899 秒、本地检查 0.847 秒。峰值 GPU 已分配内存约 0.702 GiB，新增输出 67,735,949 bytes。共享计算下的分支时间戳不能用于逐方法速度排名。详见[执行审计](EXECUTION_AUDIT.json)、[成本](RESOURCE_LEDGER.json)、[匹配](MATCHING_AUDIT.json)、[访问](ACCESS_AUDIT.json)、[机器结果](RESULTS.json)、[函数变化](DIAGNOSTICS.json)和[全条件通道表](condition_channel.csv)。

用户已授权图像内容隔离开发实验；本轮复用了上一轮已评价的 8 内容对，患者关联及骨干预训练暴露未知。区间不构成患者独立性或临床显著性证据，也没有连续流、遗忘或 CTTA 累积验证。冻结头原先按原步长训练，本轮只改变推断幅度，不能据此判断等幅元训练的结果。

**最终判断：步幅过小确实是上一轮的一个有效解释，但不足以解释或建立 X 的方法优势。** 主均值 +0.5 pp、主区间下界>0、对全部强方向均胜三项投资门槛均失败，因此本轮不支持把图像条件损失或跨图机制直接提升为 TMI 主路线。报告保留全部负结果，实验到此结束。公开交付仅含代码、配置、匿名聚合指标及审计；图像、标签、权重、逐图预测/评分和标识不发布。
