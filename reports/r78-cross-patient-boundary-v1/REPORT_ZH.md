# 内容隔离边界目标小规模对照：完整结果与停止决策

2026-10-18。**COMPLETE / 开发门槛未通过 / 不进入 CTTA 长流。** 9 个固定方法、5 个训练分支、1,000 次外循环和 736 个最终读出均完成；GPU worker 与独立 CPU scorer 都以 exit 0 退出，controller 已退出。RDC 和 ENGRAM 始终关闭。

## 结论

唯一预定主比较 CROSS_MATCH 的 **X−F = -0.043494 Dice 百分点**，描述性 95% 内容对 bootstrap 区间 [-0.081492, -0.005508]。它既没有达到预定的 +0.5pp，也没有胜过前馈预测器。X 相对不更新基底只有 +0.000051pp，基本等同于不更新。**本轮不支持把这一版学习损失及跨图像内循环作为 TMI 主贡献继续扩展。**

这不是“所有学习损失均无效”的证据。主要限制是当前固定步长下 X 的实际更新非常弱；同时没有观测到图像条件化或跨图像训练的实质收益。完整保留这两个解释，不以临时调步长或追加训练来改变本轮结论。

## 数据与证据边界

用户明确授权将原患者隔离设计改为内容隔离开发实验。官方下载页、原始压缩包 README/目录和数据库论文没有提供可据此核验的患者对应表；论文将文件中的 K 定义为图像编号。这里只证明已登记图像内容不跨子集，患者依赖和源骨干预训练成员关系仍未知。

40 个源内容划为训练 16、验证 8、最终 support 8 / query 8，形成 8 个互不重叠的内容对。源分割标签用于训练与验证；最终 8 个 query 标签只由 GPU worker 成功退出后的 CPU scorer 读取。worker 访问 40 个源图像、24 个训练/验证标签文件，最终标签和目标域图像/标签读数均为 0。不是 736 名患者，也不是医院外验证。

所有方法对同一 32 个 query 输入评价；原图、范围外 gamma、范围外 RGB 增益和训练未包含的模糊族全部保留。条件在原生 min-max 后确实改变模型输入。成像干预是人工可控条件，不冒称真实扫描仪变量；CROSS_MATCH 是离线配对效用诊断。

## 为什么当前版本没有竞争力

1. **实际适配幅度不匹配。** X 的 CROSS_MATCH 状态 L2 范数均值为 0.00025861；F 为 0.05000000，约相差 193 倍。二者同为 512 维并共用 0.05 最大半径，但不代表它们实际走了同样远。C_A 的平均范数更小，为 0.00003609，最终硬掩码完全不变。这削弱了对“损失信息价值”的强因果解释；当前实验直接否定的是固定设置下的竞争力。
2. **X 几乎未改变输出。** 32 个 CROSS_MATCH query、两个通道、512² 网格中，X 合计只相对 B0 翻转 12 个像素；21/32 个 query 的硬输出完全不变。它通过尾部安全门槛，很大程度上来自几乎不动，不能解释成主动保护病理结构的能力。混合导数、正负方向与实际 512px 模型接口检查均通过，源训练外循环梯度也存在，因此不是把内循环完全 detach 的实现假象。
3. **没有显示共享成像条件的特异价值。** X 的 MATCH 与 MISMATCH Dice 完全一致；F 的差只有 +0.00002787pp。SELF 和跨图像 MATCH 的差也极小。不能据此宣称已经学会可跨患者迁移的采集因素。
4. **简单强控制更值得警惕。** D 的 Dice、ASSD、HD95 与平均 vCDR 均优于 X，说明额外源监督可能由直接修正头更容易利用。F 的头为 12,336 参数，X/P/S/D 为 3,649 参数；它们匹配的是源内容池、标签访问、选择次数、适配状态上限，不是参数量和 FLOPs 完全相等。

还需限制对 D 的解释：在两个解剖通道的真值前景中，D 的错→对比例均为 0，原本对→错的宏比例分别约为 OD 0.0545%、OC 0.1792%。因此观测到的纠错来自真值背景上的假阳性移除，同时损坏了一些真前景；这不能证明它获得了双向边界修复能力，更不能把小幅 Dice 增益当成病理结构保留。该分析与预定前景/边界分区指标一致，不引入新评价集或改换主比较。

预定主门槛、主区间门槛和“X−P/S/D/H 全为正”门槛失败。X 的原图平均变化为 +0.000216pp，最差内容×条件×通道相对 B0 为 -0.006404pp；无新增空盘/空杯。所有方法表面指标 64/64、vCDR 32/32 有定义；X 的 vCDR 与 B0 完全相同。像素改正/损坏在全图、真值前景、3px 真值边界分别保存在 [transitions.csv](transitions.csv)。这些安全读数不抵消收益门槛失败。

## 工程、成本与局限

7 项合成检查通过，并在实际随机初始化 ResUNet 上确认 512 维接口、混合导数；服务器 CPU 检查确认零状态与原宿主输出一致、完整 CW_LSO 恢复后重复一致、六弱视图/强视图/读出共 8 次原生前向。首次宿主诊断字段索引错误在训练前修复，失败 CPU 检查成本保留；只有一次 GPU 实验，没有科学调参、追加 seed 或缩减对照。

GPU worker 总进程墙钟 240.245s（包括进程启动），独立 CPU scorer 178.878s；远程 CPU 资格检查含失败共 141.893s。GPU worker 的新运行输出约 46.6 MiB，峰值 allocated 约 1.20 GiB，低于预定 3,600s GPU / 900s CPU / 2GiB 输出边界。记录的合计 CPU worker 成本约 349.769s，另有少量未计时的准备/传输失败；不把墙钟进程秒称作 GPU kernel 秒或受控速度比较。详见 [EXECUTION_AUDIT.json](EXECUTION_AUDIT.json)、[RESOURCE_LEDGER.json](RESOURCE_LEDGER.json)、[COUNTS.json](COUNTS.json)。

每分支固定 200 次双向 episode / 400 次 query 标签监督；每 50 次按同一源验证准则选 checkpoint，没有用最终标签选择模型。所选 epoch、所选验证汇总和每 25 episode 聚合训练曲线公开；未保留全部四次验证的完整时间轨迹，因此不能事后重建每个候选 checkpoint 的所有验证输出。仅一个训练 seed、八内容对、未知患者关联与骨干暴露，所有区间仅作描述性开发不确定性。
