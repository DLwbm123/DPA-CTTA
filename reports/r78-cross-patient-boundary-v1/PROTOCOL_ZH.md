# 一轮小规模对照设计：边界目标能否产生跨患者有用更新

2026-10-18。**原始设计，以下修订获得用户明确授权。** 它检验 路线决策 的必要条件，不直接宣称真实医院 TTA／CTTA 或 TMI 方法已成立。

## 1. 本轮只回答一个主问题

同样源图像、分割监督预算和小适配状态下，**图像条件、跨患者训练的无标签边界目标 X，是否比直接从相同输入生成适配参数 F 更有用？**

同时检查：图像信息是否必要（X 对 P），跨患者训练是否必要（X 对 S），反传是否只是另一种直接修正（X 对 D），以及手工图像目标是否已足够（X 对 H）。这些控制不能在结果出来后删掉。

首轮不再采用“只往 CW_LSO 添加新损失后跑短流”的设计，因为 R66、R73 已暴露信息质量与更新效用不同。先在患者可核验的源材料上检验学习目标，既不使用目标测试标签选型，也不靠长流掩盖机制失败。

**RDC、ENGRAM 均关闭；不增加 CSDR、扩散教师、VLM、拓扑优化或新的记忆库。** 现有 CW_LSO 仅作独立参考，不与候选叠加。

## 2. 数据资格与固定规模

### 2.1 必须先满足的条件

- 已有合法来源、允许本次训练使用的源图像和 OD/OC 分割标签；历史协议中的有限引用例外不自动扩大为训练许可。
- 可核验患者／双眼／重复检查分组。要求至少 **40 个患者组**：16 训练、8 验证、16 最终机制评价，组间不相交。若原骨干训练曾见过某组，必须披露；要主张端到端未见患者，最终组还必须与原骨干训练组不相交。只做到适应模块隔离时，结论限于该条件。
- 同一患者的多张图像不跨组；首轮每组固定一张，按既定无标签排序选取，不按掩码大小、损失或难度挑图。
- 使用已有源 ResUNet 的确定 checkpoint、预处理和原生 512×512 接口；先核实 up3 BN 的仿射维度、梯度接口和归一化语义。

这些是运行前资格要求，**当前尚未核实已具备 40 个合格患者组**。缺一项就不启动依赖该项的训练，不自动退化成“跨文件就是跨患者”。也不从反复暴露的目标 SEARCH/REVIEW 中另划一个“新测试集”补足数量。

### 2.2 配对

训练每 episode 取两个不同患者 i、j，以同一个外观条件 c 生成各自图像；若有随机噪声，只共享噪声强度，不共享逐像素噪声实现。两方向 i→j、j→i 都形成一个监督 query，保证每个训练分支每次都获得两个患者的标签监督。

验证 8 个患者组成 4 个不重叠 support/query 对；最终 16 个患者组成 **8 个不重叠对**。患者按冻结随机种子排列，前半 support、后半 query 一一对应，不按解剖或疾病标签匹配。各条件沿用这 8 对，bootstrap 以整对为单位，避免把共享 support 的相关性漏掉。

## 3. 成像干预：不使用会被预处理消掉的假变化

宿主有逐图 min-max 处理，单纯全局仿射亮度／对比可能被抵消。因此不把原始像素发生变化等同于模型实际看到域偏移；资格阶段检查处理后的输入确实变化。

训练 episode 在四类条件中等概率抽取：

1. 原图；
2. gamma，指数均匀取 [.85,1.15]；
3. RGB 三通道独立 gain，各均匀取 [.9,1.1]；
4. 独立高斯噪声，标准差均匀取 [0,.02]。

外观操作在既定裁剪／解码之后、模型原生归一化之前执行，结果 clip 到 [0,1]。没有几何变换，分割标签位置不变。保存具体实现、处理后变化幅度与随机状态；不把共享合成 c 称作真实医院或扫描仪变量。

最终评价固定四个条件：C0 原图；C1 gamma=.7；C2 RGB gain=(1.15,1,.85)；C3 高斯模糊 σ=1.0、7×7 核、reflect padding、逐通道执行。C3 是训练未包含的扰动族，C1/C2 是范围外参数，而不是新的扰动族。四种条件都运行，不按结果选择。

验证使用训练分布内的固定原图、gamma=.9、RGB=(1.08,1,.92)、噪声 σ=.015；不能用最终的 blur 条件挑 checkpoint。

## 4. 共同适配对象与能量

### 4.1 状态 a

核心对照只改变 up3 BN 的 scale/bias 偏移 `a=(Δγ,Δβ)`，预计 256+256=512 个坐标，实际维数须核实。原有卷积和其他仿射参数冻结。归一化统计均使用与当前图像宿主一致的方式，不新建运行均值或隐藏历史；无梯度的 query 前向也不更新权重或优化器。

每个 episode 从 `a0=0` 开始，做 **一步 SGD，η=.01**；将结果投影至 `||a||2≤.05`，零梯度保持零。此步长与边界是本设计的固定筛查值，不来自论文有效性证据或源验证调优；不扫描它们。X、S、P、H 共用这条更新，F 输出相同状态球内的 a。

完整 CW_LSO 参考保留其原 BN 参数集合、Adam、W、LSO、GraTa 更新及输出时机；与 512 维候选的差异明确报告，不能用其对比单独证明损失贡献。

### 4.2 共同几何接口

以参考 a0 的 logits 双线性缩放到 256×256 虚拟网格，逐通道定义 `ψ=-z`，参考分母 `h=max(sqrt(||∇ψ0||²+1e−6),.1)` 停止梯度，`d_a=−z_a/h`。法向取参考 d0 的中央差分方向；法向范数不超过 1e−6 的位置不作为 anchor。

选 `|d0|≤1` 且所有采样位置离图像边缘至少 2.5 虚拟像素的 anchor。每通道至多 128 个，按行序在合格位置中等间隔选取；不以真值或 δ 大小挑选。每点取 ξ∈{−.5,0,.5}。权重使用参考 `4q(1−q)`，杯通道再乘参考盘内 gate `sigmoid(−d_OD/.5)`，全程冻结。各支路使用相同构造，不学习新的可靠性 gate，不添加 Eikonal。

没有合法 anchor 的通道贡献为零；整图没有则 H/P/S/X/F 保持 a0，不删除该病例。记录空支持率。参考权重仅为定位候选的归纳偏好，不是正确性证书。

### 4.3 X 的相对边界目标

输入为 `[标准化RGB(3), 图像梯度幅值(1), q_c(1), clip(d0_c,−3,3)(1), n_x(1), n_y(1), 通道标记(1)]`，共 9 通道。参考预测与几何对 a 的依赖冻结。固定小网络：3×3 Conv 9→16、ReLU、3×3 Conv 16→16、ReLU、1×1 Conv 16→1，最后层零初始化，以 tanh 输出 `δφ∈[−1,1]`；两解剖通道共享参数、通过标记区分。

在固定参考采样坐标 s=x0+ξn 上，定义

`Eφ = Σ w·smoothL1(d_a(s)−d0(s)+δφ(x0,c)) / Σw`。

smooth-L1 使用 β=.5，各有效解剖通道等权；全空贡献为零。不通过 argmax、选点或参考分母反传。δφ 对 φ 必须可微：冻结参考不是把学习目标整体 detach。δφ=0、a=0 时辅助梯度应为零。δ>0 倾向使局部 d 降低，即向外移动，梯度符号必须验证。

此式为针对本轮的迁移设计，与 SRDF 原来拟合 `d(s)=ξ` 不同；去除了参考场不够像距离场时的额外初始几何正则。它不复现 SRDF，也不借用其原 λ、EMA 或 warm-up。

## 5. 九个固定方法、五个训练分支

|ID|定义|回答的问题|
|---|---|---|
|B0|同预处理／归一化、a=0 的固定权重基底|无需学习适配的参照|
|C_FULL|完整 CW_LSO，每 episode 源初始化|现有系统参照；与新候选信息／容量不同|
|C_A|同 a 与一步 SGD，使用 W 加权 BCE＋0.1 LSO 一致性目标|常规无标签目标在相同适配容量下是否足够；这是 matched-capacity control，不是原 GraTa 复现|
|H|同 a／SGD／相对能量，δ 来自 SRDF RGB/梯度两侧带评分|手工边界证据是否已经足够|
|P|独立训练能量，只有预测／几何输入，跨患者外循环|图像证据是否必要|
|S|图像条件能量，同患者 support/query 源训练|跨患者配对是否必要|
|X|图像条件能量，不同患者共享外观条件源训练|核心候选|
|F|相同图像／预测输入直接输出 a，跨患者 query 监督，无内循环反传|学习损失和在线反传是否必要|
|D|相同局部输入直接预测有界修正场，query 图像源监督，无适配状态|是否只是一个有额外源监督的修正头|

H 保留同一 anchor／权重和相对目标，只借原 Ribbon 的 δ 生成：候选 {−1,0,1}，两侧偏移 {−1.5,−.5}/{.5,1.5}、切向 {−1,0,1}，比较跨侧差异与侧内变化；并列最高时优先 δ=0，其次较小绝对值再固定索引。原 r 评分差不另作权重，以免 H 与 X 同时改变方向和支持。虚拟 1px 约对应模型输入 2px，不当作固定物理长度。

P 从第一步就独立训练，四个图像通道固定为零，其余网络形状相同；不是把已训练 X 的图像抹掉就当一个公平基线。S 每个双向 episode 用 i→i、j→j，与 X 的 i→j、j→i 保持患者图像与标签访问数一致。

F 使用同样固定的两个宽 16 卷积层，再空间／解剖通道平均池化与线性层输出 a；零初始化输出层，使用与 X 一样的 L2 状态球。D 用与 X 相同的小卷积结构生成 δ_D，直接在参考场对应位置给 logits 添加 `h·δ_D` 的局部残差，再插值回 512 网格；只在共同边界支持作用。所有尺寸在实现时写出准确参数量，不宣称结构不同却“参数完全相同”。

C_A 的六弱视图／强视图沿用宿主对齐方式，W 和 LSO 公式原样，但一步采用本轮 SGD，不引入 GraTa 熵扰动或余弦学习率门控。C_FULL 独立保留真正原方法，避免把改过的控制命名成原算法。

## 6. 源训练预算与选择

P/S/X/F/D 各训练 **200 个双向 episode**，共 1,000 次外循环优化；每分支每次两个 query 标签，合计 400 次分割标签访问，不把相同标签的不同像素当独立样本。

- 外循环损失为解剖通道等权的 BCE＋soft Dice；五个分支均可访问相同源患者池、同一对 i/j、同一扰动参数和监督数量。D 对 i、j 各直接监督，F/X/P 做跨患者监督，S 做同患者监督。
- 小网络使用 Adam，lr=.001，betas=(.9,.999)，eps=1e−8、weight decay=0；FP32，一种初始化 seed=20261018；骨干不训练。
- 仅在 episode 50/100/150/200 上验证。共同源验证准则为匹配条件、跨患者 query 的宏 Dice；D 直接评价 query。选最高者，完全并列选较早 checkpoint。没有 LR、步数、宽度、半径或种子搜索。
- F、D 的运算与 X 二阶训练不同；源患者／标签访问、选择次数相同不等于 FLOPs 相同。分别报告前反传次数、时间、显存及部署成本；不靠给简单分支空耗算力来制造“等计算”。

源训练中混合导数必须贯通 `φ→∇a E→a'→query loss`。不能只训练能量数值或把内循环更新 detach 后称 meta-learning。固定坐标双线性采样优先用四点 gather＋常数权重实现，避免坐标学习触发不支持的 grid-sample 二阶导；须用一个小型有限差分检查混合导数。此检查属于工程资格，不是科学增益证据。

## 7. 最终固定读出：736 个，不跑长期流

8 个 query 患者 × 4 个最终条件 =32 个固定 query 输入。每对的 support 与 query 始终不重叠。

对 H/C_A/P/S/X/F/C_FULL 七个会产生适配参数的方法，分别评价：

1. **SELF**：query 自身计算更新再输出；对应 episodic TTA。
2. **CROSS_MATCH**：support 使用与 query 相同 c 的更新，query 只读输出。
3. **CROSS_MISMATCH**：query 固定不动，support 条件按 `Ck→C(k+1 mod 4)`，只读输出。

每方法 32×3=96 个读出，七个方法共 672。B0、D 直接评价 32 个 query 输入，各只生成一次，共 64。总计 **736 个最终预测读出**；训练／验证前向单独计成本，不混作 736 的测试证据。重复条件共享同一 query 内容，不能当成 736 名患者。

每个动作独立从相同初始模型／适配状态开始。Query forward 可以计算其自身的归一化响应，但不反传、不写优化器或运行统计；不得误把 query 读出触发的隐藏状态变化当迁移。没有目标域／周期／病理标签送入算法，也没有 future-case 查询。

这是受控源条件的机制实验，不是自然患者流。CROSS_MATCH 是带显式配对的离线效用诊断，不能冒称部署时已经能无标签识别哪两个患者共享 c。

## 8. 固定指标、判定与失败解释

### 8.1 主指标

`CROSS_MATCH` 的 query Dice，OD/OC 等权、四条件等权、八对等权，报告百分数及百分点。

**唯一主要比较为 X−F。** 将 X−P、X−S、X−D、X−H、X−C_A 和 X−C_FULL 一并报告，不按结果换主要比较或选择某一个“最强基线”再解释。原图 C0 单独报告，不被其他条件掩盖。

Bootstrap 2,000 次、seed=20261018，以八个互不重叠患者对为簇，四条件、解剖通道、所有方法和三个读出绑定。区间仅是该小开发机制集上的描述性不确定性；八簇不足以证明临床或跨医院显著性，训练单 seed 不支持训练稳定性主张。

### 8.2 预定继续筛查门槛

以下是本轮建议的工程筛查条件，**不是临床最小重要差异**，且本轮尚未按其运行：

- CROSS_MATCH：X−F 平均至少 +.5 Dice pp，配对描述性 95% 区间下界 >0；
- X−P、X−S、X−D、X−H 的平均均 >0，所有对比区间与负单元完整展示，不声称这些未调整次要区间建立同时显著性；
- C0：X−B0 平均不低于 −.2pp；任何 query 对×条件×通道的 X−B0 不低于 −1pp；
- 不新增空盘／空杯预测；有效表面距离和 vCDR 分母覆盖不能降低。vCDR MAE、表面指标及尾部损害须与 Dice 一起解释，若其方向与“结构保留”冲突则不推进该主张。

若差值小或区间过宽，结论为证据不足，**不是自动加 seed、加 episode 或放宽门槛**。即使满足这些开发门槛，也只支持投入下一阶段，不作 TMI 有效性结论。

### 8.3 机制／损害指标

- SELF 与 CROSS_MATCH 的差，区分修自己与迁移别人；CROSS_MATCH 与 MISMATCH 的差检验外观条件特异性，但不硬性要求错配必然变差——若不变，不能声称识别了特定成像因素。
- 原本错→对、原本对→错的像素比例；全图、真值前景和固定 3px 真值边界带分开报告，真值区域仅 scorer 使用。
- 原生 512 网格上的对称表面平均距离与 HD95，单位 pixel；空预测／空真值按预先约定返回 NA 并披露全部分母，绝不填零。主要 Dice 保留所有病例，不因表面指标无定义丢病例。
- vCDR 按杯／盘竖直跨度比计算，与面积比严格分开；盘跨度为零记未定义、报告计数并触发上面的空预测门槛，不用有限子集的漂亮均值遮掉失败；不裁掉超过 1 的不合理比值。
- signed δ、饱和率、空 anchor、实际 a 范数／投影触发率、模型输出变化及 BN 统计模式；显示目标有变化是否真正产生了参数与任务变化。
- 原生基底掩码附近与真值边界附近的诊断区分，不能只展示有利目标 ROI；不以 uncertainty enrichment 或预测更自信替代增益。

## 9. 实现资格、预算与结束规则

启动前必备的最小工程检查：

1. 身份与接口：正确 checkpoint、合格分组、参数名／维度；核心方法仅 a 更新，query 只读；完整 native 参考与保留宿主一致。
2. 禁用 parity：零 δ 辅助梯度为零、零适配为基底；固定相同输入／状态可重复；空支持安全且不删除病例。
3. 方向与 meta 信号：用简单解析边界核对 δ 正负及图像坐标；小型有限差分核对 φ 的混合导数；P 确实未接收图像通道，参考与标签不能意外流入部署输入。
4. 随机与选择：所有分支共享预先生成的患者 episode 和外观参数；附加计算不改变 native 的增强随机流；源验证可选 checkpoint，最终评价标签不能进入任何选择、停止或门控。

建议总上限：**单 GPU worker 3,600 wall seconds、独立 CPU scorer 900 seconds、运行输出 2GiB**，含失败和工程资格消耗。用最初少量训练步测量后保守估算五个完整训练分支＋所有验证＋736 读出是否可容纳；不够就停止准备并修改下一版计划，不能跑到一半减少对照或训练轮数。当前没有实测速度／显存，不能承诺时间内完成。

运行时服务器／GPU／挂载及中性进程名按全局指令；预计超过 30 分钟则可靠后台启动并短检，无默认持续监测。只在全部生成分支结束后启动独立最终 scorer。原始标签不挂到部署代码路径；源训练与源验证标签各有明确权限，最终标签 scorer-only。
