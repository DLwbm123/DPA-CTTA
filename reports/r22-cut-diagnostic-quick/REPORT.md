# R22：区域相对 cut 判别短测

**结论：当前 model-only 因果 cut 版本未建立有效性，不进入 RN-DPO 或纠偏训练。** cut 排序 AUROC 为 0.5333，低于置信度的 0.5600；固定选择规则在两个顺序均损害候选质量，平均伪标签 Dice -5.2452 pp，净损坏 804,513 个像素，其中低方差子集净损坏 409,694 个。

候选并非完全没有互补空间：按真实区域错误数事后选择可得到 79.5201% 的候选 Dice，而学生候选为 76.5757%。这支持“当前瓶颈在可靠性判别”的解释，但不是根因证明，也不能据此否定原版 SafeCut。本轮无标签调参、无自动追加训练。

执行状态：COMPLETE；预先规定的信号：**NOT_ESTABLISHED**。

本轮只检验判断器。两次 C+W 基线重放没有接收任何判别器反馈；所有 384 次最终硬掩码均与 R21 原结果逐次相同。下方 Dice 属于当前伪标签候选的直接选择，不是训练新方法后的分割性能，也不可与 R21 的最终输出 Dice 直接比较。

AUROC 的正类是源候选在整个区域的 OD/OC 总像素错误数更少；分数越大越偏向源候选。三个规则使用相同可用区域和固定 0.05 阈值，但 cut、概率、熵的尺度与覆盖率不同，不能仅凭选中数量比较优劣。confidence 使用所预测类别的概率；entropy 使用三类熵（nats）。

有明确优劣的可用区域中：源候选更好 1339 个，学生候选更好 1875 个。按区域像素错误数事后选择的 oracle 净修正空间为 913,776，其中满足可用条件的空间为 850,094。全背景/结构删除保护触发 22 次到达。

oracle 使用真实标签，仅作为候选互补空间诊断，不能部署；它最小化区域像素错误数，不能声称是全局 Dice 的数学上界。低方差阈值为六弱视图方差 <=0.001。硬 Dice 使用 1e-6 平滑；宏平均为域、OD/OC 通道、顺序等权平均。

## 固定实现与边界

使用同一 checkpoint 的冻结 up3 特征，32x32 查询 token、过去八张图像各 16x16 记忆 token。两候选共享 mutual-16-NN 图，余弦距离权重温度 0.1；当前图像处理后才入库，至少两张历史图像。分歧区域至少一半位置有四个互为近邻；若源候选会删除学生已有的整个 OD/OC 结构则放弃纠偏。三种分数均只影响保存的候选选择，不影响模型更新。

SafeCut 原论文的额外互补模型、整目标集跨 epoch 统计与这里不同。本轮的同源候选和有限因果图不能继承其有效性保证；空间降采样、历史模型变化、域切换和背景比例仍可能影响 cut。历史 SEARCH 已暴露、单种子、患者关联未知；不能作独立泛化结论。

预注册通过条件：至少 100 个有明确优劣的可用区域；cut AUROC >=0.6 且不低于两个简单依据；两个顺序均有正的净纠错和宏 Dice 变化；低方差净纠错为正。未达到时不调参、不扩展、不训练后续方法。

实测墙钟 3.22 分钟，GPU worker 累计 5.09 分钟（含初始化与 I/O）；每图重放加诊断 0.724 秒。代码提交 `e4f6d8a`。
