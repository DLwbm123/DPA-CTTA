# VV 能否作为 TMI 主方法：算法、机制证据与验证缺口

2026-10-21。**DOCUMENT_REVIEW_ONLY；没有启动新实验。** 用户要求先围绕VV本身判断，而不是继续叠加R100。本文以当前源码、已交付实验和一手文献为依据，不修改旧门槛，不把开发结果改称独立确认。

**判断：VV值得作为主方法候选保留，并优先梳理；但现有证据还不足以认定它具备可投稿TMI的方法创新和验证强度。** 约1pp增益是真实可复核的开发信号，且存在有内容的历史机制分析；主要缺口是双视图训练相对成熟一致性方法的实质创新、外部强基线公平比较、独立数据验证。不是因为方法简单就不成立，也不是再加模块才有资格。R97失败不否定VV；R100保持未运行，不作为VV必须附加的模块。

## 1. 首先纠正 NATIVE 的身份

这里NATIVE不是“未经修改的官方GraTa”，也不是冻结推理。源码链为 `r85_migration → r79 → r78 → r37/r36 → r20 → b1_host`：r78选r37的CW_LSO配置；r37令host=C、学习率倍率1；r20的C是普通一致性Adam路径。NATIVE已包含项目内W加权和0.1方向LSO，只对一个strong分支计算损失。VV在此基础上增加同一strong的水平翻转分支，并逐视图计算损失后平均。

因此VV−NATIVE约1pp支持的是相对**项目内单强视图CW+LSO**的增量，不能直接写成VV优于官方GraTa约1pp。GraTa的官方方法包含梯度方向与动态步长设计；代码沿用其部分数据/优化基础不等于保留官方算法。早期R20确实比较过GraTa与普通一致性C，但不是当前VV在当前面板上的完整公平外部比较。

源码入口：[VV损失](../../src/dpa_ctta/r85_loss_aggregation/method.py)、[视图与输出](../../src/dpa_ctta/r78_aligned_barycenter/method.py)、[NATIVE配置](../../src/dpa_ctta/r37_cw_orientation/method.py)、[W](../../src/dpa_ctta/r20_model_only_search/method.py)、[LSO](../../src/dpa_ctta/r36_incremental_modules/method.py)。本轮只读源码，没有执行这些模块。

## 2. VV 到底是什么方法

可用于讨论的描述名：**逐视图结构一致性的持续测试时适应**。这是工作描述，不宣称首创或已有论文名。VV的两个V分别表示BCE和LSO均先在每个视图上评价，再平均；不是双教师、双模型、双域或输出集成。

每到达一个图像：

1. 用当前连续模型的六个既定弱几何视图产生逆对齐概率p_v，得到停止梯度的软目标 `q=mean_v p_v`。
2. 每个OD/OC通道独立计算 `var=mean_v(p_v−q)^2`；像素权重为 `rawW=(.25+.75 exp(−var/.1))*(1+2 B)`，B是q≥.5周围半径3的膨胀/腐蚀边界带。按每通道空间均值归一化W，并停止其梯度。
3. 从原strong样本s取得z1，再对同一个s水平翻转、预测、逆翻转得到z2；不是两个独立强增强样本。每分支batch=1，不跨视图合并BN统计。
4. `L_VV = [L(z1,q,W)+L(z2,q,W)]/2`，`L=BCE_W+0.1 LSO`。只进行一次联合反向和一次Adam更新。输出当步更新后的原图K，不是两个视图的均值。
5. 保留全部19136维BN affine及连续Adam状态，冻结非BN参数和分割头。BN用当前统计、无running-stat历史累积。Adam lr=1e−4、betas=(.9,.999)、eps=1e−8。在线不访问源图像、标签或未来输入。

LSO先将预测概率和q做4倍平均池化、3×3平滑，再用Sobel梯度构造平滑结构张量；归一化方向向量为 `(Jxx−Jyy,2Jxy)`。惩罚预测与目标方向的1−内积，由目标结构强度与池化W加权，目标结构强度≤2e−6的点不计。它是逐头方向对齐，不是拓扑保持、严格解剖约束或梯度冲突消除；两头仍共享BN更新。原分母跨头汇总，不能为叙述方便改成各头分别归一化。

无诊断PRE时，VV核心每输入9次F（6弱+2strong+更新后原图），NATIVE为8次F（6弱+1strong+输出），均一次更新；加上研究PRE各为10/9次F。额外分支保留计算图，因此峰值/耗时不能由F数直接推算。必须同硬件测量，不能把“仅BN训练”等同于零成本。

## 4. 为什么有效：已有机制证据比“增强更稳”更具体

### 4.1 已有直接证据

R79在共同内容绑定strong、完整状态恢复下，D1 OC的V−N最终增益+4.522707pp，其中更新前历史差H=+4.535014pp，当前一步额外差C=−0.012308pp。OD对应TOTAL +3.149252、H +3.162883、C −0.013631pp。说明D1额外收益主要已在入站状态中，而非每张图即时多算一个视图就增加约4pp。

R80在每步清空Adam历史、固定初态q/W条件下，D1 OC相对历史收益仍+3.537283pp，OD仍+2.555758pp。由此可排除“必须依赖Adam历史或自反馈才存在任何优势”，但不能宣称唯一纯BN因果机制；这些干预也改变完整学习路径。

R81进一步分开q与W：D1 OC相对历史收益中，固定W时q反馈新增+1.495630pp；固定q时W反馈仅+0.003210pp；交互+0.169177pp。证据支持q反馈放大既有优势，不支持W反馈单独解释全部收益；也不说明删除W权重不会影响方法，因为“固定W”不等于“无W”。

这些来自旧R79–R81已完成开发干预，不能把其绝对分数与当前迁移环境逐位等同，不能与当前六anchor叠加当独立重复。需要新材料确认能否复现。

### 4.2 同预算聚合对照已有结果

R85/R86当前环境，V表示逐视图损失平均、B表示先平均logits再评价；第一位为BCE、第二位为LSO：

| 聚合 | Raw总体Dice | 相对VV |
|---|---:|---:|
| VV | 76.822123 | 0 |
| VB | 76.783067 | −0.039056 |
| BV | 76.489540 | −0.332582 |
| BB | 75.972087 | −0.850036 |

四格使用相同两视图及更新预算。因此VV优于BB不能完全归因为多一次F；但VV与VB差很小，不能宣传“逐视图LSO是已证明不可缺少的关键”。这组结果支持聚合位置值得解释，未单独证明VV相对单视图增益的全部来源。源码支持的BCE凸性意味着逐视图BCE≥均值logits的BCE，但该Jensen差是标准代数性质，不是新理论，也不保证Dice更高；LSO非线性和Adam/反馈使全轨迹不能仅由该差推断。

### 4.3 仍待验证的解释

合理假设是：对逆对齐的每个强视图分别约束目标与局部方向，避免某分支错误被logit平均抵消；这种训练约束长期改变BN affine状态，再经q反馈影响后续目标。已有证据与此相容，但没有证明它比一般等预算增强、等变一致性或调整更新规模更特殊。

禁止写成已证实：跨患者知识迁移；消除OD/OC冲突；防止长期遗忘；恢复真实解剖；普遍改善边界；Adam导致损害；LSO单独贡献全部收益。R93重置/域bank失败支持切断某些历史会损失收益，但其域边界/年龄不完全匹配，也不是完整的持续学习独立证明。

## 5. 方法创新的判断

| 组成 | 当前创新判断 | 需要的证据 |
|---|---|---|
| 六弱软目标、weak-to-strong一致性 | 成熟范式，不宜独立主张 | 与标准多视图一致性精确对齐 |
| 仅更新BN affine、持续Adam | 常用适应机制 | 费用和持续历史贡献，不是首创 |
| 视图方差与边界W | 可能是任务适配设计，但可靠性/边界加权已有近邻 | 排除温度、梯度规模、边界质量等平凡替代解释 |
| 双头结构张量方向LSO | 具体空间约束值得审查，通用结构张量并非新概念 | 方向与幅值/边界/梯度一致性的近期全文比较及公平消融 |
| 两对齐视图逐项优化 | 当前直接差异，简洁且有效 | 标准等变/多视图训练是否已覆盖；等算力/等更新控制 |
| 历史形成与q反馈机制分析 | 已有较有内容的实证资产 | 从开发描述提升到可复现规律；不是算法新颖性的替代品 |

**主风险不是模块少，而是审稿人可以把VV解释成标准多视图一致性加已知空间正则。** 必须证明一个清楚、可推广的设计原则及其不可被简单基线替代的价值。否则即使平均提高约1pp，也更像扎实的工程改进。

TMI官方强调方法创新和深入机制讨论，不以固定Dice增益阈值决定录用；其范围明确不鼓励仅应用既有方法而缺少显著方法创新的工作。我的判断是条件式主方法候选，不是“已足够TMI”，也不是“必须复杂化”。见 [scope](https://ieeetmi.org/scope/)、[criteria](https://ieeetmi.org/key-criteria-for-publication/)、[authors](https://ieeetmi.org/authors-instructions/)。

## 6. 还缺哪些强基线：按优先级补证，先复用旧资产

“缺”指当前未形成可用于VV主论文的同协议证据，不等于这些方法从未在项目中运行。先核已有实现/输出能否合法复用，不重跑已完成对照。

| 优先级 | 比较 | 作用与公平性 |
|---|---|---|
| P0 必须 | SOURCE_ONLY、P0、Q0、NATIVE、VV、E-VV | 静态BN/视图与动态更新分开；E-VV完整复位affine/Adam/cache，先核R79 reset是否已满足，不称完全缺失 |
| P0 必须 | 去W、去LSO、二者均去；各有单/双视图版本 | 区分完整方法贡献与附加第二视图收益；既有R37为1017内容搜索证据，不能直接代替当前192同协议全交叉 |
| P0 必须 | 等预算标准双视图BCE；两独立strong；同一strong重复分支 | 排除多算一次、随机覆盖和纯梯度尺度；重复视图应代数等价但BN/优化状态仍须资格确认 |
| P0 已有应保留 | VV/VB/BV/BB | 聚合位置及交互，保留负结果，不重新跑来选择赢家 |
| P0 必须 | 官方GraTa与普通一致性C | GraTa是实现来源近邻；当前NATIVE不能替代官方对照 |
| P1 必须 | VPTTA、CoTTA、Tent-continual、SAR | 医学prompt、通用持续适应及常用简单强基线；同骨干checkpoint、预处理、时点和调参预算；SAR优化子空间等保留各自合法定义 |
| P1 近邻优先 | SicTTA；视图/权重平均相关医学方法如FAWA | 与单图持续、增强聚合更近；必须核全文及可复现实现再选，不能只靠摘要冠以SOTA |
| P2 视主张 | 其他医学结构/质量引导TTA、GAIN、foundation-model TTA | 输入权限/模型不同须分组，不强行在不同骨干上做绝对分数排名；GAIN不是VV最直接必须基线 |

同时给出各方法原生推荐配置与统一预算下比较；不通过关闭对方核心模块制造“公平”。新增超参只在独立开发材料上确定，比较所有F/BW/更新数、时间、显存和持续状态开销；图像输出时点及后处理统一。当前9 vs 8次F不是充分成本结论，禁止声称免费提升。

## 7. 独立验证与TMI最小证据包

当前192属于已暴露1951内容；其余1759也不是未见测试集。新seed、顺序、迁移重演或旧数据重划不能消除开发暴露。需要先取得真正未用于方法选择的材料并核患者、眼别、中心、来源与预训练重叠；无身份信息时按content-level结论降级，不虚构患者独立。

建议以下作为论文证据设计，不是本次运行指令：

1. **同任务外部确认：** 冻结完整VV及最小强基线，在未使用的中心/设备队列上评估OD/OC、Dice、ASSD、HD95、vCDR和缺失/空预测，原图与post均报告。样本规模按有意义效应与患者聚类方差规划，不能预设“192就够”。
2. **持续性确认：** 同输出语义VV与E-VV配对，增加预注册的域重访、混合流和长流场景；不在线使用域标签路由。原顺序流只支持其设置，不能宣称已证明灾难性遗忘被解决。
3. **方法可迁移性：** 若宣称通用医学分割，至少再选语义不同的独立任务和第二骨干/源训练实例，明确2D/3D、sigmoid/softmax映射。不把“必须几个数据集”说成TMI官方硬规定；若只做眼底，应收窄论文主张并加深临床/多中心验证。
4. **统计合同：** 主比较、效应界、患者聚类、重复眼/切片、seed/order相关性及比较家族在新评分前冻结。报告相对最强外部基线的效果、区间和失败域，不能用内容bootstrap自动代表新流历史的不确定性。后处理与多指标不按结果择优。
5. **局部代价处理：** D3 OC对Q0约−4.34pp必须公开解释；不能只报macro。面向“安全部署”主张需预定局部非劣界并通过；若不能通过，可研究平均效用与适用范围，但不得声称普遍安全。旧R97零容忍门不自动变成TMI通用录用规则，也不能在当前数据上放宽后宣称通过。

## 8. 能否成为主方法：明确决策门

- **保留VV为主候选：** 已有约1pp、六anchor方向一致、历史干预与聚合四格等证据，值得优先整理。
- **暂不判TMI-ready：** 外部强基线、充分新颖性排查、独立验证尚未完成；目前不能给出可靠录用概率。
- **停止以“新方法”包装的条件：** 全文/代码核查显示只是成熟多视图一致性的直接组合，或等预算普通BCE已解释全部增益，或LSO/W无稳定增量且无新的可验证设计原则。此时应报告为基线/机制研究，不能靠命名或加模块补创新。
- **停止推广主张的条件：** 独立材料不复现、效果只来自开发中心D1、相对外部强基线无实际增量，或局部代价违反预先保护条件。保留负结果并收窄范围，不继续扫配置修测试集。
- **当前优先级：** 算法/近邻审计→已有对照资产盘点→独立材料与预算合同。R100保持备选设计，本轮不执行任何阶段实验。
