# 原创候选：参数恢复后的优化器矩迁移（方案v0，未执行）

## 单一主假设

固定相同的恢复时机、参数组与源锚后，一部分恢复后退化来自参数发生跳变而优化器仍沿用旧位置历史。若该跳变对历史梯度近似产生共享平移，可用同批输入的成对梯度迁移历史，而非只能保留或删除。**只检验“已知恢复跳变所引入的不相容”这一狭义机制，不自动解决真实分布改变、伪标签错误或恢复动作本身错误。**

不新增解剖特征、监督网络或生成模型，不把无监督损失下降等同任务收益。最终贡献如成立，应是恢复事件中的历史一致性及跨数据证据，而非新的触发器或全新优化理论。

## 1. 明确状态与可观察量

主方案限普通稠密Adam、固定betas、无AMSGrad；未知变体不自动兼容。设当前参数为theta−，外部冻结恢复器给出theta+=R_G(theta−,theta0)，跳变Delta=theta+−theta−。恢复器、G和源锚在各对照中相同。

保存原Adam的一阶和二阶原始矩m、v；新增一个按beta2衰减的梯度均值r。还保存权重总质量s1、s2（初始0）：

    m <- beta1*m + (1-beta1)*g
    r <- beta2*r + (1-beta2)*g
    v <- beta2*v + (1-beta2)*(g*g)
    s1 <- beta1*s1 + (1-beta1)
    s2 <- beta2*s2 + (1-beta2)

其中乘法/平方逐坐标进行。额外r是一个可更新参数大小的buffer；不训练额外模型。迁移必须从支持r的起点开始，不能从已有Adam checkpoint的m推回r。主方案中的m/r/v不允许混入P-DORM的异步衰减事件；那些是独立控制臂。

在当前已完成PRE评分的批B_t中，按固定输入顺序奇偶拆成A/B两个非空子批。分别在theta−/theta+求同一原生无监督目标的梯度，得到d_A=g(theta+,A)−g(theta−,A)，d_B同理。每一对中teacher/伪目标、样本筛选权重、BN统计、RNG/增强、损失归一化均冻结；原生目标若不能提供这一契约，则该宿主NOT_APPLICABLE，不能偷偷改损失再叫原版。两个子批不是独立患者或严格独立随机样本。无梯度参数跳过计数与状态；不存在的梯度不能补成零梯度。

按样本数加权d=(n_A*d_A+n_B*d_B)/(n_A+n_B)。主方案对所有已登记可更新参数计算该向量，包括G外的组：改早层会影响后层梯度，不能假定仅恢复组的历史需要修正。未登记/未授权参数始终不更新。

## 2. 矩迁移与可证明的窄结论

假设每个历史梯度都被相同向量d平移，则按原EMA定义直接展开可得：

    m+ = m + s1*d
    r+ = r + s2*d
    v+ = v + 2*d*r + s2*(d*d)

右侧r必须取迁移前值，同时提交三项。s1/s2和Adam计数不变，随后由m+/s1、v+/s2进行原偏置校正。此式不是m+=m+d、v+=v+d²；二阶交叉项不能省。**beta1不等于beta2时，不能用m替代r。**

推导：v=sum_i w_i*g_i²，r=sum_i w_i*g_i，s2=sum_i w_i；代入(g_i+d)²即得到公式。该恒等式本身是基本矩变换，不作为新理论贡献。它不要求执行数值实验。

若每个样本损失为共享Hessian的二次函数，则对固定跳变Delta有g_i(theta_i+Delta)−g_i(theta_i)=H*Delta，故上述公式精确对应**把历史参数轨迹整体平移Delta后的梯度矩**。这不是恢复后的真实重演轨迹，也不是把所有过去梯度重新计算到同一theta+；不据此推出非凸分割或CTTA收敛/收益保证。

一般情况下设历史位移为d_i，r_i=d_i−d，则一阶误差为sum_i w_i*r_i；二阶误差逐坐标为sum_i w_i*[2*(g_i+d)*r_i+r_i²]。当前两子批一致，只能局部支持共享平移近似，不能界定所有过去d_i，更不能保证任务正确性。

## 3. 固定、可失败的迁移资格门

这些值是方案v0的事前设计，不来自任何目标数据结果，不称作者默认或已经验证。计划完整冻结后不在目标集扫描。

- eps数值量=1e−12；计算范数使用float64归约，buffer保持原dtype。
- 两子批均非空且梯度有限；d_A/d_B余弦>0；若两者范数都<=eps，取d=0作恒等迁移，不用0/0；仅一者<=eps时资格失败。
- 相对不一致度rho=||d_A−d_B||/(||d_A||+||d_B||+eps)<=0.5。
- v+理论应非负；只有绝对负值<=1e−10*max(1,||v||_infinity)可截到0，超过则资格失败，并保存诊断，不能广泛clamp掩盖错误。
- 资格失败时保持同一theta+，全局清空本方案优化器m/r/v、计数与质量；不取消参数恢复，不换恢复组或补采子批救门。
- batch<2时本v0不适用，不将像素/patch当独立样本来凑证据；不能声称支持单样本流。

不额外用目标GT、未来样本或任务收益选择迁移。暂不加入多个软门/学习控制器，以免把状态机制与新selector混合。

## 4. 严格时序和副作用

1. 用当前theta−对到达批做PRE预测并封存；之后该批才可参与无监督适应。
2. 冻结恢复器决定是否恢复及G。未恢复时原生Adam一步，r同步只读梯度记账，无额外网络调用。
3. 恢复事件先复制完整事务快照，包括参数、所有buffer、优化器、scheduler、RNG、teacher、方法历史与监测器。
4. 探测theta−/theta+的两子批梯度，调用不能提交任何学习或监测统计。RNG和可变buffer回到同一快照；不复用污染的BN统计或SAM临时参数。
5. 从干净快照恢复到同一theta+，按资格门迁移或fresh-reset，再执行原生全批更新恰好一次；当前梯度不得在探测时进入EMA。
6. 同步提交参数/优化器事务。冻结teacher或显式同样处理的其他history必须有宿主契约，否则不准入；本v0不宣称支持任意EMA/SAM宿主。

探测是每恢复事件额外4次前向/反向（两子批×两参数状态），之后原生更新另1次；不能写成零额外反向。若实现能复用一对已有计算，另报告实际节省，不提前虚报。r额外内存为P*sizeof(dtype)，临时快照/梯度也计峰值。

## 5. 关键反例和停止条件

- 恢复参数本身有害：再一致的历史也不能保证救回；需包含无恢复对照。
- 历史来自已消失的域：当前位移可一致，但被迁移的历史语义仍错；mixed/recurrent流要显式检验。
- 不同历史样本Hessian差异大：共享平移近似失效，两当前子批可能漏报；必须与历史重放oracle作诊断，oracle绝不参与部署。
- 梯度平移很大或v退化：固定资格门可能全部fallback；若与全清等价则没有独立机制证据。
- 目标依赖重采teacher/筛选：成对梯度混入目标变化，不能称参数跳变因果效应。

只有跨数据对强控制的PRE未来收益和机制诊断同时成立，才推进。否则关闭此版本，不通过改rho、恢复层或数据子组救分。本文件不构成实验启动授权，未实现任何算法运行。
