# 跨数据验证设计（规划，不是已准入协议）

## 1. 要验证的贡献与两层比较

先固定参数恢复事件，隔离“恢复后历史怎么处理”；后做在线端到端验证，允许各臂轨迹分歧。不能把同一source初始化的两个完整分支称完全相同历史。

第一层使用一个冻结参考运行预先生成的因果事件表；表仅含到达时间与恢复组，不读GT。各事件从同一参考快照分叉，在同一后续32批上按PRE先预测后更新评分。参考表从部署输入产生、需要额外参考计算，故本层是诊断，不冒可部署控制器。event重叠按流/序列绑定统计，不能当独立事件样本。

第二层各臂从相同初始化独立在线运行、使用相同冻结恢复规则；只用各自过去状态作决定。报告恢复次数/范围/触发差异，并保留第一层判断，不能把触发频率变化误当矩迁移独有收益。

## 2. 必须保留的控制

| 控制 | 作用 |
|---|---|
| SOURCE、成熟静态读出 | 防止打败退化适应臂就称收益 |
| 无恢复的原宿主 | 恢复事件本身是否必要 |
| 参数恢复＋保留优化器 | PSR式部署语义 |
| 参数恢复＋全量fresh optimizer | 最直接且强的替代；含V6已知状态清空 |
| 原P-DORM包裹同宿主 | 方向异常检测/矩处理先例；先解决论文与代码差异 |
| 同参数恢复＋固定P-DORM式moment动作 | 固定事件的一阶清零/二阶保留/局部偏置校正控制；不是完整原P-DORM复现 |
| 同参数恢复＋仅一阶迁移 | 二阶联合迁移是否必要 |
| 同参数恢复＋无资格门迁移 | 两子批门的增量；不能替代主方案 |
| 只迁移G内历史 | 检验跨组梯度耦合；不得按目标集选择最佳范围 |
| IGT/MARS式成对梯度修正 | 排除仅因增加梯度评估和经典方差缩减获益；需原法兼容审查 |
| 相同探测预算但不提交探测梯度的控制 | 保持同网络调用及随机性隔离；另列原始成本和等预算前沿 |

PSR缺完整runner时，只能明确叫“PSR语义自有重建”，不能填成作者原版分数；未解决P-DORM配方时paper/code两种contract分别登记，不能选目标集高者。

## 3. 数据与迁移矩阵

**以下均是待登记资源，不表示已有使用许可或已下载。现有固定8眼底内容不够验证本方案，且停止的BN尺度路线不恢复。** 不因列出公开基准就自动下载checkpoint/数据或源训练。

| 角色 | 计划数据/任务 | 必须冻结的迁移 |
|---|---|---|
| 通用机制开发 | CIFAR-100-C分类，一个已有兼容LayerNorm宿主 | v0门槛/eps/两子批规则先固定；若需设计修改只记开发版本 |
| 未调参通用验证 | ImageNet-C、DomainNet-126 | 同一迁移公式/门槛/回退/恢复触发profile，不用目标标签调；架构参数名映射单独登记 |
| 医学主要验证1 | 前列腺MRI跨中心分割，现有源模型资格待核 | 与其它医学任务共用状态管理规则，损失继承各宿主已冻结原生目标 |
| 医学主要验证2 | 心脏MRI跨设备分割，现有源模型资格待核 | 与前列腺/眼底做leave-one-dataset-out设计，按患者或体数据绑定统计 |
| 医学主要验证3 | 眼底跨数据集分割的独立未开发队列，资产待核 | 不使用当前8内容作独立验证，不据眼底结果反调规则 |

医学数据身份、划分、重复患者、预训练成员、许可证、源模型与可更新参数均需先登记。以上任务中的新增模型/数据未获当前默认资产许可，不能仅凭本方案启动。无兼容非BN-scale宿主时记录BLOCKED_ASSET，不改成旧BN路线。

分割二头保持独立Bernoulli；互斥多类采用各宿主原生多类语义。不是把所有任务都强行softmax或复制眼底动作块。方法层仅使用梯度与状态，不使用血管、杯缘或器官形状。

统一考察：缓慢漂移、突变、回访、域混合/类别比例变化、无变化null；同协议多独立顺序与seed，流长度/顺序需预先冻结。PSR原文ACDC为驾驶数据，不能误当本表心脏MRI资源。通用验证与医学验证分层报告，不把Accuracy与Dice直接平均成一个指标。

## 4. 主指标与可证伪门（设计约束，运行前需补全资源清单）

分类主指标为整流PRE错误率，分割为整流PRE Dice；H32未来指标只作事件机制诊断。后更新当前图POST不能换主。报告返回域、最差域/患者损害、恢复成本、fallback比例和不适用分母；独立评分器读取标签，标签不可反馈控制器。

候选主比：迁移方案对“参数恢复＋全清Adam”的配对未来PRE差。分类按错误率下降计，分割按Dice上升计。在每个未调参主数据集，计划要求改善>=0.3pp且95%配对区间下界>0，最差域差>=−0.5pp；对SOURCE/最强固定静态至少不出现超0.5pp的损害。三个医学主任务均单列，不用平均值盖住某任务失败；同时报告预先固定全清以外各强控，若只有弱臂可胜则不推进。

不能把0.3pp门移植为所有任务科学意义的证明；这是本方案预设推进标准，不是统计显著性替代。独立患者/体数据/序列为重采样单位，不以像素、事件或重复条件夸大样本量。多项主数据集需在实际协议中冻结多重比较控制（计划Holm、alpha0.05），不得选择通过的子集宣称普适。未冻结各集样本/seed/身份前，完整性能protocol_frozen=false。

先看固定事件空间的收益机会，但新的状态恢复作用改变未来轨迹，**不直接沿用眼底逐块加和oracle作为严格联合上界**。有限分支H32 oracle只是在已登记动作空间内的诊断上限，不是所有状态管理机制的全局上界。

## 5. 将来才可执行的资格顺序与预算

当前禁止启动，以下仅为计划。将来得到明确恢复实验指令后，仍需先补全资产/协议与工程准入：

1. 纯合成解析资格：共享Hessian二次、异质Hessian反例、不同beta、恢复零跳变、跨组耦合、有限精度/计数、事务副作用、探测梯度只记一次、完整状态重演。当前一个也未运行。
2. 固定事件真实诊断：共因快照、有限分叉、同未来数据、独立评分，先检验机制机会与强控。
3. 未调参多数据在线验证：一套v0公式，固定恢复器，各任务不重选门；资格失败/NA完整保留。

每独立轮仍<24h与每服务器新增actual<50GB，并服从更严20GB硬/18GB工作/aux1GB、原clock及独立硬守护。拟定第一轮合成<=600秒、输出<=32MiB；首个真实有限轮拟<=3600秒、输出<=1GiB，所有分叉/失败计入同clock。这里只是上限草案，不是派发或运行root。

探测额外4次反向/恢复事件；若平均额外反向>0.5次/批或峰值超过原生1.5倍，先记效率门失败，不靠隐藏probe/降低baseline计算量取得优势。无原模型吞吐/内存测量时不能声称这些预算可行，不能为测吞吐偷偷开模型。
