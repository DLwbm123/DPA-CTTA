# R67 fixed-image mask-response diagnostic

Registered after R66 negative results and its declared post-hoc attribution, before any R67 real-image inference. This tests one possible failure mechanism of the old-method signal; it is not a new-method training route and not a segmentation efficacy experiment.

Fixed inputs: the same48 exposed SEARCH images, two archived CW orders,96 pairs, native128-grid masks sampled at2::4. Source model, normalization, eval current-image BN and frozen-state/first-repeat checks are exactly the qualified R66 extraction pipeline. No source images, source masks, target labels, optimizer, historical replay or altered final deployment outputs. Target labels are not copied into this run. The aggregator only receives an already-public domain designation per content.

For each pair, construct minus/center/plus nested masks using one3x3 square erosion, identity, and one3x3 square dilation (border_value0). Both channels receive the same operation; nesting is preserved. No radius scan. Run unchanged R66 native proposal on each mask with (a) fixed source up3 image features; (b) three one-hot channels encoding current candidate background/disc-rim/cup, rebuilt per perturbation. The latter is a prediction-only geometry control, not an image feature baseline. Total576 native proposal calls plus49 source forwards including the first-image repeat. The common worker saves only a copy of the original CW masks; native diagnostic proposals are summarized, not deployed.

For each channel, response spread ratio = symmetric-difference area between corrected minus/plus masks divided by the input minus/plus symmetric-difference area. Identity/complete abstention gives1. Zero input denominator is undefined, never0; any undefined channel/pair prevents the full-matrix gate and overall summary. Retain all missing counts. Report all domain/order/channel ratios and accepted-boundary fractions separately for minus/center/plus. The primary contrast is image ratio minus mask-only ratio, equal content/channel/order/domain weighting. Existing2000-draw content-stratified bootstrap, seed20261016, keeps orders/channels coupled. No target labels enter this statistic.

Working response criterion (not an accuracy claim): full192 channel/pair denominators defined; mean contrast<=-0.10; descriptive95% upper bound<0; both orders negative; minimum over3 shifts and2 channels of mean image acceptance>=0.25. These thresholds only determine whether the signal shows usable response contraction beyond the mask-derived control. A pass does not imply true anatomy, useful Dice correction, causal independence from the mask, or benefit from a parameter update. A failure does not justify tuning this measurement. R66 remains negative regardless of outcome.
