## 2. 共同设置、符号与证据边界

沿用 192 个既有开发内容、四个匿名域 D0–D3、两条既定顺序。R90/R91/R92 使用三 seed（20260907、17011、29009）形成六个 seed×order anchor；R93 仅 seed 20260907 的两 order，是机制筛查。宏平均为四域、双头等权 Dice；OD/OC 分别为视盘/视杯。分数用 %，差值用百分点 pp。R93 的单 seed 绝对均值不能与 R91 三 seed 均值混作性能变化。

- P0：初态 BN affine、当前图统计下的原图输出；不是 SOURCE_ONLY 的 running-stat 输出。
- P：VV 入站历史状态的原图 PRE；K：当步真实更新后的原图输出，即保留的 VV。
- Q0：初态、当前图统计下的固定六弱读出；Qt：原 VV 已有入站六弱概率均值的只读导出。Qt 没有新增主线前向，也不改变写入。
- V：R93 原 VV；S：依既有域元数据离线构造的四 bank；J：固定伪分组四 bank。
- 固定 post：逐头 8 连通最大连通域（并列取首光栅）→4 连通背景填洞→OC∩OD；各方案一致，未按结果修改。

原 VV 学习规则保留：19,136 维 BN affine、current statistics、无 running statistics，非 BN/head 冻结；continuous Adam 1e-4、betas(.9,.999)、eps1e-8；原六弱 q、W(.1,2)、原强增强与同一实际 strong 的 flip 逆对齐、native normalize、BCE+.1 方向 LSO 及原分母。严格 model-only，在线不读 source 图像、标签或未来图像，无额外模型。

**数据限制贯穿全部结论：**192 内容及注册 1951 内容均已历史暴露；patient/video/source-training overlap UNKNOWN。内容 bootstrap 不是患者独立或 seed 总体区间；换 seed 不产生独立确认。R87 未暴露 cohort 不可用，R88 前置条件未满足。所有结果只属当前开发证据，不作临床安全或泛化确认。

## 3. R90：任务价值成立，单一少写信号失败

### M0：静态控制没有消除 VV 增量

|输出|raw macro %|post macro %|
|---|---:|---:|
|SOURCE_ONLY|68.733077|68.808691|
|P0|74.749237|74.936448|
|NATIVE|75.843778|75.987955|
|VV K|76.822123|76.950749|

post VV−P0 +2.014300 pp，95% 按域内容 CI [1.481285,2.603461]；post VV−NATIVE +0.962794 pp，CI [0.644449,1.302029]。两比较均通过预定 +0.3 pp、CI 与方向门；D1 双头相对 P0 全六 anchor 正。与此同时，D3 OC 相对 P0 仍 −0.398002 pp，六 anchor 全负、47/56 内容负。M0 支持继续诊断这一具体权衡，没有证明存在可在线识别、可获益撤销的写入。

### M1：局部坏写入存在，不等于规则可用

每流八个预定位置，共 48 探针；比较 WRITE 与 USE-ONLY。当前 K 共享，USE 撤销该步参数及 Adam 学习状态，保留数据到达和随机消耗，随后各自演化 16 张。信号只用真实入站 m/v/t 计算零新梯度理论 Adam 位移，与当前完整梯度作带预定 float64 数值保护的冲突判断。

G_rule 为按信号撤销的窗口收益；G_identify 为超过每 anchor 同频随机期望的增量。虽然 G_identify 总体为正，但规则收益为负，稳健性不足，且仅触发 3/48，涉及 3 内容、2 域，未满足至少 12 次、每 anchor 1–7 次、至少 6 内容/3 域的覆盖门。

全部窗口 WRITE−USE 中 11 负、37 正，均值 +0.020066871 pp。事后完美局部 oracle 的撤销收益仅 +0.001232003 pp；同频随机期望 −0.001024774 pp。**这些量只描述原 VV 历史上的 48 个 16 张窗口，不是四域全流 macro，不是完整策略上界，不能累加或乘更新数。** 关闭该信号，不调符号/阈值/频率/窗口，不进入 M2。

## 4. R91：读出有平均价值，完整部署候选不合格

|输出|raw macro %|post macro %|
|---|---:|---:|
|Q0|75.756872|75.785919|
|P|76.776010|76.907043|
|K|76.822123|76.950749|
|Qt|77.274662|77.288457|

DEPLOY=Qt−K +0.452540 pp，六 anchor 全正，但 Bonferroni 双侧 97.5% 内容 CI [−0.326591,+1.263398] 跨零；HISTORY=Qt−Q0 +1.517790 pp，CI [1.117851,1.958890]、六 anchor 全正，通过该项。不能用同一内容上的六次同向替代内容不确定性。

READ=Qt−P +0.498652 pp；STATIC_READ=Q0−P0 +1.007635 pp；INTERACTION=READ−STATIC_READ −0.508983 pp。静态读出已有收益，历史在同读出下也有正宏增量，但不能将 Qt 的全部优势包装成新持续学习机制。

Qt−K 的 D3 OC +1.732286 pp，预定 D1 保护及 raw/post 38 项结构门均通过；然而 D0 OD 相对 NATIVE −1.098211 pp，违反 −0.5 pp 均值伤害门。该头相对 K 有 17/22 内容负。D1 OD/OC 虽均值改善，仍有 29/57、27/57 内容负；OC 最差内容跨 anchor 均值 −43.652178 pp，经 R92 复核双方非空、映射与单位无误，保留该真实损伤。

Qt−Q0 的 D3 OC 仍 −2.610158 pp：相对 K 改善并未消除同读出历史残余。关闭这次固定六弱替换，不追加融合、视图/阈值、teacher/EMA 或 selector 扫描。

## 5. R92：历史残余真实，误差方向与简单叙事不同

|---|---:|---:|---:|---:|

D3 OC 的 H_id 六 anchor 全负，47/56 内容负；H6 也六 anchor 全负，49/56 负。D1 H_id OD 55/57、OC 47/57 内容正，收益并非仅少数极端值。因此需要同时保护广泛的 D1 正收益，而非仅优化 D3 残余。

二值编辑账显示 D3 OC 历史退化主要伴随假前景补入净增加：P0→P 假补入 0.126272、正确删除误报 0.089283 个整图百分点；Q0→Qt 分别 0.305193、0.079684。两历史转移真补入均超过错误删除真前景。不能概括为“持续学习主要删掉真实杯区”。编辑账是任务误差描述，不唯一定位 BN、Adam、阈值或生物机制；没有概率资产，未推断熵、置信度或方差，也未补跑 GPU。

36,864 项 Dice 重建、384 条编辑账及分解恒等通过。旧 VV 干预审阅显示，R80/R81 减少 D3 损伤时也丢失 D1 收益；R32 同域后续更新亦可有害，跨域污染不是必要解释。旧 reset 与当前 V/S/J 没有找到严格同条件重复，但不可用私有资产并未被穷尽排除。R92 的 GO 是允许 R93 资格/profile，不是效果晋级。

## 6. R93：边界清除历史改善 D3，却损失更多有益历史

S 在本流的精确含义是域边界恢复初态 affine+空 Adam：两 order 每域仅一个连续块，没有重访，不能声称测试了状态检索。既有域 metadata 只用于 CPU 离线构造匿名索引，不授权部署 router。J 用固定 rng93 按 canonical 内容置换、quota 22/57/57/56；跨 order 同内容同 bank。最终更新数和全流 local-age multiset 匹配，但逐 arrival 年龄有 189/183 次不同，S−J 不是唯一域语义因果。

|臂（单 seed 两 order）|raw macro %|post macro %|
|---|---:|---:|
|V|76.734295|76.865502|
|S|75.732163|75.882783|
|J|75.501274|75.671983|

S−V −1.002132 pp，两 order −0.773069/−1.231195，校正 97.5% CI [−1.380773,−0.654052]，失败。S−J +0.230889 pp，两 order +0.245343/+0.216435，CI [0.094325,0.394497]，通过。S 比 J 好不能支持替代 V，因为两者均劣于 V。

D3 OC +0.399937 pp、50/56 内容正，达到预定 +0.3 pp；但 D1 OD/OC −2.989289/−4.315135 pp，分别 46/57、44/57 内容负，远超 −0.2 pp 保护限制。结构门 38 项中 16 项失败；总体 ASSD +1.119626、HD95 +3.130449 网格像素。相对 NATIVE 的伤害门通过，不能抵消相对 V 的主门和保护失败。

**结论仅限本干预：**本次清除跨域前缀的收益不足以保住有益历史。它不证明所有历史共享都好或所有隔离都无效，不识别唯一参数/优化器机制。关闭该干预，不调分组、边界、seed 或门槛，不训练 router，不扩 seed 矩阵。
