# CTTA 项目进展、方法路线与实验结果

更新日期：2026-10-13。运行状态核实时间：北京时间11:12:33。
本文是已公开结果与一次只读状态查询的总结，不是实验启动、续跑、调参或追加监测指令。
运行状态会继续变化；效果结论仅来自已经完成并评分的轮次。

## 1. 当前判断

项目已从学习策略/动作选择，转向保留正向基础的非 RL 医学分割适应。
**当前最扎实的正向组件证据是 CW_LSO 的结构方向一致性损失；联合敏感性路线已具备可运行实现，但尚未建立平均效果提升。**

- CW_LSO 相对 C 的 SEARCH macro Dice 提升0.3541pp，相对 CW 提升0.1911pp，两顺序、六个种子顺序组合均正。
- CW_LSO 相对 W 的最差域/通道/顺序单元仍退化5.1551pp，未通过完整开发门槛，不能称为均匀安全的适应。
- R46 共享敏感空间改善了一部分严重退化，但平均 Dice 相对 CW_LSO 下降0.0251pp，并损害 Drishti_GS 和 ORIGA。
- 下降约束版已经通过 CPU 校验和真实模型资源 profile；效果尚未知。R47 同轮五条件 profile 已通过并准入，正式固定队列正在运行，尚无评分结果。

SCNP、谱熵等候选的平均点估计略高于 CW_LSO，但增量很小、区间包含零。因此“最扎实的组件证据”不等于所有表格里最高的单个点估计。

## 2. 任务与共同评价边界

当前主实验是眼底 OD/OC 分割的连续测试时适应，保留源 ResUNet，只更新 BN-affine 参数。
OD 为视盘、OC 为视杯，采用两个独立 sigmoid 通道；不是互斥 softmax 分类。
目标图像在线到达，在线更新不读取目标标签或源图像；全体在线 worker 退休后，由独立 CPU 评分器读取授权标签。

每条完整流1951张图像，含 SEARCH1017、历史 REVIEW678、CONTEXT256。
三种子20260907/17011/29009，两种固定域顺序。主要域为 REFUGE、ORIGA、REFUGE_Valid、Drishti_GS。
主指标是512px硬 Dice，域与 OD/OC 等权，再平均种子和顺序；双空掩码 Dice=1。
图像加权指标单独报告，不替代主指标。

SEARCH 和历史 REVIEW 均已开发曝光；REVIEW 只用于描述，不能当独立确认或用于后续调参。
内容 bootstrap 将重复内容的顺序/种子耦合，不能消除开发选择偏差或证明患者独立性。
患者关联及 ROI 来源审计仍未解决，ASSD、Brier、soft Dice 和临床校准尚未形成已验证结果。
多轮重复同一基线/内容主要支持复现性，不是多个独立队列的验证。

## 3. 方法路线

### 3.1 早期：强对照、参数策略与动作空间诊断

R20 的连续像素权重 W 超过原生 GraTa，但仍低于普通一致性 C；后续不再把超过较弱的 G 当作方法成功。
参数策略、嵌套结构选择、更新幅度和暂停动作等轮次检验了学习策略是否有足够的可用动作收益。
现有证据不足以支持将 RL 作为必需主线，RL 当前暂停。

| 代表轮次 | 指标范围与比较 | 结果及含义 |
|---|---|---|
| R20 | 当轮历史 REVIEW：W−G / W−C | +0.6159 / −0.5453pp；强简单 C 更好 |
| R25 | 当轮历史 REVIEW：PG_RETAIN−ANCHOR | +0.000385pp，区间跨零；新增策略没有可靠增量 |
| R27 | 当轮历史 REVIEW：GREEDY−ANCHOR | −0.025883pp；离线选择信号未转化为在线收益 |
| R28 | 固定同状态 SEARCH 四候选 oracle−ANCHOR | +0.080122pp，未达0.3pp投入门槛 |
| R29 | 固定同状态 SEARCH FULL/ZERO/HALF oracle−FULL | +0.010225pp；局部动作空间收益很小 |
| R35 | 前瞻 H256 SEARCH：HOLD−UPDATE | −0.765089pp；oracle−最佳固定动作+0.234880pp，门槛失败 |

这些轮次的终点、状态、角色和观察窗口不同，不能并成一张统一性能排名。
局部 oracle 结果也不是所有 RL 或多步闭环方法的理论上界。

### 3.2 正向基础：CW_LSO

保留 C 的固定学习率一致性 Adam 宿主，把 W 的可靠性/边界权重迁入形成 CW，再增加 LSO：

\[
L_{CW\_LSO}=L_{\text{weighted consistency}}+0.1L_{\text{orientation}}.
\]

六弱视图形成 detached 软伪目标；W 根据视图方差与边界信息加权，温度0.1、边界增益2。
LSO 在下采样、平滑后的预测/软伪目标上估计结构张量方向，以可靠性和参考结构强度加权方向一致性。
OD/OC 分别处理，不强制形状模板或临床解剖结论。
CW_LSO 固定 LR1e-4，Adam 的矩、步数和源模型保留。

| R37 SEARCH 方法 | macro Dice（%） |
|---|---:|
| C | 78.6916 |
| W | 78.0896 |
| CW | 78.8545 |
| CW_LSO | 79.0456 |

CW−C 为+0.162930pp；CW_LSO−CW 为+0.191136pp，95%内容区间[+0.159125,+0.225917]pp。
CW_LSO−C 为+0.354066pp，区间[+0.303809,+0.402994]pp。
迁移 W 到 C 宿主同时改变了原宿主的学习率与其他原生行为，CW−W 不是孤立的权重因果消融。
W 与 LSO 的交互仍缺少 C+LSO 条件，不能写成已经证明协同。

### 3.4 统一机制路线：成像与解剖联合敏感性

R45 原 JS 用两个固定成像探针、OD/OC结构响应和四个辅助 VJP，估计 BN 参数的成像/结构敏感方向。
在 Adam 度量下，以成像空间 Q=orth(X) 过滤实际 Adam 提议；保留 CW_LSO 原损失。
它只表示投影到成像空间内的解剖响应，最大 rank2。

R46 改为共享空间 Q=orth([X/||X||_F,Y/||Y||_F])，最大 rank4。
仍保留相同证据、探针、VJP、strength1/ridge0.01 和 Adam；没有加入 GC/GP、SCNP、SE 或 RL。
方法主题是协调成像变化可塑性与结构稳定性，但当前实现并未证明能辨别有益纠正和有害漂移。

| R46 同轮 SEARCH 方法 | macro Dice（%） |
|---|---:|
| CW_LSO | 79.0456 |
| 原 JS | 79.0387 |
| SHARED | 79.0205 |

SHARED−原JS 为−0.018238pp，区间[−0.041453,+0.008933]pp。
共享空间 rank4、注册 VJP 捕获约1.0、平均相对更新向量变化17.4989%，说明机制确实生效；不说明解剖正确性或效果因果。

## 5. 下降约束版与当前 R47

下降约束版在 R46 共享空间上，仅增加基础 CW_LSO 损失的一阶下降约束。
令 v_A=Q^T H^{1/2}delta_A，c=Q^T H^{-1/2}g，g 为已有基础损失反向的梯度，则求解：

\[
\min_v\frac12\|v-v_A\|^2+\frac12v^T T v,
\qquad c^T(v-v_A)\le0.
\]

约束不活跃时保留原共享滤波；活跃时作四维闭式 KKT 修正。
原 Adam 提议不是下降方向、无有效敏感性或数值退化时回退实际原提议。
这是局部代理损失的一阶约束，不保证有限步损失、Dice、解剖安全或全局范数收缩。

- CPU28项通过：约束禁用与冻结 R46 输出/诊断/完整状态精确一致；整个联合模块禁用与 CW_LSO 精确一致；独立 KKT、调用、Adam、RNG 和恢复校验通过。
- 真实源模型 GPU profile 四项 PASS，仅物理0/1，反序比较，每项12张、4热身/8计时。
- GPU0：R46共享1.339秒/图，下降约束1.352秒/图，+0.98%；GPU1：1.330→1.324秒/图，−0.51%。
- 两者峰值 allocated 均816.9MiB，reserved896→898MiB，增加2MiB；两次下降约束 profile 均11/12次触发，无回退。
- 网络调用仍10F/4辅助VJP+1基础反向/1Adam。短样本共卡测量未显示明显额外开销，不是全流速度或效果验证。

## 7. 论文主线与最小证据缺口

目前可支持的实证主线是可靠性加权与结构方向一致性的平均增益，以及局部安全/准确率权衡。
成像与解剖敏感性协调是正在验证的算法主线；应等 R47 的完整配对结果，再决定它能否成为正向贡献。
不能以数学形式更复杂、CPU校验通过或显存开销小替代效果与新颖性证据。

最小补充方向仅为建议，本文没有启动：

1. 用已完成预测检查一个边界指标（如ASSD）、空预测和OC越出OD；明确空表面距离的未定义数量。
2. 补 C+LSO，形成 C/CW/C+LSO/CW_LSO 的2×2消融，检验 W 与 LSO 交互。
3. 采用一个未曝光、患者可审计的确认队列，并加入一个协议兼容的近期医学TTA对照；不把旧REVIEW重命名为独立验证。

若 R47 仍没有可靠增量，联合敏感性应作为权衡/负结果讨论，不能写成已实现的解剖保护贡献。
原论文机制复现边界、与已有解剖TTA/子空间更新的区别及新颖性比较仍需单独核实。
