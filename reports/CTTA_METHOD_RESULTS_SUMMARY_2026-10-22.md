# CTTA 方法与阶段结果总结（截至 R106）

日期：2026-10-22。本文汇总已交付实验，不是新实验协议，也不修改历史判定。当前研究主线仍为完整 VV 及其有依据的机制改进；C2 是固定的简化机制对照，不以优化 C2 或扩充评测框架替代主线推进。

## 1. 当前方法是什么

使用既有分割 checkpoint，在线仅更新 19,136 个 BN affine 参数；采用当前输入统计，不积累 BN running statistics，其他参数和 head 冻结。每个内容到达时：

1. 当前模型进行六个弱视图的无梯度前向，概率均值得到本分支伪目标 q；完整方法沿用原可靠性权重 W。
2. 构造既定 content-keyed strong 输入及其水平翻转。第二分支 logits 逆翻转后对齐，不平均两个分支的输出作为最终预测。
3. 对两分支分别计算完整损失，再取均值：`L_VV = [L_full(z1,q,W) + L_full(z2_aligned,q,W)] / 2`，其中 `L_full = 原W加权BCE + 0.1 × 原方向LSO`。保留 W 的 variance_temperature=0.1、boundary_boost=2 及原实现的归一化/分母。
4. 一次联合 backward、一次 Adam 更新，lr=1e-4、betas=(0.9,0.999)、eps=1e-8。持续模式保留 BN affine 和优化器历史；最终 K 是更新后的原图输出。

上述是方法结构描述，具体运算顺序以冻结实现为准。没有新增 teacher、EMA、网络结构或输出集成。历史存储在可训练参数和优化器等状态中；q/W由当前模型生成，形成反馈。BN affine 的积累不能称为 BN running-stat 积累。

| 名称 | 定义与用途 |
|---|---|
| NATIVE | 原单强视图完整 W/LSO 配方，方法对照 |
| C1 | 单强视图普通 BCE，去除 W/LSO 的机制对照 |
| C2 | 两个对齐 strong 视图普通 BCE 的均值，无 W/LSO；固定简化对照 |
| VV | 两视图分别计算 BCE/LSO 再平均；当前完整主线 |
| VB / BV / BB | 分别改变 BCE、LSO 在逐视图还是对齐 logits 均值上计算的位置 |
| episodic C2/VV | 每个内容恢复初始可训练状态及空 Adam；保留既定增强随机流，不回拨累计物理计数 |
| P0 / Q0 | 初态 current-stat 原图 / 固定六弱概率均值读出；二者不是同一种预测 |
| PRE / K / Qt | 持续模型入站原图 / 本步更新后原图 / 入站六弱概率均值 |

SOURCE_ONLY 使用原 source eval/stored running statistics，与 P0/Q0 区分。C1/C2 的目标来自自己的模型状态，不借用 VV 的目标。C2/VV 等在本报告中是机制对照称谓，不等同于所有论文中的“基础模型 baseline”。

## 2. 共同实验口径

当前核心开发面板为 192 内容，四域 OD/OC，三 seed（20260907、17011、29009）及两个固定顺序。宏观 Dice 对域及双头等权，单位 pp 为百分点。两个顺序不可假定完全互逆。raw 和固定 post 同时报告；距离指标为输出网格像素，不是 mm；vCDR 误差为比值单位。

在线适应不读取标签和旧评分；GPU阶段结束、预测封存后独立评分。静态参考、历史轨迹复用、短程资格与完整重演在各报告中分别标注，不能把复用当新增独立重复。内容 bootstrap 反映已实现流上的内容不确定性，不是患者独立、外部泛化或新流历史总体的置信区间。不同批次有不同冻结门与校正方式，不混用。

## 3. 最关键的结果

### R102：完整包相对普通双视图只有小幅增量

| 方法 | raw Dice % | post Dice % |
|---|---:|---:|
| C1 | 75.776636 | 75.921885 |
| C2 | 76.724873 | 76.858795 |
| NATIVE | 75.843778 | 75.987955 |
| VV | 76.822123 | 76.950749 |

- C2−C1：+0.948237 pp，95%描述性内容区间 [0.643098,1.304393]。
- VV−C2：+0.097250 pp，95%区间 [0.073181,0.123241]，6/6 anchor 正，但均值及上界均低于冻结的 +0.20 pp 投入界，故 `BELOW_REGISTERED_INCREMENT`。
- 双视图与完整损失的交互为 +0.030108 pp，属于辅助结果，不能解释主要增益。
- C2−C1 的 D1 / 其他三域平均为 +3.757023 / +0.011975 pp，D1算术贡献约99.05%；这是收益分布，不是因果归因。
- VV 相对 C2 的总体 ASSD、HD95、vCDR 筛选通过，不能将本轮未晋级说成总体结构失败；D3局部仍有损害。

### R106：历史收益成立，但完整损失额外历史价值很小

| 对比（持续−episodic） | raw pp [95%内容CI] | post pp |
|---|---:|---:|
| H_C2（原主指标） | +1.838024 [1.360031,2.390587] | +1.809215 |
| H_VV（辅助） | +1.934244 [1.446285,2.497695] | +1.899115 |
| I_history=H_VV−H_C2（辅助） | +0.096220 [0.071829,0.122389] | +0.089901 |

episodic C2/VV 的 raw 分别为74.886849/74.887878，相差仅+0.001029 pp；持续条件下相差+0.097250 pp。完整损失的额外差异主要在持续过程中出现，但其幅度仍小。不能将辅助交互改为预注册主指标，也不能将其正区间解释成完整方法已达到原投入门。

H_C2 主门通过，6/6 anchor 为正；但 post vCDR 绝对误差增加+0.002729，结构门失败，冻结决策为 `HISTORY_VALUE_WITH_LOCAL_TRADEOFF`。VV 的对应 post vCDR 增加约+0.002358（补充描述）。C2去掉D1后历史收益仍约+0.425245 pp，但D3 OC为−0.268817 pp。

**两种比较不能混淆：VV相对C2的总体结构略好，与持续状态相对episodic存在结构代价可以同时成立。不能把历史损害直接归因于W/LSO。**

R106含资格共2,336 updates、21,048 forwards、2,336 backwards；12正式轨迹及评分完成。存在跨聊天重复准备覆盖磁盘脚本/config的事件；已恢复原冻结源和时钟并针对性核对，原formal worker未重启，评分前恢复scorer。该事件与证据边界完整保留在R106报告/RECOVERY，不称无干预独立复现。

## 5. 当前能够与不能够得出的结论

**成立的开发证据：** 普通第二视图贡献主要增益；持续历史对C2/VV均有明显宏观收益；完整W/LSO相对C2有小幅稳定增量及部分总体结构改善。

**尚未成立：** 完整VV具有足够大的不可替代增益；收益在所有域/头普遍成立；历史适应安全；独立患者泛化已获验证。相对Q0，持续C2/VV的raw宏观差分别+0.968001/+1.065251 pp，但D3 OC仍−4.189458/−4.342444 pp，去D1后分别−0.138815/−0.129341 pp。K−Q0同时混入读出差异；R91同读出Qt−Q0的D3 OC仍−2.610158 pp，提示不能全部归因于读出。

当前1951历史目标内容已暴露，192为子集；患者/眼关联及源训练重叠UNKNOWN。这限制独立确认主张，但**不意味着必须更换数据才能继续主线研究**。不能重切旧内容冒充未暴露测试集，也不能用新增seed替代独立性。

## 6. 当前研究决策（按用户最新要求）

1. 保持VV及其机制改进为方法主线。C2保持固定的简化对照，不转为C2调参项目；外部方法若用于构建主线，明确用途，不能仅因来源将其归为受限对比方法。
2. 在现有一致数据协议上，优先检验能直接指导VV改进的新机制假设：保留有益历史，同时减少局部/结构损害，并增加相对C2的额外贡献。现有结果尚不足以直接指定应修改W、LSO或Adam中的哪一项。
3. 先复用已有诊断排除重复问题，再冻结最小干预实验。不得按测试标签设计D3专用规则，或不断查看测试评分选择权重。若当前划分不能支持无泄漏的模型选择，明确开发性质并记录选择预算。
4. 主线和对比方法使用一致划分、流、读出与后处理口径，并披露合理资源及调参差异。对比方法采用标准配置，仅做正确运行、公平比较必要适配；不削弱对比以制造优势。
5. 新数据不是当前推进前置条件。独立验证可作为后续证据增强阶段，若开展则所有方法按同一条件比较，不能只给主线换数据。

本文撤回此前“先暂停完整VV、转向C2并以新数据为必要前置”的建议。调整的是研究优先级，不改变R102/R106及历史负结果。尚未冻结具体下一实验，也未因本次总结启动GPU、恢复监测或修改原协议。既有六候选窗口及P2均已结束；后续实验需新记录假设、准入、费用和停止条件，不能复活已耗尽额度。
