# Stratified reliability routing: finite TTA/CTTA mechanism pilot

Status: protocol frozen; see [Chinese route analysis and protocol](PROTOCOL_ZH.md). No scientific result is claimed by preparation checks.

The candidate is an explicit adaptation of Reliability-TTA to independent OD/OC Bernoulli outputs. It uses current-image reliability within frozen-source predicted foreground/background/boundary strata, a source-posterior anchor, and BN-affine updates with frozen running statistics. It is neither the author's implementation nor a claim that ordinary gating, balancing or KL anchoring is novel. RDC and ENGRAM are disabled.

Ten learners cross per-image reset versus continuous affine/Adam state, two fixed orders, and five blocks (clean, gamma, RGB, blur, clean return). Both pre-update and post-update predictions are retained. Five static references retain source-eval/current-image BN and the previously trained D/R correction frontier. The complete matrix is 3,600 readouts, 40 learner trajectories, 1,600 arrivals and 128 unique legacy-reference parity checks. The primary comparison is STRAT minus RANDOM on retained-state post-update Dice. Eight reused development contents cannot establish independent-patient generalization.

Implementation: `src/dpa_ctta/srg_ctta/`, tests: `tests/test_srg_ctta.py`, config: `configs/stratified_reliability_ctta_v1.json`. Prepare a new approved run directory with `code`, `private`, `scorer`, `public`, `predictions`, `gates`, `gate_predictions`, `processes`, `attempts`, and `logs`. Bind the registered data/checkpoint and prior roots privately. Use only the preceding eight query RGB records in the worker panel and keep their masks in the scorer-only panel. Preserve the pinned reference/GraTa environment. Use the existing neutral interpreter and entry convention with `DIAG_MODE=controller`; it runs one capped GPU worker and then, only after successful retirement, an independent CPU scorer. No target label enters gate, updates, normalization budgets or future-stream decisions.

The actual second-step gate and its corresponding pre-second-update prediction are preserved for post-hoc whole-image and true-boundary error audits. Those artifacts and per-case scores remain private. Public delivery contains source/configuration, anonymized aggregates, report and sanitized execution receipts. Each subsequent user-authorized improvement must have a separate frozen protocol and budget; it must not replace this round or erase failed attempts.
