## Native histories and isolated diagnostics

Two independent native A hosts start from the same source state and seed. Each visit restores that host's own CPU/CUDA/NumPy/Python RNG, runs the unchanged native step, then records its resulting RNG. Reference and watched logits, prompt, Adam, counters, memory, buffers, source gradients and RNG are compared. Counters/steps/identities and RNG are exact; floating comparison tolerance is rtol=1e-4, atol=1e-5. Read-only optimizer pre-hooks capture the actual initialized prompt and pre-step moments after native backward; no additional initialization or native step is performed. Observational wrappers count actual retrievals and pushes without changing their return values.

Only after the native step finishes, separate source-loaded diagnostic models compute N/G/I. N uses the original standard source BN model and no prompt. G uses all-one prompt and AdaBN. I uses the captured initialization. U is the completed watched output. G/I recompute their own current statistics with the current native sample count and `new_sample=False`. Separate source models isolate hooks, buffers, bn_loss and .grad; nothing is written back to either history. A procedural identity-prompt FFT/IFFT check precedes real scoring. If it exceeds the frozen tolerance, G−N is labeled normalization plus identity-prompt numerical-path change.

At positions 1,2,3,4,17,18,19,20 per task, all six isolated one-step branches restore the same actual initialized prompt and copied pre-update Adam moments/step. Source tensors are frozen only in the diagnostic models; native A source-gradient behavior remains intact. The isolated current-image host gradient must match the captured native prompt gradient. A_cf must reproduce watched prompt, optimizer and prediction. Native AdaBN statistics are recomputed, never borrowed across branches.

The H/R/D gradient graphs are evaluated separately, retaining full K=4 for proxy supervision. Linear combinations of their raw gradients implement the prescribed joint loss before a single Adam step; this avoids retaining both query and K=4 proxy graphs simultaneously. It does not split the proxy batch or apply multiple optimizer steps. Raw and actually weighted norms, pairwise cosines, Adam update norms and distance from A_cf are scalar observations. Query-label gradient Q and oracle branches are computed only after all non-oracle branch predictions/updates are fixed. All six branch states are discarded, including their optimizer moments. Only the native A histories proceed to the next visit.

Per-channel metrics reuse the original evaluator and add actual thresholded foreground, FP/FN and denominators, plus Fundus OC-outside-OD ratio using predicted OC count as denominator. Zero denominators yield null. Before/after branch region loss, Dice and area refer to I and the one-step prediction. Norm/init/update differences are conditional on the fixed replacement order, not a unique causal decomposition. Oracle branches are source-label offline diagnostics, not an online method, performance upper bound or main method result.
