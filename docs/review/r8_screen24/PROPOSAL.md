# R8 24 小时筛查方案（待实施、未启动）

## 结论

可以把目标缩为一次 A/B 初步有效性与历史状态作用筛查。推荐 **10 个 source job、40 条 target 轨迹**。根据 SHA `654848c5fa8ecf9cc33e3bd73dac4cacea50b2e6` 的三卡实测单元成本推算，三张卡合计约 **49.0 GPU·小时**，考虑阶段依赖后的队列约 **18.1 小时**；再预留 2 小时汇总和额外 I/O，约 **20.1 小时**。这些计算已包含 1.3 时间安全系数。

这是对**正式启动后的运行时间**的估计。新入口、oracle 分片等价检查和最终资源资格核验尚未完成，其实施耗时未计入；不能承诺从当前消息起 24 小时必定交付。

## 冻结候选与任务数

- A 固定 `A_r32_a0p3`；B 固定 `B_expanded_global_aux1p0`。这是预先选择的两个较大容量候选，未据 target 结果挑选，也不能声称它们是最佳配置。
- A/B × FULL/STATIC × 两个源种子 = 8 个任务；匹配 B 输入和 rank 的 CURRENT-MLP × 两个种子 = 2 个任务。合计 10。
- 源种子保留 20260924、20260925；目标随机种子对应 20260907、20260908。
- 每个模型训练 4,000 步，保留第 1,000/4,000 步快照。沿用原 16,000 步学习率曲线的前 4,000 步，不重新缩放 LR；明确报告为有限训练预算筛查。
- A/B 两个快照各自独立校准 1,024 步，保留完整 64×32 source-val，记录校准前后指标；按原 soft Dice 规则跨两个种子选共同快照。
- 保留目标 order 0/1、完整 1,951 次访问和 1,695 个主要评分内容，不截断图像流。

| 目标任务 | 数量 |
|---|---:|
| A/B FULL/STATIC 与 MLP：10 个源模型 × 2 orders | 20 |
| VPTTA、C-CTTA、G-CTTA：3 × 2 seeds × 2 orders | 12 |
| N、C0、R7 C FULL/STATIC：4 × 2 orders | 8 |
| 合计 | 40 |

共 78,040 次 target arrival、67,800 条主要评分记录。确定性对照每 order 只运行一次，不冒充独立种子重复。

## 24 小时内的关键条件

只保留幅度 0.3，但该幅度的 512 fit、128 cal、128 val oracle anchors 全保留，各 256 步、LR 0.03。将这 768 个独立 anchor 拆为三个预先固定的 256-anchor 任务并行，保持每个 anchor 的初始化、support/query、keyed augmentation 和计算完全不变；合并时按原 ordinal 排序并核验完整身份与覆盖。**必须先验证串行/分片等价性。**

保留共同 scaler、A32/B64 basis，容量探针只保留这两个实际使用空间，各 64 anchors×128 步，LR 0.03。容量结果作为报告诊断，不用于 target 调参。

采用按测量预算优先调度较长任务，三阶段保守屏障的预计耗时：

| 阶段 | 墙钟时间，已含 1.3 余量 |
|---|---:|
| 并行 oracle、共享 scaler 与 basis | 4.73 小时 |
| 10 个源训练/校准/验证任务及容量探针 | 8.97 小时 |
| 40 条在线轨迹及独立评分 | 4.39 小时 |
| 汇总与额外 I/O 预留 | 2.00 小时 |
| 合计 | 20.10 小时 |

沿用原来单 GPU 串行 oracle 准备入口时，同一缩减方案连同 2 小时预留约需 25.9 小时，不能宣称 24 小时达标。单纯用 49 GPU·小时除以三张卡也会低估阶段依赖。

## 删除与保留的研究问题

删除 12 配置搜索、额外三个种子、orders 2/3/4、MIXED/LONG10、B 的目标梯度 LR 搜索与 G1/G3/COLD 诊断、额外同权重消融、跨幅度/rank 容量扫描及可选外部方法接入。

仍可初步回答：A/B 在固定训练预算下相对当前基线是否有收益；FULL 相对 STATIC 是否受益；B 相对简单 MLP 是否有额外价值；两个种子、两个主要顺序是否出现明显不一致。

不能回答：最优配置、收敛后的性能上限、五种子稳健性、回访顺序/十轮长流稳定性、rank 或调制幅度的独立因果贡献、是否需要目标梯度。训练不足导致的负结果不能当作方法无效的最终证据。两个种子只提供初步稳定性线索，主要报告每 seed/order 的配对差异，不把图像数当独立训练重复。
