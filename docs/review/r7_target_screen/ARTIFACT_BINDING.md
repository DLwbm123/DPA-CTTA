# Artifact and authority binding

The existing SOURCE_PREP `artifacts.json` is consumed unchanged. Exactly A_FULL, A_STATIC, B_FULL, B_STATIC, C_FULL and C_STATIC must be present. Each inventory row binds `<name>.pt` by SHA256 and length, `<name>.context.json` by file SHA256, and the context's canonical payload digest. `ARTIFACT_INVENTORY.schema.json` describes the inventory wire format; explicit production checks do not require a new JSON-schema dependency.

`binding.source_release` requires REVIEWED status, artifact_identity equal to the inventory file SHA256, a real external source-release review reference, trusted_loader_verified=true, and exact source manifest/split SHA256. These are PENDING in this delivery. Contexts must be R7_INFERENCE_CONTEXT_V1, source status BOUND, correct original checkpoint/manifest/split digests, the exact group/FULL-or-STATIC mode, and no ablation. Preflight checks all six artifact files before target reads. Each applicable fresh job additionally calls the existing `load_artifact` -> `inference_from_tensors` -> `OnlineHost(expected_context=...)` chain; no candidate-derived expected weights or environment can substitute for trusted release metadata.

The original checkpoint is independently bound to the frozen registration by digest and byte length. It is decoded from verified bytes with weights_only=True. C_BASE uses the unchanged historical `b1_host.Host('C', state, 'cpu')`. C0 derives only its zero-method context descriptor from A_FULL's trusted source/environment identity; the candidate segmenter must match that trusted environment. No source RGB, masks, source diagnostics or oracle records are deployment inputs.

The disabled authorization template enumerates the complete binding: exact clean code HEAD, science hashes, exact 24-job matrix and target seed, registration file digest plus canonical registration/recurrence digests, inventory file digest, source review/provenance, checkpoint identity, target/artifact/output roots and full resources. `execution_layer_review.binding_sha256` is SHA256 of canonical JSON of this entire binding. Its PASS/scope/reference plus the user receipt's granted/scope/id and matching resource receipt are mandatory. Wrong scope and disabled receipts reject before any input reads or device probes.

Future resources must specify device=cpu, physical_GPU_ids=null, runtime matching hostname/system/machine/Python/Torch/CPU-count/threads, workers in {1,3}, two threads, finite integer wall/output/asset/decoded-image limits, retry=false and resume=false. Current CPU qualification does not qualify CUDA. A future GPU implementation/qualification requires its own code and review binding, with a separately approved numerical smoke; this package makes no GPU runtime claim.

SOURCE_PREP SHA and training runtime are not substituted by target SHA. Source provenance remains in the trusted contexts; target execution binds its own code revision. Real source artifacts are absent from this source-only review package.
