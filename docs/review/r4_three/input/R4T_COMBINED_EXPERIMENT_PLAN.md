## 0. 为什么新增第五条 G，而不是再新增一条无关路线

保留：

- **A：教师时间尺度 × RP。** 检验伪监督来源是否影响区域记忆的增量。
- **B：KDG。** 研究受约束的新增卷积可塑性；属于第三条“更新几何”的主题性补充，不伪称已经胜出的 U_PCA 版本。
- **C：边界锚定图监督 G_BOUND。** 明确继承原五框架的第五条 G：仍用图结构形成训练教师、仍更新 C 的 BN affine，但改变图的作用范围、锚点政策和边证据。

选择G不是因为它已成功：R3 G_PCA比C低0.114493pp，也低于G_ISO和G_ORDER。实际代码对32×32整图进行软约束优化，并在上采样后做全图包含投影。其图能量下降、教师包含违反归零，没有转化为分割增益。[S1,S8]

这支持一个**可检验但未被证明的候选解释**：图的有效作用应局限于尚不确定的轮廓邻域，不应改写已一致的区域内部；并且当前图像的局部颜色证据可以补充模型自身特征，而不必继续依赖历史PCA精度矩阵。

本次不是把G的lambda调小重跑。新增方案把软全图优化改成**硬固定域 + 局部自由域**的图边值问题。它使用更细的128×128网格；由于同时改变了网格、能量、边证据和支持范围，**与旧R3 G的差不能独立归因于某个单一因素**，需要本批G_CONST/G_SHUFFLE/G_GLOBAL控制。

T与A都修改教师，作为新增路线的差异较小；M的迁移增益已被恒等POST控制覆盖；S在R3中真正发生复用却落后共享状态。本版因此选择G，而不再调整T密度、M旋转或S路由阈值。该选择是有限资源下的研究判断，不是这三类方法普遍无效的结论。

**“提高容错率”的准确含义是分散所检验的机制假设。** 三条路线仍共享checkpoint、无标签自监督及已暴露目标数据，失败风险并不独立；不能把三个候选称为三次独立成功机会或保证至少一个有效。

## 4. 方向 A：保留原 R4 科学定义

### 4.1 教师与学生

学生记作 f_(w0,ψ)，教师记作 f_(w0,ψbar)。教师与学生都使用 C 的当前输入统计。教师无 optimizer，全部参数不参与反向。

q_t = sg[(1/6) Σ_j T_j^(-1) sigmoid(f_(w0,ψbar_(t-1))(T_j x_t))]。

六个原有几何视图分别前向；不堆成 batch=6；不锐化、不混源概率、不做 hard target。

- C/RP：ψbar_(t-1)=ψ_(t-1)。
- MT/MT_RP：ψbar_0=ψ0；学生最终输出、memory commit 后，ψbar_t=0.99ψbar_(t-1)+0.01ψ_t。
- FT/FT_RP：ψbar_t=ψ0。

FT 是“初始 C0 前向规则的六视图教师”，不是 No Adapt source-BN。EMA 不加 warm-up、偏置校正、域相关动量或阈值门控。

学生目标：

L_A = BCEWithLogits(z_student_strong, q_t) + λ_RP L_RP。

无 RP 时 λ_RP=0，有 RP 时固定为 0.05。

### 4.2 RP 的公式和坐标不变

复用原绝对重建函数：

L_RP = Avg_(r,u) ||(I-U_r U_r^T)(v_s-μ_r)||² /
                   (sg[||v_s-μ_r||²]+ε)。

保留原函数的 epsilon、归约与空区域处理。32 维 `seg_head` 输入；32×32 网格；rank≤8；OD_bg/OD_fg/OC_bg/OC_fg 四 bank；每区域每图最多 32 个 token；16 张贡献图/128 个向量后允许使用；每 16 张非空贡献刷新；累计 Welford，无遗忘、迁移或路由。

BCE q、hard 分区、可靠性和实际待写入位置均来自本臂教师。可靠性仍为 q≤0.1 或 q≥0.9 且六视图 hard 一致。可靠性只控制写入，不能暗中改变原 RP loss 的全部区域归约。

**存储特征来自学生更新前原图，不是教师或 post 特征。** MT_RP/FT_RP 额外做一次学生原图无梯度前向取得 f0_student，所以是 9 次前向。其余 A 臂 8 次。

### 4.3 A 时序

当前 RGB → 过去 memory 快照 → 教师六视图 q → 必要的学生 pre 特征/待写入选择 → 学生 strong loss → 一次 Adam → 学生原图最终预测 → memory 合并 pre 特征 → EMA 状态更新 → evaluator 才读取 mask。

不能用当前图更新后的 EMA 重新产生本图目标，不能将本图提前并入自己的 PCA。

## 5. 方向 B：KDG 卷积核空间细节保持的几何适配

### 5.1 假设与真实创新边界

假设：除 BN 通道缩放/偏置之外，还需要有限的跨通道响应调整；但不必自由改写卷积核中对空间差分的响应。使用源权重可解析的结构来限制这部分适配，可能优于伪标签决定的保护方向。

原 C 已经冻结全部卷积权重；所以 KDG 相对 C 是**受限地增加卷积可塑性**，不是比 C 冻结更多内容。它要证明这种新增自由度值得开放，而不只是证明自己能保持已规定的 kernel 不变量。

这不是“低频一定是风格，高频一定是解剖”的定理。空间 DC kernel 也不是严格截止频率的图像低通滤波器。这里的可证明性质仅是**选定卷积核的零均值空间部分保持不变**，不等于整网边界、拓扑或旧域准确率保持。

### 5.2 两个预先固定的实际入口

| 路径 | 源权重 OIHW | stride/padding | 理由 |
|---|---|---|---|
| `res.conv1` | [64,3,7,7] | 2 / 3 | 最早局部 RGB 响应 |
| `res.layer1.2.conv2` | [64,64,3,3] | 1 / 1 | 首个残差 stage 的末端空间卷积，影响高分辨率 skip |

均 groups=1、bias=False。路径与结构已从固定依赖源码核对。[S4] 实现时程序化枚举确认；若不匹配，不按得分改选层，不臆造等价路径。只报告真实结构差异并保留其他可实现工作。

本批不扫描插入层，不触碰 1×1 segmentation head，不更换 BN 统计，不加入新的分割头或边界网络。

### 5.3 空间分解

设一个 kernel 为 W0[o,i,s]，s 遍历 K=kh×kw 个空间位置。定义单位 DC 基：

b(s)=1/sqrt(K)，A0[o,i]=Σ_s W0[o,i,s] b(s)，H0=W0-A0⊗b。

于是 Σ_s H0[o,i,s]b(s)=0，W0=A0⊗b+H0。A0 是 O×I 通道矩阵；H0 是本计划所称的“空间细节项”，不是人为解剖标签。

### 5.4 KDG 有效权重

新增 I(I−1)/2 个坐标 u，填入 S 的严格上三角，下三角为其负值，对角为 0。令：

Q = solve(I + S/2, I − S/2)，D=diag(exp(a))。

u 和每个输出通道的 a 均初始化为 0，故 Q=I、D=I。不要用零态 Python 分支直接返回原权重，否则会切断初始梯度。

A_t = D_t A0 Q_t，W_eff = W0 + (A_t−A0)⊗b。

每次前向生成有效 kernel，不改写底层源 `.weight`。小矩阵运算 float64、同模型设备；有效 kernel 转回 float32，保留经过 cast 的梯度。使用残差形式，避免 H0+A_t⊗b 重建在初始化时改变源 kernel。

**不对 gain 进行隐含 clipping，不做额外正则或恢复。** exp(a)>0，但不宣称幅度有界。非有限值按已有工程错误处理，不临时夹断后继续。

### 5.5 两个局部代数性质

1. **空间细节保持：** H_eff=H0，kernel 任意两个空间位置的差保持不变；ΔW 只存在于 spatial-DC 模式。
2. **DC 行夹角保持：** 对非零 A0 行，cos(A_t[o],A_t[p])=cos(A0[o],A0[p])，因为右乘 Q 正交且每行仅有正缩放。

不得把第 2 条扩大为“整个 flattened kernel 的夹角保持”：KDG 只保护 DC 矩阵的角度。K_ALL 才有完整 kernel 行角度保持性质。

对同一个局部输入 patch x，新增输出为 Δy_o=Σ_i ΔA_oi Σ_s b(s)x_i(s)。因此，对每输入通道都具有零空间均值的 patch 扰动 δx，(W_eff−W0)δx=0。这个恒等式条件是同一个局部输入；上游 BN 或其他层改变输入后，不可推成整网函数不变。

### 5.6 三个控制

**K_ALL：** 使用与 KDG 完全相同的 u/a 数量，在每个空间位置上执行 W_eff[o,:,s]=exp(a_o) W0[o,:,s]Q。不保留 H0；用于检验“只开放 DC、保留细节”的必要性。这是 PAID 思想的受控卷积化对照，不是完整 PAID。

**K_MAG：** 只学习 a，Q 永远为 I，其余为 KDG；检验是否只需要均值项幅度调整，而不需要跨通道方向学习。

**K_FREE：** 学习 E∈R^(O×I)，E0=0；A_t=A0+(||A0[o,:]||/sqrt(I)) E[o,:]。不额外学习 gain，不约束角度；仍只更新 DC。检验简单的通道均值项自由修正是否已经足够。源 DC 零行在所有 DC 臂保持零，不添加人工最小源范数或随机源方向。

KDG 与 K_ALL 参数坐标数相同；K_MAG 更少，K_FREE 更多，学习率相同不意味着函数空间步长相同；后续当前统计 BN 还可能抵消 K_ALL 的部分整通道幅度变化，因此等参数坐标不等于等有效自由度。必须报告实际有效 kernel 位移，不能伪称所有控制等参数/等 FLOPs，或从 K_FREE 一次失败直接证明角度约束的因果必要性。

### 5.7 参数与优化

| 臂 | 新参数 | 原 BN affine | 合计可学习标量 |
|---|---:|---:|---:|
| KDG | (3+64)+(2016+64)=2,147 | 19,136 | 21,283 |
| K_ALL | 2,147 | 19,136 | 21,283 |
| K_MAG | 64+64=128 | 19,136 | 19,264 |
| K_FREE | 64×3+64×64=4,288 | 19,136 | 23,424 |

先按原 C 配置 BN，再安装新参数化并组装确定顺序的 optimizer 参数列表。一个 Adam 同时更新 BN 与新增坐标，全部 lr=1e-4、其余设置相同。原始源卷积、bias、分类器和其他非 BN 参数全部不被 optimizer 拥有。底层源 tensor 不变与有效权重变化分别记录。

B 的六视图目标来自本臂当前更新前模型（包含该臂当前有效 kernel），strong 分支仍只优化原 BCE。无 EMA、无 PCA、无额外 loss、无 Jacobian。

B 每图 8 次网络前向、一次 backward/Adam。虽然调用次数不增加，参数化矩阵求解和卷积 weight-gradient 会增加工作量；不得声称与 C 等 FLOPs 或无额外耗时。

### 5.8 B 时序与冷启动测试

当前 RGB → 当前有效 kernel 下六视图 q → strong BCE → 一次 Adam 更新 BN+kernel 坐标 → 新有效 kernel 下学生原图预测 → 固定在线状态 → evaluator 读取 mask。

新增参数从第一张图即参与更新，无 ready/warm-up。**只要求零初始化的更新前函数与 C 一致；第一步更新后的 K 输出不应被强制等于 C。** 另在新坐标强制冻结为零的程序化测试中验证完整 C 轨迹退化对齐。不能照搬 R3“未 ready 的所有新臂首步 post 必须等于 C”的断言。


## 6. 方向 C：原第五条 G 的边界锚定图监督改造

### 6.1 要改变的不是输出平滑，而是训练目标的形成方式

原图六视图概率均值仍为q；图模块输出q*仅作为strong BCE的停止梯度目标。最终网络预测不做图求解或包含后处理。

```
当前原图RGB ──→ 局部颜色边权 ─────────────┐
当前学生六视图 ──→ q、可靠位置、轮廓带 ──┼→ 受限图传播q* → strong BCE
                                         │                      ↓
                                 没有历史图缓存            一次BN affine Adam
                                                                ↓
                                                        原图网络最终预测
```

G不调用EMA/固定教师、不接RP loss或PCA bank，不使用KDG参数化，不新增分类器或图网络。与A/B同批比较，而不混合其预测或状态。

### 6.2 输入和两个网格必须明确

原`pixel_rgb`已经是读取器resize后的CPU float32 [1,3,512,512]、范围[0,1]。[S11] 图分支使用这一份原始RGB，不能用strong图或改变模型的min-max预处理。

缓存原六视图已逆变换的概率`views`=[6,2,512,512]及其原均值q=[1,2,512,512]，都detach。沿用C概率平均的顺序，不平均logits。

只对图分支做4×4平均池化：

qg=AvgPool4(q)，p_jg=AvgPool4(p_j)，Ig=AvgPool4(pixel_rgb)。

得到128×128图网格。它与RP的32×32中心采样不是同一操作，严禁复用旧`grid`冒充平均池化。OD/OC仍是两个独立二值通道，不做互斥softmax。

### 6.3 固定锚点与可变边界域

在任一分辨率上，可靠条件仍为：

R_c(u) = [q_c(u)≤0.1 或 q_c(u)≥0.9] 且所有六视图的hard预测都等于[q_c(u)≥0.5]。

在图网格上，由h_c=[qg_c≥0.5]的真实四邻接类别变化标记轮廓的两个端点，不把图像外部padding视作背景。将这个轮廓膨胀Chebyshev半径2格（约对应原图8像素halo）。

主臂自由域：F_c = dilate(contour(h_c),2) ∩ ¬R_c。

G_CONST/G_SHUFFLE使用完全相同的定义。G_GLOBAL改为F_c=¬R_c，取消轮廓范围限制，其余相同。

**所有自由域之外的位置固定为原qg软值。** 可靠位置是固定点；边界带外的不可靠位置也固定为原qg。不把可靠点强制变成0/1，不要求出现人工种子，不读取GT来校准置信度。

没有轮廓或自由域为空时，主臂q*=q，仍照常执行一次C更新。无前景、无背景或少数不可靠位置不构成运行失败，也不触发搜索/扩带。固定置信度可能保留自信错误，这是已承认限制。

### 6.4 图边证据来自当前图像，而非历史协方差

图为128×128四邻接，无自环、无首尾wrap-around，共32,512条无向潜在边。

对Ig逐通道计算本图空间均值m和总体标准差s，定义：

c(u)=(Ig(u)-m)/max(s,0.05)。

此标准化仅用于图距离；绝不替换C模型输入或BN统计。对于相邻u,v：

w_uv=max{ exp[-||c(u)-c(v)||²/(2×0.5²)], 1e-4 }。

只用当前RGB局部差异。较强颜色边会减小跨边传播，但颜色边可能是血管或光照而非OD/OC边界；不宣称能从RGB直接得到正确标注。

控制：

- **G_CONST**：水平方向全部边取原水平边均值；垂直同理。匹配各方向边权总和，不把全部边设1而无意增大总强度。
- **G_SHUFFLE**：水平/垂直边权分别按固定局部随机数打乱，保留边权多重集合和图端点拓扑。种子为SHA256(`R4T_G|20260907|visit|h或v`)前8字节big-endian取模2^63−1；不消费全局增强RNG。
- **G_GLOBAL**：与主臂相同原RGB边，只放宽自由域。

这些控制匹配定义和部分权重统计，不匹配每个节点度、实际teacher位移或不同轨迹中的置信mask。后者随模型状态分化，必须记录，不强制跨臂共享状态。

### 6.5 有正保真项的受限图能量

对每个通道求：

E_c(Q)= 1/2 Σ_(u∈F_c)(Q_u-qg_u)² + λ/2 Σ_(u,v∈E) w_uv(Q_u-Q_v)²，

约束Q_u=qg_u（u∉F_c），固定λ=1。

这是带原软标签保真项的图传播，不是无约束纯平滑；即使某种可靠类别未出现，正保真项也使问题定义完整。图的目标是修正不确定局部，不是强制前景比例或获得额外真值。

### 6.6 固定64步同步Jacobi，不分解巨大矩阵

令d_u=Σ_v w_uv，Q^(0)=qg。对自由位置：

Q_u^(k+1) = [qg_u + λΣ_v w_uv Q_v^(k)] / [1+λd_u]。

固定位置每次均直接拷回qg。使用CPU float64，固定64步；不因energy或Dice“足够好”而改变迭代预算。禁止原地Gauss-Seidel更新冒充同步Jacobi。

无需构造16,384×16,384矩阵，仅保留二维邻接stencil和两通道概率。因为w≤1且最多4邻接，固定λ=1时Jacobi无穷范数收缩因子不超过4/5。每一步是原q和邻域概率的非负凸组合，因此概率保持在[0,1]；固定节点按构造不变。这些是本图求解器的代数性质，**不是分割正确性、边界保持或抗遗忘定理**。

### 6.7 只把图残差回写到允许的全分辨率位置

在图上定义Δg=Q^(64)-qg；图自由域外Δg严格为0。

1. 将Δg双线性上采样至512×512，align_corners=False；不是上采样低分辨率q覆盖原q。
2. 将图自由mask nearest上采样，得到Fup。
3. 全分辨率重新用原q和六视图计算Rfull。
4. 定义M=Fup ∩ ¬Rfull。
5. q*=where(M, clamp(q+upsample(Δg),0,1), q)。

**M外与Rfull内必须逐值保留原q；插值不允许把修正溢出到这些位置。** 不加log-odds修正、全图OC≤OD投影、额外锐化或输出平均。这是与旧G不同的明确策略，不是遗忘一个实现步骤。

两个通道独立求解，q*不保证OC≤OD。记录违反数，但不按违反自动修正或停跑。全背景仍可能稳定存在，方案不能自行发现没有被教师提示的器官。

### 6.8 在线更新与因果隔离

学生loss仍是全图普通BCEWithLogits(strong_logits, detach(q*))。不按自由域单独归一化，不增加图loss，不改变学习率。每图六弱前向+strong前向+更新后原图前向=8；1 backward/Adam，0 VJP。

只保留原C的BN affine/Adam/RNG。q、q*、边权、mask在当前辅助评价后释放，不缓存历史图像或图状态。

**教师只改边界，不等于学生只改边界。** 共享BN参数更新后可以改变任何位置的最终预测。因此不能将q*的固定域性质写成最终分割“安全保证”。

### 6.9 明确风险和为何仍值得一次比较

已有G负结果不能唯一定位为过平滑；我们没有完整的R3教师纠错记录。新方案同时改变自由域、硬锚点、图网格、RGB边和能量，所以必须以本批控制归因。

其价值假设是：在已有大致正确分割附近，当前图像可提供局部差异，硬固定可靠/远离边界位置可减少无差别改动。其局限是：错位大或自信全错时没有恢复能力；高置信锚点也可能错；血管边、照明边可能误导；图范围太小可能没有效果。不得因一次无效自动扩大带宽、增大lambda或加入PCA精度矩阵。

## 7. 共同评价与新增图证据

### 7.1 A/B评价不变

全部十四臂评价当前q的教师Dice/Brier及GT前景/背景分项；前三个RP臂另评实际写入、已去除零向量的token质量。没有memory的臂标NOT_APPLICABLE，不伪造shadow bank。

K系列继续记录source kernel不变、DC/detail位移、正交误差、相应Gram、gain和实际有效kernel位移。不增加Jacobians或旧域模型probe。

### 7.2 G的教师纠错评价必须利用本轮已经得到的q/q*

在当前学生输出和在线状态固定后，evaluator才读取当前mask，对G额外计算：

- 原q与q*的OD/OC Dice、Brier及前景/背景Brier；原q和q*分别用相同0.5阈值。
- 相对于GT，错误→正确、正确→错误、正确未改、错误未改的像素数；分别给全部像素、允许域M和实际hard-flip域的分母，避免把没有翻转算成纠错。
- q*−q的改动覆盖和绝对概率差；全分辨率可靠位置和M外的最大差应为0；锚点实际正确率仅事后评价。
- 最终学生对GT的主指标仍独立列示。不能因为q*更好而改成输出q*。

GT先由原evaluator映射到预测栅格再计算；不要使用GT确定图mask、边权、带宽、停止迭代或选择方法。所有完整概率图、mask与边张量只存在于本图瞬时内存，落盘只留标量；后续CPU重算可检查计数关系和聚合，不能宣称从标量重建完整图解。

这里的q对GT辅助评价是本臂轨迹上的监督质量，不是独立的无适配后处理baseline；不据此声称排除了全部test-time ensembling或后处理解释。

### 7.3 时序

当前无标签RGB → 只由已允许信息构造q/q* → strong loss → 一次Adam → 原图学生预测 → 全部无标签状态commit → evaluator读取当前mask → 主/辅助标量 → 清空瞬时张量。

## 9. 三方向选择规则

### A（不变）

MT−C、FT−C；RP−C、MT_RP−MT、FT_RP−FT；MT_RP−RP、FT_RP−RP，以及MT/FT比较。RP贡献必须相对相同教师的无RP臂评估，不能把教师收益算给PCA。

### B（不变）

KDG−C、KDG−K_ALL、KDG−K_MAG、KDG−K_FREE。简单幅度或自由DC已足够时，不硬留旋转或角度约束；不把局部kernel不变量当成整网准确率保证。

### C（新增）

G_BOUND−C、G_BOUND−G_CONST、G_BOUND−G_SHUFFLE、G_BOUND−G_GLOBAL；三个控制各自−C。旧R3 G/RP结果可作背景，不能代替同配方直接控制。

- G_CONST相当或更好：不能主张RGB边的必要性。
- G_SHUFFLE相当：缺乏正确边权位置关系的证据；可能只是重新平滑或调强度。
- G_GLOBAL更好：不能主张限制边界域更好。
- 只有teacher q*辅助指标改善：不能晋级，最终学生才是主输出。
- G_BOUND净赢C且直接控制支持关键机制：保留这一图监督改造；它不因此成为完整SPEGC复现或经典图分割的新发明。

沿用四主序mean−C至少+0.5pp、至少3/4主序同向的资源选择参考；域均值−2pp、最差同序−0.5pp为明显风险提示。这些都不是显著性/临床/TMI门槛。辅助指标不替代主终点；仅在回访改善时只能作为回访专门证据。

三方向对C的排序仅是总体筛选，不用不匹配的跨路线差解释特定模块因果关系。多路线都可能因同一伪标签问题失败。全部为开发证据，不做事后按医院拼算法，不因多臂里总能挑出一项小正差而宣称泛化成功。

本批停止后再选择：保留有效的最小方案；两路线都有效时也不自动组合MT_RP+KDG+G；都不清楚时归档本批，不扫描教师动量、卷积层、图半径、边温度、PCA rank直到成功。
