# Method provenance and evidence boundary

The implementation follows the user-supplied `02_METHOD_SPEC.md`, the exact `r3_science_proposal.json` bytes, and the supplied reference kernels. These are five proposed segmentation frameworks, not complete reproductions of five papers. No paper performance, theorem, clinical safety, venue or novelty claim is established by this implementation.

| Framework | Direction attributed by the supplied package | Implemented project-specific design | Not imported / unverified here |
|---|---|---|---|
| T_LR | BayesTTA class-conditional density supervision; SicTTA summary-level density direction | Frozen given-checkpoint feature frame; separate OD/OC binary density pairs, shrinkage/LR8, log-evidence correction; ISO and DIAG controls | No CLIP text prior, hypothesis-test/self-paced procedure or BayesTTA performance inheritance |
| U_PCA | KeepLoRA direction protection; SplitLoRA summary-level stability/plasticity split | Regional feature-to-BN Jacobian; one real Adam proposal; parameter-space proximal displacement; feature-QR random and same-norm controls | No LoRA, no direct 32D projection of 19,136D parameters, no inherited retention theorem |
| S_JOINT | MoIE expert reuse; ReservoirTTA style routing | Capacity-three affine/Adam/regional-memory pool, frozen-checkpoint descriptor, fixed unlabeled novelty rule; SHARED and NOPCA | No MoIE KTI, KFF source statistics, model ensemble, whole-model-per-slot replication or calibrated novelty guarantee |
| M_TRANSPORT | LCA compatibility of historical objects with changed representations | Equal-region same-position current pre/post Procrustes; O(32), no determinant correction; live and cached statistics transported; IDPOST and SHUFFLE | Not LCA's original objective; not exact re-encoding of historical features |
| G_PCA | SPEGC structural/graph supervision | PCA precision geometry on 1,984 grid edges; fixed 32-step Bernoulli mirror/prox solver and containment projection; ISO and ORDER | No prompt pool, OT sparsification or original learned graph solver |

The package's [source note and primary-paper links](06_PAPER_PROVENANCE.md) record the summary-level evidence and unknowns. This coding stage did not independently obtain or review those papers' full texts. Source attributions above are explicitly package-attributed; the formula authority here is the supplied project specification. Missing paper details were not guessed or substituted. Paper PDFs and unknown-license paper code were not copied.

`src/dpa_ctta/r3/kernels.py` preserves the supplied tensor formulas. `test_r3_reference.py` ports the supplied 24 tests to repository imports; its matrix check targets the generated repository plan. The untouched package reference tests were also run first, with their actual standalone log retained. Host glue, cached statistics, contexts, execution wiring and CPU audit tests are repository additions.

Existing provenance anchors remain unchanged: `b1_host.py` imports the pinned GraTa dependency (`33ae20d664f305af34739ec54a5bec7da53ffa0b`) and its original augmentation functions; the model bridge uses CTTA commit `dbff0d985c6c95345d9fb78f5b1daef57b392564`. R1 C/REGION paths, verified-byte readers, evaluator, NFS scan and supervisor retain their original source. No extra trainable component or third-party dependency was added.

Implementation details made explicit for review: density covariance/mean are lagged snapshots refreshed with the fixed 16-contribution statistical cadence; current-step live data never modifies its own teacher. Zero-rank raw PCA still permits a shrunk density snapshot after support thresholds. New random namespaces use the existing seed helper with a positive fixed index (1); the scientific seed is unchanged. Graph zero-edge control is returned exactly rather than accumulating 32 iterations of round-off. These choices do not edit the supplied science JSON; reviewers should assess their alignment with the snapshot and fallback wording.
