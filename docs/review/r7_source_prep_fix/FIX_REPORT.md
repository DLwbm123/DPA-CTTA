The common path guard fixes sibling Output/ordinary callers; no resolve is used to hide a link. Parents are validated at preflight and output construction. This is not a new claim of race-free directory handling against an adversarial concurrent namespace replacement.

The global reserve is 98304 bytes. Six slots cover supervisor first/cleanup/resource/evidence errors, supervisor summary and completion. Error records are at most 16384 bytes each; exception messages are clipped to 3000 characters. Pending/error completion takes the success branch with no preceding supervisor failures, so it also fits the terminal envelope. Parent evidence counts the entire tree including already completed child evidence; the previous 64 KiB per-writer reserve remains an additional guard, not the global accounting source. A burst may cross the cap between polls; this is detected and fails, never labeled success. Existing payload is retained; if disk/cap prevents a failure file, bounded stderr is attempted instead. There is no physical filesystem quota or silent deletion/truncation.

During development a macOS timeout-child cleanup race was observed: first=TimeoutError, cleanup=PermissionError, returncode not yet reaped. The existing EPERM fallback now waits once, at most 0.5 seconds, for its owned child, then independently requires the PGID absent from ps. A still-live child or remaining process group still fails. No additional signal, process restart or change to the historical r1 stop_owned implementation. A targeted synthetic regression covers reap/timeout/group-present states.

The 32 execution tests retain all original 17 methods and add 15 methods (some have subtests). The 59 R7 regression methods are unchanged. Process/clock/storage-fault substitutes only establish those boundary branches; three short real CPU children establish owned cleanup. Encoded image/mask and checkpoint fixtures are procedural, with guarded BytesIO loads. No full real SOURCE_PREP success, runtime duration, effective state or trained artifact is claimed.

Old evidence and NEEDS_FIX remain unchanged. New test success is engineering acceptance only. The attached review's separately mentioned annex scripts were not supplied; our before-fix probes are independently authored, not attributed to those annexes.
