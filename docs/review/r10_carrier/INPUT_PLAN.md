## 5. 固定干预：缩放实际 FiLM 增量，不改变内部状态递推

对原来的每个 FiLM 注入位置，写作：

`original_output = h + delta_h(h, v)`

新诊断输出定义为：

`diagnostic_output = h + alpha * delta_h(h, v)`

保留原内部 amplitude=0.3、tanh、expm1、gamma／beta 布局。alpha 是乘在实际 FiLM 增量外面的新诊断系数，不能偷换成缩放进入 tanh 的 v、改变 amplitude、修改 BN 或输出概率混合；这些是不同干预。

alpha=0 时两处注入都是恒等映射；alpha=1 精确恢复原 B。alpha=0.25 是预先固定的干预点，不是源／目标选出的最优超参数。不得追加 0.1／0.5／0.75 等目标扫描。

READOUT_ONLY 条件下，B 的零调制观察、候选计算、ISTA、校准及内部历史递推保持原样。实际执行版必须核验：相同 history 条件不同 alpha 的 B 内部状态轨迹相同，差异只来自输出调制。若做不到，应报告不符合本实验干预定义，不把缩放后的码再写回历史后仍称纯读出干预。

这里操作的是原生 B 父载体的完整历史状态，按真实代码清零／递推；不能误用 R10 actor 的 m/q/h 状态定义。计数器只作审计，不能通过清零改变后续数据顺序。RESET 使用 B_PARENT_FULL 的同一权重，不加载独立训练的 B_STATIC。

## 9. 分析与判定

主要比较：

- 历史干预（原强度）：D(B_RESET_1) − D(B_FULL_1)。
- 读出缩放（有历史）：D(B_FULL_READOUT_025) − D(B_FULL_1)。
- 读出缩放（无历史）：D(B_RESET_READOUT_025) − D(B_RESET_1)。
- 四个条件各自相对 C0 的差，以及相对 GraTa 的剩余差距。
- 上述缩放效应在 FULL 与 RESET 下的差，作为尺度×历史交互的描述。

对每个比较报告每 order、每域、OD／OC、域等权主指标及逐图配对差分布。两个 order 用同一内容集合，不是两个独立训练种子；像素或重复访问不是新增患者。若做描述性区间，按可核实患者／来源 group 配对重采样，并明确未覆盖训练随机性；依赖关系未知则说明。

| 观察 | 决策 |
|---|---|
| B_ZERO 与 C0 不等价 | 先定位实现／身份／预处理／BN／hook 差异，不用性能表诊断算法 |
| 缩放改善 B，但仍未超过 C0 | 仅为减少调制损伤，不作为新适应收益 |
| RESET 改善，而缩放作用较小 | 当前父载体的历史递推是优先问题；不支持继续加 writer |
| 缩放在 FULL 和 RESET 都改善 | 当前输出调制尺度／方向值得研究，但不能仅凭均值断言尺度是唯一根因 |
| 源端收益为正、目标为负 | 优先研究源模拟／校准／表示迁移，不能按目标标签选门控 |
| 非零调制均未显示对 C0 的正效用 | 封存当前固定 B＋actor 配方，不自动延长训练或换种子 |
| 固定非零干预超过 C0 | 只作为新的开发假设，后续用冻结配方另行复验；本轮不把最佳格点当独立确认 |

本轮研发参考尺度改为相对 C0，而不是相对较弱的旧 R10：固定非零条件平均 ≥+0.5pp、两个 order 均为正，且需同时公开最差域／通道退化，才优先进入下一次复验设计。这是前瞻性的资源优先级尺度，不是统计显著性或临床门槛，不重新判定前一轮，也不授权中途早停／调参。

0 到 +0.5pp 的改善如实记为小幅开发信号；负结果如实保留。回到 C0 水平不叫创新成功。本轮无论结果如何，都不自动开启下一次训练。
