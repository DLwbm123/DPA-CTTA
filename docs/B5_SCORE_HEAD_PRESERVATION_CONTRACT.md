# B5 exact score-residual head policy

B4 is a valid negative Polyp transfer experiment and remains immutable. This experiment tests a structural hypothesis, not a confirmed bug fix. Only ra4_conv5.bn, ra3_conv4.bn and ra2_conv4.bn are selected from the pinned architecture. They end prediction-residual branches; earlier branch scores also enter reverse attention. They do not independently guarantee foreground area or calibration.

F freezes their six source affine scalars while retaining current-image statistics. H freezes the same affine and restores the three source running_mean, running_var and num_batches_tracked buffers explicitly from the strictly loaded source state, setting just these three modules to eval/track=True. All other BN stay train/current-statistics. Configuration is checked at construction and before every model forward. H0 uses H forward policy with all parameters fixed and no optimizer. Frozen heads preserve autograd through their inputs. No no_grad boundary is inserted in their strong-view training path.

The adapter filters the still-empty existing B4 Adam group to the exact remaining list, without altering its settings. Actual expected inventory is 150 BN, 66,212 scalars and 300 parameter tensors; F/H equality is checked. The entire PolypC.step remains unchanged. New entry all-adapt returns the old B4 PolypC. Augmentation, normalization, BCE, RNG and eight-forward sequence are inherited. Source buffers are restored from source tensors, never from None. No source file is modified.

Seven new CPU tests cover exact policy/inventory, F/H parameter and optimizer identity, frozen-head gradient connectivity, H0 stateless/fresh-H parity, all-adapt B4 parity, label/private-RNG isolation, and failed scalar-closeout rejection. One relevant B4 normalization/geometry/detached-target test is rerun, for eight current checks. Historical full test counts are not added. GPU smoke is once only, using registered source weights and programmatic inputs: four old/new all-adapt steps each (64 forwards/8 Adam), two F and H steps each (32 forwards/4 Adam), and two fresh H0/H original-view pairs (4 forwards/0 Adam). Strict deterministic scope is restored before a separate formal process. No target score is read to select a setting.

Formal work is H0 canonical once on 1,802 registered Polyp groups, order0 F then H, order1 F then H. Total 9,010 new scored records, 59,466 forwards and 7,208 backwards/Adam; including smoke 59,566/7,220/7,220. H0 CPU identity mapping creates 3,604 reference positions, not new inference. Source/DD/selector/outer/inner training is zero. One UUID-bound GPU from authorized 3-7, prefer 7 with adequate memory. Cap six active hours and 512 MiB private output. Failures retain prefix and stop without retry; no performance gate or next experiment.

Only final-original head spatial mean/population std, prediction foreground fraction, loss, gradient and actual affine update norms are persisted alongside scalar metrics. There are no extra forwards for diagnostics, target maps or adapted checkpoints. Masks are read by the evaluator after final prediction. Source statistics policies are never chosen using GT.

Host time excludes evaluator, old timing is historical; network calls are not FLOPs. Remaining_dev is exposed development data, not unused validation.
