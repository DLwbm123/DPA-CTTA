## Release fixes

The release entry appends and flushes/fsyncs each completed visit to a new private per-task/arm JSONL. It writes completion only after exact arm coverage and final source-state equality. Failure records retain task, arm, visit, segment, stage, exception type, private reason and successful prefix count. N/A completion and B's prefix survive B failure. Exceptions terminate the pilot with exit 1; no resume, next-image fallback or step checkpoint exists.

E3: `prompt_state_delta_norm` measures the entire host.step state change including memory initialization. CUDA peaks use actual process allocator observations; no empty-cache manipulation is used.
