# R65 single-atlas reverse propagation

Registered before real registration or target scoring. R63 forest selection failed; R64 found weak margin/quality association. Test whether image-aligned spatial label transfer provides useful candidate feedback. This is a new mechanism, not an RF parameter or confidence-threshold sweep.

Basis: [Valindria et al., section II-A, single-atlas label propagation](https://arxiv.org/html/1702.03407). It evaluates candidate labels transported by nonrigid image registration. Its MRI results do not validate fundus use. Here use a task-specific 2D TV-L1 implementation, not a reproduction of the paper's cardiac registration. [scikit-image API](https://scikit-image.org/docs/stable/api/skimage.registration.html#skimage.registration.optical_flow_tvl1) supplies the fixed solver.

Freeze the exact R63 eight source references, 48 SEARCH images, two R52 candidate masks (CW/VPTTA seed17011), two orders, 96 pairs and original 512px outputs. No extra source data, labels, model or segmentation inference. Read 512px RGB via existing reader, area-average to128 and rgb2gray. For every candidate/reference pair compute optical_flow_tvl1(reference,current), attachment15, tightness.3, num_warp5, num_iter10, tol.0001, prefilterFalse, float32. No intensity tuning, affine pre-stage, solver sweep or reference selection. Nearest-neighbor transport of the candidate's 128px mask uses reference-grid plus flow; outside pixels are background. Score mean OD/OC Dice per reference, then maximum over the same eight references. Choose whole original mask; ties retain CW. Flow depends only on images, while the transported-mask score depends on the candidate. Recompute flow per candidate to keep the implementation simple and qualification costs honest.

Reuse R63 guard, all96 retirement barrier, separate scorer, fixed primary gate (+.1pp versus CW, CI lower>0, both orders>0, worst cell>=-2pp, RVOC>=1pp), bootstrap and random/oracle controls unchanged. Reuse the legacy scoring output schema and regenerate a correctly titled final report at delivery. No result may be promoted on secondary metrics if the primary fails.

Before real images: synthetic translated texture/mask validates flow direction and nearest interpolation (Dice>.98), identity, outside-zero and candidate dependence. Existing source authorization applies only to the same eight records. Publish aggregate results and failures after completion.

Risks: optical flow between different eyes need not represent valid anatomy, can distort shapes and inherits photometric assumptions; no diffeomorphism or clinical correspondence guarantee. Source checkpoint overlap unknown, grouping CONTENT not patient, SEARCH exposed. This diagnostic cannot establish independent generalization, source-free operation or novel methodology.
