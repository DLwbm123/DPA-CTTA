# R63 RCA reference-assisted candidate selection

Registered before real forest fitting/reference decoding/target scoring. The user explicitly authorized fixed small existing source references on 2026-10-17. This overrides the R20 model-only source-access prohibition only for the eight frozen reference groups below; no other source set, external model or new dataset is admitted. This is source-reference-assisted inference, not source-free CTTA.

The complete fixed algorithm, candidate definitions, feature scales and practical gates are in [R63_RCA_DESIGN.md](../R63_RCA_DESIGN.md). This registration adopts them unchanged: 48 balanced SEARCH contents, seed17011, both orders, R52 archived CW_LSO/VPTTA paired masks; 96 pairs. Eight groups are the first eight entries of the existing frozen source val split (25 available); select their existing registered representatives. Grouping is CONTENT, not patient-independent. Source checkpoint training membership remains unknown. Source and target registered content identities are disjoint.

Metadata qualification checks the frozen source split/manifest binding, source file availability, identical R50/R52 online sequences, each archive's completion receipt and sequence binding, 1951 visits and expected packed-mask size. It extracts exactly the two original candidate masks for each registered pair. It does not read target labels, fit forests or rerun either segmentation model. Existing input readers preserve their required content-identity validation when decoding; no extra archive-wide checksums are added.

The selector fits independent OD/OC forests to each candidate and scores eight source references. Source images and masks are allowlisted explicitly; only the current target image is additionally readable. The worker denies scorer files, unregistered data and target-label paths, including symlink escapes. It cannot read target labels or historical scores. All selected masks and private choice scores are written before process retirement; a separate CPU scorer requires successful retirement and exactly 96 completed pairs before target-label access.

The first registered pair qualifies the two real candidate scores by an exact repeated fit and requires projected full selection cost <=6200 worker-seconds, including elapsed initialization, a 1.5 multiplier on the remaining 95 pair costs and 120 seconds reserve. Its first deterministic result is retained as formal pair 0; its repeat is qualification overhead. If qualification fails, stop without target scoring. No new pair, reference, hyperparameter or retry is substituted. This benchmark does not measure online full-model deployment latency: both candidate models would also be required in deployment.

Primary selector minus CW_LSO: mean >=0.1pp, content-cluster bootstrap 95% lower bound >0, both orders positive, worst domain/channel/order >=-2pp and REFUGE_Valid OC mean >=1pp. Domain/channel/order weighting is equal. Publish oracle headroom/regret, non-tied pair ranking accuracy, selection coverage and all negative cells. No secondary outcome can rescue a failed primary gate.
