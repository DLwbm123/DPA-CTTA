# CTTA 四方向一次性冻结实验：执行 Prompt

你现在作为本项目的研究工程执行代理，在现有 CTTA 代码、数据与授权计算环境中，完成下面这一轮有限实验。任务是实现、测试、执行、汇总四个方向，而不只是继续提出方案；也不是把所有模块直接叠加，最后只报告一个最好结果。

本轮四个方向：
A. 当前图像内部特征原型纠错。
B. 多阈值结构候选与区域验证。
C. EVA-0 启发的两次前向零阶适应。
D. ORCA 启发的源端条件化残差纠错，目标端冻结。

这是一个新实验，不恢复已关闭的 R15 campaign，不恢复 RL，不自动开启下一轮。四个方向都必须得到实现与源端检查；具备运行资格的方向都进入同一个目标评价协议，不因为源端小幅负收益就悄悄删除。

以下超参数是本轮提出的工程起点，不是论文报告的最优值。除明确列出的源端选择外，不进行参数搜索。所有改造均使用 Inspired / Adapted 标识，不冒称原论文复现。

## 2. 问题、数据边界与输出约定

本轮只回答四个问题：图内特征是否产生正确的新边界修改；结构验证是否减少错误修改；零阶参数更新是否优于同预算的纯扰动预测；源端上下文纠错是否优于同容量的概率侧纠错。

目标标签只能由独立 scorer 在预测轨迹终态封存后读取，全部注册实验臂终态后才向研究侧展示目标分数。算法进程不得访问目标标签、目标 Dice、由目标标签计算的 oracle、域别最优阈值或病例挑选结果。

禁止先看目标小样本效果再改架构、门控、损失或参数。目标数据已经参与过历史开发，本轮结果仍标为 DEVELOPMENT，不称独立确认。

沿用现有 source_train/source_val 划分；新增训练只能使用已授权的源数据。原图及其所有增强版本必须属于同一划分。已知患者 ID 时按患者隔离；未知时按图像隔离，并明确不能据此声称患者独立。

不同患者不是连续切片；不能通过强行匹配相邻样本面积、固定前景比例或均匀类别边际来稳定输出。

所有方法保留原分辨率、阈值和公共后处理。结构模块的额外处理须单列，不能把额外后处理偷偷加入其他基线。

定义 B=DS_H025 为静态纠错方法的直接起点。其 raw logits 来自既有实现，不从饱和概率重新构造。所有未获准修改的位置通过显式条件选择原 logits，保证精确保留。

## 4. A：图内原型纠错

从原图前向中获取一个空间对齐的 decoder 特征层。优先核查 up3；实际结构不同则在源端预检中固定一个等价层。只允许一个层，不搜索多层组合。网络及 BN buffer 冻结，特征 detach，不保留反向图。

在源端确认标注定义后，构造背景、盘内非杯、杯三个互斥辅助区域。初始种子条件：
- 背景：p0_OD≤0.1 且 p0_OC≤0.1。
- 盘内非杯：p0_OD≥0.9 且 p0_OC≤0.1。
- 杯：p0_OD≥0.9 且 p0_OC≥0.9。

种子远离原图预测边界，按固定半径腐蚀后映射到特征网格。所有插值方向和 align_corners 明确记录。翻转不是种子的强制真值，不用目标评分决定是否信任翻转。

对特征做通道 L2 归一化，区域内平均后再次归一化，得到三个 prototype。每类至少 16 个特征网格种子；缺类、非有限或原型范数过小时整图回退 B，并记录原因，不强迫图中出现前景。

q_i(k)=softmax_k(cos(f_i,mu_k)/0.1)。
q_OD=q_盘内非杯+q_杯，q_OC=q_杯。

可编辑区域 M 为 B 硬边界的固定空间带，半径 r=ceil(0.01×min(H,W))，并排除可靠种子内部。它不等同于 p∈[0.4,0.6]，不复制 R14 的概率门控。

候选 logits：
z_P = where(M, z_B + 0.25×clip(logit(clamp(q,1e-6,1-1e-6))-z_B,-1,1), z_B)。

强度、温度、种子阈值、层和空间半径在本轮固定；源端检查不变成持续搜索。每图只计算一次 prototype，不迭代更新伪标签，不写入跨图记忆。

记录 seed 覆盖率、回退率、原型类间距离、编辑像素比例、编辑前后 TP/FP/FN。另做一个源端固定空间打乱特征的诊断，不新增目标实验臂。

## 5. B：结构候选与区域验证

借鉴多阈值结构稳定性，但本轮不实现完整持久同调＋OT＋在线训练头，不声称复现 TopoOT。

S 的候选来自 B 概率在固定阈值 {0.40,0.45,0.50,0.55,0.60} 下相对原决策的局部增加／删除。对变化区域分解连通分量，限于 M；禁止把不同阈值的全图 mask 直接做并集充当逐区域选择。

必须保存每个候选的空间 support、通道、增加／删除方向、父分量、阈值来源及跨阈值对应关系。采用固定 8 邻域；对应关系用空间重叠匹配，IoU 阈值 0.5，冲突按固定确定性规则处理。该实现叫多阈值连通结构追踪，不冒称严格持久同调。

P_VERIFY 的候选仅来自 P 已提出的硬决策修改；D_VERIFY 同理。不能在验证时悄悄新增更强的候选产生器。

完整验证器采用相同冻结规则：
1. 候选区域的原型语义证据支持新标签，平均新旧标签概率差至少 0.05；证据无效则拒绝。
2. 候选所属结构在至少 3 个阈值层级中存在空间对应；不得只比较面积。
3. 不删除可靠内部种子，不新增标注协议禁止的包含关系错误，不增加不必要的碎片或孔洞。
4. 累计编辑不超过有效图像像素的 2%，不跨越 M。

原型证据对 P 不是独立模型证据，报告中不得将其称为独立验证。结构一致同样不是真值保证。

候选按固定的语义支持、稳定性和确定性位置顺序排序，单次贪心接受；每次检查与已接受候选的合并结果。拒绝的候选恢复 B 的原 logits。来自阈值 tau 的结构候选在其 support 内取 z_tau=z_B-logit(tau)，support 外保留 B；同像素冲突只接受固定排序中第一个通过检查的候选，不叠加多次偏移。不用人工 0/1 概率伪装为校准输出。

P_SIMPLE 对完全相同的 P 候选使用最大连通域／填洞规则形成简单形态学参考，只接受与该参考一致的候选，不使用特征支持或多阈值追踪。候选边界、编辑预算和输出回退与 P_VERIFY 相同。该对照所用的最大连通域、填洞及并列规则须固定，并明确既有公共后处理中是否已经存在同类操作。

结构候选的并发冲突、包含关系、无候选和 tie-break 必须写入测试。规则不充分时只能在源端／合成样例上补齐，正式目标访问前冻结，不以目标表现修改。

源端可计算已列举候选输出集合内的 oracle 选择诊断，但要标为使用源标签的离线诊断；它不是可部署方法，也不是任意组合算法的理论上界。

## 6. C：EVA-0 启发的零阶适应

此路线独立于 B，不调用原图＋翻转基线作为运行时教师。只读源参数锚点不需要前向；读取额外源模型输出则必须计入前向次数。

默认在已固定的 decoder 层加入一个零初始化、恒等旁路的低维通道仿射 adapter：
F'_c=(1+a_c)F_c+b_c×RMS(F_c)。

RMS 基于当前同一次前向中、注入之前的特征计算，不需要未来样本。只允许更新 a,b，冻结主干和 BN buffer。up3 为 256 通道时参数维度为 512，但以实际检查为准。不能只对最终单个二值 logit 做尺度归一化后声称学到了新边界。

每图 t，围绕当前 adapter 参数 w_t 生成两侧扰动：
z+ = f(theta0,w_t+mu*u_t,x_t)，z- = f(theta0,w_t-mu*u_t,x_t)。

先输出 sigmoid((z++z-)/2)，再利用这两次输出更新供后续样本使用的 w。平均 logits 与平均概率不混用。不得更新后再补一次未计费前向。

全局种子、源端选择种子与 D 训练种子固定为 20261003；目标 Z 种子固定为 [20261003,20261004]。基础随机方向取独立 Rademacher 向量，公共随机数由 seed、order、step 确定，分支额外采样不能改变其他分支的随机数流。零阶估计为：
ghat=((L+−L-)/(2mu))×u_t。

分割损失须单独适配：两个通道使用 Bernoulli 而非互斥 softmax；按通道的空间 RMS 对两侧 logits 归一到共同尺度，再计算无标签熵；前景／背景分组权重由两分支平均输出一次性确定，两个损失使用同一权重。禁止逐像素二值向量 L2 归一化后只剩符号的退化设计，禁止通过背景总像素数支配损失。

具体令 bar_z=(z++z-)/2，r_bar,c=sqrt(mean_ROI(bar_z_c^2)+eps^2)，r_±,c=sqrt(mean_ROI((z±_c)^2)+eps^2)，s±_c=z±_c×r_bar,c/r_±,c，eps=1e-6。以 sigmoid(bar_z_c)≥0.5 划分前景组、其补集为背景组；对 sigmoid(s±_c) 的 Bernoulli 熵先在各非空组内平均，再对组、通道等权平均，得到 L±。ROI 仅来自既有输入有效视野规则，不来自目标标签。两侧共用停止梯度的分组，空组不计入组分母。

不得强制 OD/OC 面积等于源均值、上一患者或固定比例。源端通过纯尺度扰动的捷径检查后冻结该损失；这是一项待验证的分割改造，不保证能抑制所有塌缩。

Z_PROBE：始终 w=0，仅两侧扰动预测，不更新。
Z_CORE：使用上述损失和零阶更新，不启用锚点策略。
Z_BOUND：相同损失；按从 1 开始的 t，每逢 t mod 4=0，使用 u=sqrt(d)×(-w)/(norm(w)+eps)×v，v 各维独立均匀分布于 [0,2]，代替随机方向。更新后做 w←(1-1e-3)w，再投影到 norm(w)/sqrt(d)≤0.05。源锚点为 w=0，锚点距离为零时回退随机方向；定向探测不宣称是各向同性无偏梯度估计。

所有更新统一梯度估计 L2 norm clip=1。源端只允许 4 个预列举的共享(mu,eta)组合：
(1e-3,1e-4)、(1e-3,5e-4)、(3e-3,1e-4)、(3e-3,5e-4)。
在固定源验证 episode 上，以 Z_CORE 与 Z_BOUND 的平均域等权 hard Dice 选择同一组合；完全并列时选较小 eta，再选较小 mu。全量保留 4 个结果，不看目标指标。若全部未通过数值或捷径资格，报告该路线资格失败，不偷偷改成反向传播。

Z_CORE 与 Z_BOUND 各自保持独立状态；每个 order 从源锚点重置，域切换时不重置。Z_PROBE 也独立使用注册随机数。

三个 Z 条件均做 2 个 order×2 个固定随机种子。随机种子只描述算法随机性，不等于独立患者重复。每次额外前向、回退与更新均计数；非有限结果不得调用隐藏的 C0 补救而仍声称两次前向。

## 7. D：源端条件化残差纠错

ORCA 原任务能在之后获得真实预测误差；本任务不具备目标标签反馈。因此本路线仅在源数据上监督训练两个小头，目标时冻结，不建立目标残差库，不在线训练。

两个头架构相同、参数量相同，建议 1×1 Conv→32 通道→3×3 depthwise Conv→1×1 Conv→2 通道，总参数≤100,000。最终层零初始化，起始输出必须与 B 精确一致。

D_LOGIT 输入 B logits、原图与翻转预测的差异、熵及由预测生成的边界距离信息；图像／特征输入槽置零。
D_CONTEXT 使用相同槽位，额外输入同一次原图前向的 decoder 特征、缩小的 RGB 和固定图像梯度。源训练集计算输入标准化统计，目标端不重估跨图统计。

输出统一为 z_D=where(M,z_B+0.25×tanh(r_phi),z_B)。残差上界与 A 的有效幅度一致，不搜索强度。

基础模型全程冻结。源数据可使用现有、标签保持的风格扰动；增强前先按原图／患者划分，禁止同一原图的不同增强跨训练和验证。缓存特征只能对应其确切增强版本，不能把旧特征当作新图特征。

源损失采用固定的区域均衡 BCE＋soft Dice＋0.1×原本预测正确区域的概率改动惩罚。两个头采用同样样本顺序、训练步数和超参数。

默认 AdamW，lr=1e-3，weight_decay=1e-4，batch=8，最多 2000 updates/头。在 500/1000/1500/2000 步仅按源验证 hard Dice 保存选择；并列选较早 checkpoint。不进行架构搜索、学习率搜索或追加训练。原有更严格训练上限优先。

若合法源训练数据或标签不可用，不得拿目标数据替代；交付该方向实现与 BLOCKED_SOURCE_DATA，其他方向继续。

D_VERIFY 不新增训练，直接将固定验证器作用于 D_CONTEXT 的候选。报告中把 D 的额外源监督成本与 A/B 的无新增训练明确区分。

## 8. 工程与科学预检

至少通过以下测试后才接触本轮目标图像：
- 关闭模块、零残差、零 adapter 时与基线相同；hook 不改变输出。
- DS 与 H025 的阈值硬决策一致，阈值边界、极端有限 logits 均测试。
- 未编辑像素 raw logits 精确保留，参数与 BN buffer 不意外变化。
- OD/OC 通道和包含关系与真实标注协议一致；不把两者误当互斥类别。
- 特征与 mask 的 resize、翻转逆变换、有效区域完全对齐。
- 原型缺类、空区域、全前景／全背景、冲突候选均有确定性行为。
- 无标签算法路径无法读取标签；破坏／更换 scorer 标签不会改变算法输出。
- Z 两次前向计数、两侧参数恢复、先输出后更新、随机状态、checkpoint 恢复正确。
- Z 的有限差分更新方向在源端小型可解析例子上通过方向检查；纯尺度捷径和逐像素归一化退化有针对性测试。
- D 两头容量相同；目标进程不能创建优化器更新它们。
- 每个逻辑实验臂拥有独立状态，共享中间特征不会造成状态串扰。

测试通过与效果有效分开报告。源端错误分析必须包括边界偏移与结构错误的区别，不以“轮廓更规整”代替 Dice。

## 9. 资源预算与一次性运行顺序

本 prompt 建议的新预算为累计 GPU-worker 占用 12 GPU 小时、墙钟 24 小时、最多 2 张已有授权 GPU、私有新增缓存峰值 8 GiB。它们是上限，不是预计耗时。现有更严格权限或剩余额度优先，不自行扩大预算。

建议 GPU 子预算：预检/profile 1 小时，源端标定及 D 训练 3 小时，目标轨迹 6 小时，失败恢复储备 2 小时；总上限始终为 12，不因并行而翻倍。先保留所有方向的目标运行额度，不能让第一个训练任务耗尽预算。

T0 从本轮第一次准备操作开始。GPU-worker 占用按实际持有设备的任务区间累计，CPU 工作与墙钟另记；同时记录 full forward、partial forward、head forward、backward、更新、图像访问和失败次数。

顺序：读取与绑定→源端实现/测试→短 profile→预算准入→完成源端有限选择→冻结全部科学配置和数据清单→目标执行→全部终态封存→独立评分→汇总关闭。

Profile 只使用源图或无标签机械测试，不开目标分数。不得进行长时间 profile 后才发现预算不可行。预估至少同时覆盖 GPU、CPU 结构处理、I/O 与存储，并乘 1.3 安全系数；恢复储备不作为正常运行额度。

优先尝试原完整开发流：按现有清单核验 1951 次在线访问、1695 条主评分/每条流。不能把未评分 warmup 删除后重启有状态方法。

如果完整矩阵无法准入，只有一个预注册降级方案：所有方法统一采用与旧短流严格匹配的 1024 在线访问协议；主评分数量由相应清单核验，不能硬凑。此时结论仅为统一短流筛选，不与完整流均值混比。是否降级仅由目标评分前的成本决定，不由效果决定。

如果短流仍超预算，完成源端包并停止，列出缺少的预算与哪些目标轨迹未运行。不擅自删除不喜欢的实验臂、不降低图像分辨率、不扩大预算。

静态条件 C0/H025/DS/P/S/P_SIMPLE/P_VERIFY/D_LOGIT/D_CONTEXT/D_VERIFY 共享当前图像的原图和翻转前向及原图特征，在同一次图像访问中输出各自结果，随后释放特征。禁止构造跨图完整特征库。

若两个 order 的内容集合相同、静态方法逐图确定且评分后处理无状态，可只真实计算一次，再按内容 ID 对齐两 order。第二份标记为重排复用，不计作新运行。内容集合不同时计算并集，不能猜测相同。

Z 条件不能复用静态预测代替扰动输出；有状态 G 也不能拼接历史局部结果冒充新轨迹。共享计算节省的 campaign 成本和每个方法单独部署成本分别报告。

优先保存压缩硬 mask、内容映射和哈希。概率仅在存储准入后保存，源端缓存采用有界策略。完整概率无法保留时，概率指标标 NA，或在正式目标访问前固定同一哈希抽样集合单列样本数；不得从硬 mask 伪造 soft Dice/Brier/ECE。

## 10. 停止、恢复与日志

仅因非有限、身份/数据不匹配、标签隔离破坏、持续 OOM、权限问题或硬预算停止；不通过实时目标分数早停，因为研究侧不应看到这些分数。

技术性故障允许每个物理任务最多一次原配置恢复。必须恢复模型/adapter、随机数、在线状态、已处理样本位置和输出封存记录。不允许清空适应状态后从故障处继续；不能精确恢复时标记失败，预算内从头重跑才是新的完整轨迹。

科学代码发生变化，需要新的配置 hash 和清楚的版本边界；保留旧前缀。公开终态不得只有“已提交”而没有实际运行状态。

提供简短阶段更新：已完成的实验臂、累计资源、当前错误和阻塞。不得承诺异步交付、编造精确完成时间，或把等待当成 GPU 计算。

## 11. 指标、比较与预注册判断

主终点沿用既有定义：每图 OD/OC hard Dice 平均→域内平均→四域等权→order 等权。Z 先在相同 order 内对两个种子平均，再汇总 order；逐种子结果全部保留。

必须同时报告 ΔC0、ΔDS/H025、ΔGraTa，且注明参考是否为匹配复用。OD、OC、每域、每 order、每 seed、最差域/通道、每图配对差及最差 10% 都保留。

辅助指标：编辑像素的正确→错误/错误→正确变化，TP/FP/FN、边界 ASSD 或项目既有边界指标、包含关系违规、碎片/孔洞、原型回退、候选接受拒绝、adapter 偏移、更新跳过率、实际延迟和内存。空 mask 的边界指标处理沿用既有规则并报告有效分母。

有真实概率才报 soft Dice/Brier；soft Dice 不作为概率校准已改善的充分证据。仅有抽样概率时显式标明抽样范围。

核心机制比较固定为：P−DS；S−DS；P_VERIFY−P；P_VERIFY−P_SIMPLE；Z_CORE−Z_PROBE；Z_BOUND−Z_CORE；D_CONTEXT−D_LOGIT；D_VERIFY−D_CONTEXT。

本轮设两层描述性判断：
- 新纠错方向有开发信号：相对 DS 的主 hard Dice>0，且在可比较的两个 order 上均不为负。
- 值得进入新数据确认：相对 C0 至少+0.5 个百分点，同时优于 DS；最差域/通道下降不超过2个百分点。阈值是资源决策规则，不是显著性、临床或发表标准。

是否超过 GraTa 单列，不能因为超过 DS 就称超过强基线。Z 的两种子只有小样本随机性描述；单一 D 训练种子结果也注明局限。

同一图像的不同 order 不扩大独立样本量。有患者信息时才做患者聚类的配对不确定性分析；未知时以配对分布为主，不伪造患者级置信区间。不挑最好 seed，不把同一开发集上多臂中的最大值叫独立确认。

即便全部负结果，也完整报告。这说明当前候选生成、验证、损失或源迁移在本 checkpoint/协议下不足，不是所有相关论文方向被普遍证伪。
