# R19-MO：只有现成模型的 CTTA 实验计划与 Codex 执行说明

状态：研究计划，尚未执行。本文中的新方法效果均未知。

## 1. 任务与研究假设

从已有分割 checkpoint 和顺序到达的无标签目标图像开始，研究：

- H1：GraTa 的部分收益/退化能否仅通过降低更新幅度解释？
- H2：不参与当前反向传播的验证视图，能否帮助决定是否提交当前更新？
- H3：少量已到达的目标样本，能否检查候选更新对历史预测的影响，并改善后续在线输出？

本轮不训练 Actor，不使用 RL，不训练纠错头，不加载旧 FiLM/B carrier。实验名称只用于登记，不代表已经证明创新性或安全性。

参考父版本：DLwbm123/DPA-CTTA 的 b3b8fd7c30d5c36c82b3c565f5859e2d33ae853b。先记录当前工作区、分支和未提交修改；不得覆盖用户修改或把旧版本强制重置到工作区。

## 2. 不可违反的数据和资产约束

唯一允许的预训练资产是用户已经提供的分割模型及其原有必要结构、预处理约定、权重和 checkpoint 内的 BN buffers。允许复制该 checkpoint 作为初始/冻结参考，不要求重新训练源模型。

禁止读取源图像、源标签、源验证集、旧源特征缓存、源端拟合的独立 scaler、Fisher 文件、Actor、B carrier、额外纠错头、源端训练的奖励模型。不得通过复用旧模块权重规避限制，也不得新增外部预训练模型。

目标图像只允许按登记顺序逐张到达；历史缓存只能来自当前轨迹已到达的数据。每条独立轨迹从原始 checkpoint、空优化器状态和空记忆开始，不能继承上一条轨迹的目标适配状态。不得预扫描整个目标集来估计均值、分位数、原型、排序或填充记忆。允许登记的有界历史重放，但必须单列其额外图像访问和计算成本。

目标标签只能由隔离的离线 scorer 在对应预登记实验集合全部封存后读取。在线程序不得获得 Dice、奖励标签、域名称、真实域边界、患者标签信息或后续图像。独立的开发评估若用于决定后续研究方向，必须登记为开发集选择，不能称为无标签模型选择或独立确认。

检查现有预处理和 ROI 裁剪是否依赖目标真值；存在依赖时先明确协议和影响，不得隐瞒为普通 model-only CTTA。

原 R17 的源验证 parity / source qualification 步骤不可照搬。单元测试用程序生成输入；真实数据机械检查只能用本轮允许的无标签目标到达，并计入访问账本。

## 3. 先做依赖与复现审计

输出 MODEL_ONLY_AUDIT.json，至少包含：初始 checkpoint 哈希、全部外部读取资产、所有可训练参数、BN policy、预处理、所有缓存的来源与初始状态、标签隔离、真实到达顺序以及计费规则。

测试要求：

1. 移除所有旧 Actor/carrier/纠错头/源缓存后，C0、DS 和原生 GraTa 仍能运行。
2. 禁用本轮所有新功能时，与原生 GraTa 在同一执行环境的 logits、BN buffers、优化器状态与随机状态匹配。
3. 只读验证不得改变 BN、优化器、梯度、随机状态或未来主流程增强；不得为了方便静默改变原生 BN 的 train/eval 语义。
4. 候选拒绝必须恢复全部模型与优化器状态，包括 BN buffers、Adam moments/step、调度器和临时扰动。输入游标只前进一次；增强随机流按预先登记的规则前进，验证与诊断使用隔离随机流。
5. 快照续跑与不中断执行的下一张输出一致；不允许只回滚权重而保留 Adam 动量。
6. 空记忆时 G_MEM 与 G_VAL 一致；拒绝更新时输出来自更新前的正确状态，不可输出已拒绝候选的 mask。

以上是测试要求，不得把未运行、零测试数或缺少证据写为通过。

## 4. 本轮唯一实验矩阵

沿用已登记的两个完整顺序、同一 checkpoint、512 分辨率和 batch size 1。在历史协议有效的前提下，每顺序为 1951 次到达、1695 个主评价观察；额外 256 次到达的角色必须查明并继承，不能擅自删除或称为本轮新测试集。

| ID | 条件 | 本轮处理 |
|---|---|---|
| C0 | 原始模型，不适配 | 仅在 checkpoint/预处理/内容/角色/顺序/指标完全匹配时复用封存参考 |
| DS | 原模型的现有固定水平翻转融合 | 同上；不是本轮新 CTTA 方法 |
| G | 原生 GraTa | 2 条新完整轨迹，带隔离的只读诊断；验证历史结果复现 |
| G_HALF | 原生 GraTa，每一步原生动态学习率再乘 0.5 | 2 条新完整轨迹 |
| G_VAL | 原生 GraTa 候选更新 + 当前样本验证验收 | 2 条新完整轨迹 |
| G_MEM | G_VAL + 有界历史样本检查 | 2 条新完整轨迹 |

共 8 条新完整物理轨迹，其中 6 条是新方法轨迹，2 条是原生 G 诊断轨迹。每个条件只有一个预登记配置，不做目标分数驱动的网格搜索。

增强种子沿用原生匹配设置；新验证/记忆/诊断种子单独登记。不能把两个种子用途、两个顺序或同一批图片的重复使用当作独立患者重复实验。

## 5. G_HALF 的精确定义

保留原生 GraTa 的辅助熵、临时扰动、六弱视图、一强视图、梯度余弦、恢复、可训练参数、BN 策略、每图更新次数和输出时机。

只将最终原生动态学习率 eta_native 替换为 0.5 * eta_native，不改变梯度目标。

目的：检验新验收器的效果是不是单纯来自更保守的更新。它不是静态学习率基线。

## 6. G_VAL 的精确定义

### 6.1 状态和候选

S_minus 是当前图像到达后、执行 GraTa 临时扰动/更新前的完整持久状态。按照原生 GraTa 生成且仅生成一个候选 S_plus。允许接受或拒绝，不进行反复线搜索，不生成不同学习率网格。

主输出时机保持原生的“当前图像无标签适配后输出”。同时保存无副作用的更新前输出供离线诊断；不得将它和更新后主指标混用。

### 6.2 验证视图

在输入的合法 [0,1] 强度范围、执行模型标准归一化之前，固定使用 gamma=0.95 和 gamma=1.05 两个轻度光度视图。二者不进入当前 GraTa 梯度，不替换其原生增强。若输入规范不支持这种变换，应在任何目标评分前报告具体问题并冻结等价的合法强度变换；不得看分数后换增强。

对 S_minus、S_plus 分别执行两个只读前向。保持原生 BN 计算语义，但隔离并丢弃验证产生的所有状态副作用。明确：未参与当前梯度的视图并不是独立患者或独立测试集，也不保证无标签指标等于正确率。

### 6.3 验证量

对 OD、OC 分别计算两个验证视图预测间的 Bernoulli Jensen-Shannon divergence，除以 ln(2) 归一化。概率计算用 float32，概率数值截断为 [1e-6, 1-1e-6]。

空间权重由更新前原图预测固定：以 0.5 阈值构造前景；用半径 2 的膨胀/腐蚀构造边界带；分别平均前景内部、边界带和背景内部的 JS，再对非空区域等权平均。候选不得重算支持域来缩小受检查的区域。随后对 OD/OC 等权平均得到 V。

某通道的更新前前景少于 16 个像素，或出现不有限数值、完全退化而无法定义有效支持的情况，记为验收不可用，采用本轮预登记的保守处理：跳过该次更新、保留 S_minus，并单列计数。不得将空前景的一致性自动计成完美分数。此规则会限制从空预测中恢复，是已知限制，不能隐瞒。

接受条件：

- 两个通道均满足 V_plus,c <= V_minus,c + 1e-6；
- 两通道平均满足 V_minus - V_plus > 1e-6；
- 候选数值有限，且每通道 hard 前景面积的 (A_plus+1)/(A_minus+1) 位于 [0.5, 2]。

否则拒绝候选并完整恢复 S_minus。面积规则只防止一次更新的大幅退化，并非正确性或防塌缩保证，慢性塌缩仍可能发生。OD/OC 包含关系先只做统一离线诊断，不给某个新方法额外后处理。

这些阈值是本轮一次性工程默认值，不是已验证最优值，不允许根据目标 Dice 调整。

### 6.4 计算

在能正确复用原生前后原图输出时，验证增加 4 次前向，仍只有一次原生候选的两次反向和一次尝试的 Adam 更新。拒绝了候选也必须计费，不能说节省了这次反向。

## 7. G_MEM 的精确定义

不新增预测头，不融合不同患者的像素，不对当前图像注入旧患者 mask，不增加基于源数据的任何统计量。

记忆容量 M=8；每次检查 K=1 个过去样本；FIFO 管理；条目在写入后经过 64 次新到达即过期，过期按到达数执行，不依赖接受率，防止旧条目永久否决所有更新。它首先是短期历史检查，不能声称已经解决长时域遗忘。

条目包括历史输入 x_j、提交时的 soft prediction q_j、时间戳和固定的可靠支持。可靠支持对每个通道分别是 q_j >=0.9 的前景和 q_j <=0.1 的背景，两组均至少 16 像素。所有内容仅在私有运行目录保存。

当前图像处理开始时先清理过期条目，再选最旧有效条目。对同一历史 x_j，分别用 S_minus、S_plus 做只读前向；每通道分别计算可靠前景/背景等权的 Brier 距离 R(S;x_j,q_j)。q_j 固定并停止梯度，不刷新成当前模型输出。

只有在 G_VAL 通过，且 OD/OC 各自满足 R_plus,c <= R_minus,c + 1e-6 时，才提交 S_plus。空记忆时完全退化为 G_VAL。

当前决策结束后，只将“更新已提交且可靠支持有效”的当前样本写入；然后按 FIFO 淘汰超容量条目。当前样本不能在自己的决策前进入记忆。

历史检查最多增加 2 次前向，不增加反向。记录空记忆率、条目年龄、写入/淘汰/过期数、历史否决率以及是否因记忆变得几乎不更新。历史预测可能错误，保留历史预测不等于保留正确知识；需要真实离线结果验证。

## 8. 原生 G 的稀疏反事实诊断

在两条原生 G 轨迹的固定位置 t=1,17,33,... 记录诊断；用索引而非标签/表现/域边界挑位置。所有位置在实验前登记。

从完全相同的更新前状态和原生增强出发，获得 skip、half、full 三个候选。原生主轨迹始终提交 full，另外两个候选及其验证不得污染主轨迹的持久状态或随机流。不能沿着 oracle 选择继续走主轨迹。

保存各候选的 mask、必要私有 soft 输出、验证量、实际操作数和状态哈希。可以复用严格验证等价的中间结果；没有等价证据就完整计算并如实计费。

所有 8 条正式轨迹封存且在线 worker 退出后，独立 scorer 才读取标签，计算：

- V_minus-V_plus 与实际单步 Dice 改变量的相关性；
- 实际有害更新的识别 AUROC，任一类别缺失时为 NA；
- 验收接受了多少有害更新、拒绝了多少有益更新；
- 同一更新前状态下三个动作的局部最佳 Dice 与固定 full/half 的差。

最后一项只是被抽样状态上的单步反事实机会，不是整条 CTTA 的 oracle 上限，不证明全局最优策略或长期收益。只有稀疏采样的诊断覆盖，不能把其结论说成逐图全覆盖。

## 9. 评分、比较与判定

保持原主指标：四个目标域 × OD/OC 八个单元等权宏平均，再对两个顺序平均。各个条件的内容、顺序、主评价角色、空 mask 规则、ASSD 规则完全一致。

必须同时报告 image-weighted Dice、每域/通道与每顺序差值、最差退化单元、逐图配对改善/退化数、ASSD 有效/未定义分母、空前景率、结构违例、接受率、延迟和计算成本。具备真实概率与标签时另报 soft Dice/Brier；历史只有 mask 的指标记 NA，不从 hard mask 伪造概率指标。

本轮值得继续确认的主要门槛：相对匹配 G 的 macro 平均至少 +0.5 个百分点，两个顺序均为正；image-weighted 平均不为负；没有某一“域×通道×顺序”低于 G 超过 2 个百分点。最后一项是研究风险门槛，不是临床安全标准。

额外机制判断：

- G_VAL 应与 G_HALF 比，不能只与 C0 比。若不胜过半步长，不能声称复杂判断优于简单保守更新。
- G_MEM 应与 G_VAL 比；预登记额外价值信号为平均至少 +0.2 个百分点且两个顺序不为负。没有额外价值就删除记忆，不继续堆模块。
- “几乎全部拒绝”需与 C0、G_HALF 一起解释，不能仅凭低退化率宣称有效适配。

不把开发集多次曝光后的挑选当作独立确认。两个顺序使用相同内容，不能当作两组独立患者。患者关系未知时不要把图片或像素当独立样本来声称严格显著性。新顺序/新增强种子只验证顺序/随机稳健性，不制造未见过的数据。

## 10. 预算与执行边界

建议本轮 GPU-worker 累计硬上限为 8 GPU 小时：审计与 profile 0.5，小额诊断预算 1.0，完整轨迹预算 5.0，恢复余量 1.5。CPU scorer 的时间/内存单列。

这是建议的资源上限，不是运行耗时承诺。所有真实前向、回滚候选、诊断、失败与恢复均计入，不用 nvidia-smi 利用率代替 worker 成本，也不把复用参考说成免费部署。

在未看目标标签的机械 profile 后，按完整矩阵估计实测成本，并登记总预算和阶段额度。若完整 8 条轨迹不满足上限，在全量执行前终止为 NOT_RUN_BUDGET，保留已做的审计和诊断；不得运行中凭表现删掉坏条件、缩短坏顺序或扩大预算。

接受的基础设施恢复必须有故障证据，使用精确快照继续，仍计入原预算。不因为负结果重跑。不得将本轮协议继承为自动启动 R20 的授权。

## 11. 后续条件分支（不在本轮自动执行）

若验收/历史检查有真实正向开发信号，先在额外预登记顺序/随机种子上做匹配 G、G_HALF 和候选确认；存在真正未曝光的新病例/新域时，再进行一次冻结协议的独立评估。基线和候选都必须重新从原 checkpoint 与空记忆开始。

若后续仍研究 RL，先做从零初始化的轻量在线控制器，只使用当前/历史无标签特征与代理反馈。初始动作限制为 skip / half-native-step / full-native-step，禁止旧 Actor/carrier。

奖励候选为“未参与反向的当前验证改善 - 历史代理损坏惩罚 - 实际计算成本”。成本系数和缩放必须在新一轮评分前登记。只更新被实际执行动作的可观测反馈；反事实全动作评估若用于在线选择，必须按实际搜索方法和成本报告。

当前一步反馈可以先支持 contextual bandit 式基线，但由于动作会影响后续模型状态，不能套用独立上下文假设的最优性保证；也不能据此声称已经验证长期 RL。若要主张长期记忆写入/规划收益，需要后续到达后的真实因果反馈与一步方法的匹配对照，不得读取未来图像给当前决策算奖励。

若代理变化与真实效果无稳定关系，或三个动作缺少可利用机会，不扩展此控制器；应把负结果作为限制，而不是重新引入源端监督来补奖励。

外部方法对照可优先审计原生 CoTTA/SAR 与医学目标记忆方法 SicTTA 的兼容性，但不把移植版冒称官方原样复现；不得为复现新增源端训练。记忆本身已有相关研究，不直接作为本工作的创新结论。
