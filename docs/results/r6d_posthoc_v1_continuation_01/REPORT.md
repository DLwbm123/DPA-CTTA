## 3. 监督贡献与硬错误质量

R_BAL 在自身状态的原始前景 logit 残差能量占比 f0 约 0.429–0.446；施加区域权重后 fw 约 **0.967–0.975**。实际加权 BCE 的前景占比约 **0.820–0.858**。这说明前景主导局部输出 logit 的平方梯度质量与 BCE 质量；fw 的变化是权重公式的直接后果，不是独立的有效性证据，也不代表 BN 参数梯度方向。

C/SCALE/SHUFFLE 的基础区域量只是假设在其自身状态采用 BAL 权重的参考，未冒充实际应用。C/SCALE 的实际前景能量占比用 f0；SHUFFLE 的实际分区能量/BCE 占比未记录，保留缺失。所有原始量、局部余弦、权重、BN 范数和 Adam 位移均见完整表。

上述均值为四域等权，正负计数是 1695 内容的直接人数，两者口径不能混用。加权硬错误质量在六个流×通道聚合都增加，但每组仍有 199–491 个反例。它是 (w_fg·FP+w_bg·FN)/N，**不是 BCE、错误残差或错误梯度**。

order0 与回访中，BAL 的 q precision 较 C 降低、recall 提高；order1 方向相反。以回访 OD 为例，precision 0.902694→0.870463，recall 0.859325→0.887496；OC precision 0.779764→0.754780，recall 0.752848→0.769097。可见 FP/FN 权衡，但这些也是不同实际状态下的目标质量，不能分离权重的因果作用。precision/recall 是逐内容比例的域等权平均；不是先池化 TP/FP/FN 后再取比值。

不能恢复 GT 分区下的 soft residual/BCE、每个错误 token 的梯度、BN 参数梯度方向或 R_HALF 轨迹。现有前景残差绝不被当作 FP 残差。FIELD_AVAILABILITY 明确保留这些边界及 SHUFFLE 两个实际分区指标各 11706 条缺失。
