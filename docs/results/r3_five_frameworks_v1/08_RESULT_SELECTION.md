# R3 结果出来后的路线选择

## 总原则

有效性第一、机制贡献第二、发表定位及SOTA第三。所有方法完成后统一看结果，不根据前半流调参、不组合各域GT赢家。

五个主候选为 `T_LR/U_PCA/S_JOINT/M_TRANSPORT/G_PCA`；其余是简化对照或基线。对照胜出是合法研究结果，不必强行选择复杂候选。

## 主证据

四个主流继续参考：对C平均至少+0.5 pp，至少3/4顺序正向；同时展示最差观察顺序和各域代价。均值损害超过2 pp的域、最差顺序比C低0.5 pp作为风险提示。这些不是临床阈值、显著性标准或自动批准开关。

主候选还要超过自己的控制。控制差很小或方向抵消时，不声称PCA/迁移/几何/联合状态必要；不设新的小数点门槛伪装显著性。

secondary回访流必须单列，不与四序平均合并。对S，回访复用是关键机制证据；只在secondary上有价值时收窄适用场景，不用它覆盖主流失败，也不称为独立患者验证。

## 每个家族怎样解释

| 结果 | 选择 |
|---|---|
| T_LR好于C、RP、ISO和DIAG，修正带来更多正确而非错误teacher flip | 支持区域低秩概率教师；但teacher统计仍非校准后验 |
| T_ISO/T_DIAG已解释全部收益 | 优先简单统计教师，不坚持rank8的必要性 |
| U_PCA超过U_RAND和U_SCALE，且真实几何/区域指标与性能一致 | 支持特征到参数的方向保护；仍不能从probe直接声称旧域零遗忘 |
| U_SCALE与U_PCA相当或更好 | 收益主要可能是较小更新，优先简化 |
| S_JOINT超过S_SHARED/S_NOPCA，尤其在不同内容的环境回访时有效 | 支持参数状态与区域memory联合保存 |
| S_NOPCA更好 | 状态复用有用但PCA非必要，不能让原论文愿景强迫保留PCA |
| M_TRANSPORT超过M_IDPOST/M_SHUFFLE和C/RP | 支持正确坐标迁移超出post存储／随机变换 |
| M_IDPOST已得到全部收益 | 不把post特征写入收益归给Procrustes |
| G_PCA超过G_ISO/G_ORDER及C/RP | 支持区域度量参与空间监督 |
| G_ORDER或G_ISO更好 | 优先简单结构/图机制，不声称需要PCA |
| 候选只改善一个顺序或小域，关键OC风险变差 | 保留取舍结果，不升级默认方法 |
| 五个框架均无清楚价值 | 保留C，全部本批配置归档，停止自动扩展 |

## 输出建议

一个总表列五个主候选、各家最佳简单控制、C/RP；附表必须完整保留17臂。另列精度/实际延迟/VJP/模型forward/状态字节的Pareto关系，不因主候选名字较复杂给优先权。

每个框架给出 `retain_candidate / prefer_simple_control / mixed_not_promoted / unsupported_configuration` 等描述性决定和具体理由。

运行正常、bank ready、controller触发、拟合误差下降都只是机制已工作；不代表分割有效。0.5 pp不是TMI录用标准。通过这批筛选之后才可能提出独立验证或组合研究，但本包不授权自动继续。
